# 阶段与路线类型审计 V1

## 一、审计目的

`28-修行阶段/` 与 `29-修行路线图/` 建立于 V3 关系语义规范之前，其中大量箭头用于帮助理解，但目前容易被误读成：

- 普遍适用的修炼步骤；
- 可考的历史演化链；
- 宗派师承；
- 经典之间的直接因果关系。

本轮不以“尽快把所有旧文件加入 expected_ids”为目标，而先判断每个对象究竟是什么类型。

## 二、28-修行阶段审计

### 1. 筑基

当前判断：**可保留为 `stage` 候选，但必须限定到具体内丹体系。**

“筑基 / laying the foundations”确实出现在部分后世内丹体系的阶段化说明中。例如王沐对内丹的系统整理把“筑基”列为前置阶段，并明确其说明主要依据《悟真篇》等内丹传统。

因此不能写成：

```text
一切道家修炼
↓
必先筑基
↓
再炼精化气
```

更合适的模型是：

```text
stage.zhuji
scope: 部分后世内丹体系中的基础/准备阶段
not_universal: true
```

进入 V3 前还需要建立来源字段并说明具体体系。

### 2. 精气神

当前判断：**不是阶段，应迁移为 `concept` 概念组合。**

精、气、神在内丹中常作为人的主要构成及炼化对象，并出现“炼精化气、炼气化神、炼神还虚”等阶段化表达；但“精气神”本身不是一个位于筑基之后、性命双修之前的单独阶段。

旧表达：

```text
气 → 精气神 → 内丹体系 → 性命双修
```

应撤销。

后续建议建立：

```text
concept.jingqishen
```

并再视需要拆分：

- 精；
- 气（已有）；
- 神；
- 三者在不同文本中的组合关系。

### 3. 性命双修

当前判断：**不是阶段，更适合作为 `concept` / 理论原则。**

“性”“命”及二者修持关系是宋元以后内丹讨论的重要维度，不同传统对先性后命、先命后性及二者关系的说明并不完全一致。

因此不应写成：

```text
筑基 → 精气神 → 性命双修
```

后续建议建立：

```text
concept.xingming_shuangxiu
```

并明确它属于内丹史中的理论框架，而不是所有道家修炼共同的最终阶段。

## 三、29-修行路线图审计

### 1. 清修路线

当前判断：**项目现代研究导航，不是历史宗派路线。**

旧文件把：

```text
《道德经》《庄子》
↓
道、虚、静、心
↓
静坐、心斋、坐忘
```

排列为路线，具有导航价值，但不能理解成《道德经》历史上直接产生“静坐→心斋→坐忘”的固定实践流程。

### 2. 内丹路线

当前判断：**项目现代研究导航，不是统一内丹修炼次第。**

旧文件：

```text
《参同契》《悟真篇》
↓
丹鼎派
↓
内丹
↓
筑基
↓
精气神
↓
性命双修
```

同时混合了：

- 文本；
- 后世分类；
- 方法体系；
- 阶段；
- 概念组合；
- 理论原则。

不能继续作为历史或实践步骤关系使用。

### 3. 养生路线

当前判断：**项目现代研究导航，不是统一历史传统。**

《黄帝内经》、早期养生、导引、吐纳、服气之间确有可研究的历史交叉，但年代、语境和传统不同。

尤其不能使用：

```text
《黄帝内经》 → 导引 → 吐纳 → 现代观察研究
```

表示单线演化。

MEDOBS 当前仍被冻结，也不能被“养生路线”自动解锁。

### 4. 路线比较 / 路线演化关系

这两个文件应视为**研究分析文档**，不是独立历史实体。

其中“路线演化关系”旧版使用的多条箭头缺少关系类型和来源限定，需要立即降级为研究假说/导航说明，不能进入 V3 正式关系文件。

## 四、V3 类型决策

本轮决定：

| 旧对象 | 当前处理 | V3 候选类型 |
| --- | --- | --- |
| 筑基 | 待限定具体内丹体系后迁移 | `stage` |
| 精气神 | 从“阶段”纠正为概念组合 | `concept` |
| 性命双修 | 从“阶段”纠正为理论原则 | `concept` |
| 清修路线 | 保留为项目导航 | 暂不进入正式 `route` |
| 内丹路线 | 保留为项目导航 | 暂不进入正式 `route` |
| 养生路线 | 保留为项目导航 | 暂不进入正式 `route` |
| 路线比较 | 分析文档 | 非实体节点 |
| 路线演化关系 | 改为假说/审计文档 | 非实体节点 |

## 五、为什么不立即使用 `route`

V3 的 `route` 顶层类型目前没有进一步区分：

- 历史传统路线；
- 某一文本明确给出的实践次第；
- 某一宗派的训练课程；
- 问道志为了阅读方便制作的研究导航。

在新增 `route_kind` 或等价字段之前，把三条现代整理路线直接加入 V3 会重新制造语义混乱。

因此本轮宁可保留 legacy，也不制造“看起来结构化、实际语义错误”的正式数据。

## 六、下一步

1. 为 `stage.zhuji` 补具体内丹体系与来源；
2. 把“精气神”迁移到 `23-核心概念网络/`，建立 `concept.jingqishen`；
3. 把“性命双修”迁移到概念层，建立 `concept.xingming_shuangxiu`；
4. 设计 `route_kind` 后再判断三条研究路线是否需要成为机器节点；
5. 所有路线箭头都必须转换成已有规范关系，或明确标成“研究导航”，不得直接进入历史关系数据。
