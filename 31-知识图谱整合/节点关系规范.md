# 节点关系规范

## 一、目的

问道志的知识图谱不能只表达“两个节点有关”，还必须说明：

- 是什么关系；
- 关系适用于哪个时代、文本或传统；
- 关系依据是什么；
- 是否存在争议；
- 是否暗含历史方向或因果。

本规范用于避免把知识导航图误写成师承链、发展链或修炼步骤。

## 二、节点类型

当前允许：

- `classic`：经典
- `person`：人物
- `school`：流派或传统分类
- `concept`：概念
- `method`：方法
- `stage`：阶段
- `route`：路线
- `research`：研究与专题

`school` 作为迁移期兼容顶层类型，必须配合 `school_kind` 区分思想传统、宗教宗派、宗教传统、修炼传统等不同性质对象。

## 三、关系通用结构

```yaml
- target: concept.jing
  relation: related_to
  scope: 《道德经》第十六章虚静并提语境
  evidence: A
  source_refs:
    - source.daodejing.16
```

必填或强烈建议字段：

- `target`：目标节点；
- `relation`：关系类型；
- `scope`：适用范围；
- `evidence`：证据等级；
- `source_refs`：来源引用。

若关系存在明显争议，应增加争议卡或使用 `disputed_relation`。

## 四、第一阶段核心关系类型

### 1. `related_to`

一般关联。

特点：

- 通常视为语义上的对称关系；
- 不表示时间先后；
- 不表示师承；
- 不表示因果；
- 不表示修炼步骤。

### 2. `source_of`

直接文本或材料来源关系，具有方向。

### 3. `authored`

人物与作品的较确定著作关系。

使用条件：

- 现有历史研究对作者关系相对稳定；
- 即使文本后来有增补，也能较可靠地确认核心作品与该人物的作者关系。

不得使用 `authored` 抹平传统托名或复杂文本形成史。

### 4. `traditional_attribution`

传统作者归属、托名或后世归属关系，具有方向。

适用于传统长期归于某人物，但现代研究对作者、年代或文本形成存在明显争议的情形。

例如：

```text
老子 traditional_attribution 《道德经》
庄子 traditional_attribution 今本《庄子》
魏伯阳 traditional_attribution 《周易参同契》
```

### 5. `founded`

人物与较明确历史宗教组织、教团或运动的创建关系，具有方向。

使用条件：

- 有可靠历史研究支持该人物在相关运动形成中具有创建者地位；
- 目标必须主要是 `religious_order` 或能够明确识别的历史组织/运动；
- 不用于现代思想史分类和宽泛修炼传统。

例如：

```text
王重阳 founded 全真道
```

不得写成：

```text
老子 founded 先秦道家
魏伯阳 founded 丹鼎派
```

因为前者是后起思想史分类，后者是跨时代炼丹传统/分类标签，并非可直接证明的单一历史组织。

### 6. `influences`

思想影响关系，具有方向。必须有历史材料或可靠研究支持，不能因为概念相似就建立。

### 7. `develops`

历史发展或理论展开关系，具有方向，是高风险关系。不得把方便理解的知识导航直接写成发展链。

### 8. `belongs_to`

归属或分类关系，具有方向。需要注意分类的时代性，现代研究分类不自动等于历史人物自我认同。

### 9. `contains`

体系包含关系，具有方向。不用于表达“受到影响”或“经常一起出现”。

### 10. `practices`

人物、流派或传统与某方法的明确实践关系。要求有具体材料。

### 11. `contrasts_with`

对比关系，通常视为对称。

### 12. `disputed_relation`

关系本身存在争议时使用，必须链接相应争议材料。

## 五、关系方向规则

### 对称关系

第一阶段视为对称：

- `related_to`
- `contrasts_with`

数据层只需保存一条规范边，构建时生成双向导航。

### 有向关系

第一阶段视为有向：

- `source_of`
- `authored`
- `traditional_attribution`
- `founded`
- `influences`
- `develops`
- `belongs_to`
- `contains`
- `practices`

反向导航由程序生成，不人工创造一个意义不同但没有定义的反向关系。

## 六、历史链与知识导航必须分开

以下表达只适合知识导航：

```text
《道德经》 → 虚 → 静 → 心斋 → 坐忘
```

它不能自动解释为历史因果、固定步骤或连续师承。

正文中的箭头图必须注明性质：

- 知识导航；
- 历史发展；
- 文本来源；
- 实践步骤；
- 假说。

若未注明，默认只能视为“知识导航”。

## 七、证据等级不是关系强度的万能排序

A级原始文献适合回答“传统文本怎么说”；B级历史研究适合回答“不同文本、人物或流派之间历史上是什么关系”；E级现代研究适合回答“现代可测现象是什么”。

不能简单理解为 A 到 E 在所有问题上构成强弱排序。

## 八、流派与传统关系的额外规则

使用 `school` 节点时必须先判断 `school_kind`：

- `intellectual_tradition` 不自动拥有创建者、组织谱系或固定成员；
- `religious_order` 可以在证据充分时使用 `founded`、`belongs_to`、`practices`；
- `religious_tradition` 往往跨越多个组织阶段，应谨慎使用单一创建关系；
- `practice_tradition` 主要用于炼养、技术和修炼史，不应伪装成单一教团；
- `historiographic_category` 必须明确这是研究分类，而非历史自称。

因此：

```text
王重阳 founded 全真道
```

可以成立；而：

```text
老子 founded 先秦道家
张伯端 founded 丹鼎派
```

均不应建立。

## 九、核心概念关系的第一阶段处理

七个核心概念第一阶段优先使用 `related_to`，只有明确文本或历史证据时才升级为更强关系。

## 十、发布前关系检查

- [ ] 是否把一般关联误写成影响或发展？
- [ ] 是否把知识导航误写成历史传承？
- [ ] 是否把传统归属误写成无争议作者关系？
- [ ] 是否把思想史分类误写成有创建者的宗派？
- [ ] 是否把后世解释反读进早期经典？
- [ ] 是否说明适用时期和传统？
- [ ] 是否有具体来源？
- [ ] 对称关系是否被重复维护？
- [ ] 争议关系是否进入争议层？
- [ ] 方法关系是否被误写成固定练习步骤？
