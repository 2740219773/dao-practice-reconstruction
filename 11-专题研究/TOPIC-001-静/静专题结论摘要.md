## 一、这个概念是什么

"静"在先秦道家文献（《道德经》《庄子》）、汉代至唐代道教文献（《管子·内业》《坐忘论》）中是**少扰动的多义组合**（TOPIC-001-C06）：它既指环境与心念的状态，也指修炼过程中的方法与目标。

核心：**兼有过程义与结果义**（TOPIC-001-C01）——"守静笃"（过程，主动保持）与"归根曰静"（结果，复归本根）并存，两者不互斥。

---

## 二、它不是什么

- **不是"完全没有念头"**（TOPIC-001-C02）：已建文献无一处以"消灭念头"定义"静"；《坐忘论》收心篇明确批评"心起皆灭，永断知觉，入于盲定"，主张"息乱而不灭照"。思维减弱是**减少而非清零**。
- **不是具体的静坐姿势或呼吸操作**（TOPIC-001-C03）：文献未规定姿势；"心静气理"（管子·内业）是心静与气条理的状态关联，不是调息指令。
- **不是现代冥想/正念的等价物**（TOPIC-001-C04）：现代研究不能直接证明传统"静"的机制；也不等于禅定、放松训练、α 脑波等现代概念。
- **不是身体或能量的神秘操作**：不把"归根"解释为具体身体操作；不把异常体验解释为"突破/排病/境界"。

## 三、当前可以确认什么

| 结论编号 | 内容 |
| ---- | ---- |
| TOPIC-001-C01 | "静"兼有过程义与结果义（原文-0001"守静笃"＋"归根曰静"直接支持） |
| TOPIC-001-C02 | 已建文献无"静=无念"定义；收心篇明确批评灭念（原文-0016 直接反证） |
| TOPIC-001-C03 | 先秦文献未展开"静"的具体操作方法；操作体系化是后世（尤其《坐忘论》）的展开 |
| TOPIC-001-C05 | 压念有明确风险（风险资料-0001），与"静"的文献定义相悖 |

## 四、当前不能确认什么

- "静"在先秦是否有具体操作方法（原文未给步骤）；
- "静"是否等同于某种现代心理/生理状态（注意稳定等仅 M0 候选）；
- "归根"是否指身体层面的具体回归（语境以万物为对象）；
- 后世某些内丹或佛教影响文本是否含"灭念"表述（当前判定限定在已建文献范围）。

## 五、主要争议

| 争议 | 双方 | 项目立场 |
| ---- | ---- | ---- |
| 静是状态还是方法（Q1） | 方法义 vs 状态义 | 过程义与结果义并存（C01）；先秦方法未展开（C03） |
| 静是否等于无念（Q2） | 近现代"入静即无念" vs 文献无此定义 | 当前不支持（C02） |
| 静与虚是否同一回事 | 互文同义 vs 各有侧重 | 暂取各有侧重（虚清除、静安定），待虚概念卡建立后核对 |
| 守静能否直接作为静坐方法 | 可操作 vs 原则性表述 | 先秦未展开操作（C03），不写成操作教程 |
| 归根是否身体回归 | 宇宙论 vs 养生层面 | 暂不解释为具体身体操作 |
