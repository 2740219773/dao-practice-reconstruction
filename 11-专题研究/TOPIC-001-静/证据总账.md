## 二、Q1：静是过程、方法还是结果状态？

### 2.1 判断结论

> **暂定结论（争议-0001 观点三，过程义与结果义并存）：** 先秦文献中"静"同时承担方法/过程义（守静、致静）与状态/结果义（归根曰静），两者不互斥；但"方法"的具体操作内容先秦未展开，操作体系化是后世（尤其《坐忘论》）的展开，不能读回先秦。

| 依据编号 | 依据类型 | 支持内容 | 支持方向 | 证据强度 |
| ---- | ---- | ---- | ---- | ---- |
| 原文-0001 | 原文（道德经·十六章） | "致虚极，守静笃"——"守""笃"为主动语态，支持过程/方法义 | 方法义 | 直接（T2） |
| 原文-0001 | 原文（道德经·十六章） | "归根曰静，是谓复命"——"静"为万物复归的结果 | 结果义 | 直接（T2） |
| 原文-0005 | 原文（庄子·心斋） | "若一志"含准备性操作表述，先秦并非完全没有实践语境 | 方法义（弱） | 直接（T2） |

- 郭店楚简本《老子》"静"相关句段对本题的参考价值——待核对（TEXT-001-B）；
- 结论不升级：在底本实物复核完成前，Q1 结论维持"暂定"。

## 三、Q2：静是否意味着完全没有念头？

### 3.1 判断结论

> **暂定结论（主张-0001：当前不支持）：** 在已建文献范围内（道德经、庄子、内业、坐忘论），**没有任何一处以"消灭念头"定义"静"**；《坐忘论》收心篇反而明确批评灭念式静坐。项目约定：不把"静"定义为"脑子里没有念头"。

### 3.2 支持证据清单（对"静≠无念"的支持）

| 依据编号 | 依据类型 | 支持内容 | 支持方向 | 证据强度 |
| ---- | ---- | ---- | ---- | ---- |
| 原文-0016 | 原文（坐忘论·收心） | "若心起皆灭，不简是非，永断知觉，入于盲定"——明确批评灭念；"息乱而不灭照，守静而不着空"——主张保留觉照 | 直接反证"静=无念" | 直接（T2，网络文本已核对） |
| 原文-0001 | 原文（道德经·十六章） | "致虚极，守静笃""归根曰静"语境为复归与观察，非灭念 | 文本语境 | 直接（T2） |
| 原文-0005 | 原文（庄子·心斋） | "一志"是收束心志，"听之以气"是转换感知方式，非压灭念头 | 文本语境 | 直接（T2） |
| 原文-0006 | 原文（庄子·坐忘） | "离形去知"是放下执取与智识，非消灭念头 | 文本语境 | 直接（T2） |
| 原文-0009 | 原文（管子·内业） | "心静气理"为状态描述与心气关联，无压念含义 | 文本语境 | 直接（T2） |

### 3.3 反对证据清单（对"静=无念"的可能支持，均已核为误读）

| 依据编号 | 依据类型 | 字面内容 | 核读结论 |
| ---- | ---- | ---- | ---- |
| 原文-0006 | 原文（误读） | "堕肢体，黜聪明，离形去知"字面似"清除心智活动" | 原文语境是"忘"（放下执取）而非灭念 |
| 原文-0005 | 原文（误读） | "若一志""听之以气"字面似压念操作 | 原文语境是收束心志与转换感知 |
| 原文-0016 | 原文（误读） | "守根不离，名曰静定"或可被读作压制 | 原文"静定"为守根不离（与道相合），非压念 |

### 3.4 现代研究限定（Q2 相关风险面）

| 依据编号 | 现代证据等级 | 限定内容 |
| ---- | ---- | ---- |
| 现代研究-0004 | E3 | 冥想相关挑战体验有类型学（Lindahl 2017），部分体验含"念头增多/情绪波动"——提示强制控制念头可能带来负面体验 |
| 现代研究-0005 | E3 | 美国人口样本冥想不良反应（Goldberg 2021）——不良反应存在，但发生率随定义/设计变化 |
| 现代研究-0014 | E3 | 不良反应是定义与测量工具的函数（同批样本 6%—83%，Britton 2021）——引用任何发生率必须注明定义 |
| 现代研究-0015 | E2 | 不良事件发生率随研究设计变化约 9 倍（实验 3.7% vs 观察 33.2%，Farias 2020）——不能以单一数字当作一般结论 |

> 现代研究的作用：**限定风险面表述**，防止"静坐必然带来异常体验"或"灭念无害"等无依据说法；不用于证明"静=无念"或"静≠无念"的传统文本结论（Q2 是文本判断，现代研究只作风险提示）。

### 3.5 附加限定（概念-0001 第 11 节）

- "静"不能等同于"大脑无念/放空"——近现代传播简化，项目明确排除；
- "静"的"思维减弱"义（八义第 5 义）是**减少而非清零**；
- 风险层面：若把"静"实践为强行压念，可能致紧张、疲惫或对"念头多"的焦虑（主张-0001 第 9 节风险分析）。
