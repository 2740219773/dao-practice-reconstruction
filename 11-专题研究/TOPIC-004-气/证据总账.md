## 二、Q1：“气”能否用单一定义概括？

### 2.1 当前判断（TOPIC-004-C01）

> 当前最稳妥的处理不是先回答“气究竟是什么东西”，而是逐文本记录“气在这里做什么、和什么发生关系、组合成什么词”。
>
> 本项目采用多角色分析框架，但不把它写成古人的统一气论。

### 2.2 支持证据

| 依据 | 文本 | 当前可支持的最小判断 |
| ---- | ---- | ---- |
| 原文-0002 | “专气致柔” | 气进入“专—致柔”结构；“专”存在王弼/河上公解释竞争 |
| 原文-0004 | “心使气曰强” | 气进入心—使—气关系结构 |
| 原文-0005 | “听之以气”“气也者，虚而待物者也” | 心斋语境中“气”参与听/虚待结构 |
| 原文-0007 | “凡物之精……此气也……不可止以力，而可安以德” | “气”与精、生、天地/胸中、德等连续出现 |
| 原文-0009 | “心静气理，道乃可止” | “气理”与心静、道关系相连 |
| 原文-0010 | “精也者，气之精者也” | 《内业》内部明确给出精—气关系 |
| 原文-0011 | 善气/恶气、心气、搏气、精气、血气 | 同篇长段中出现多种含“气”复合/关系表达 |

### 2.3 限定

- 同一个“气”字出现，不等于每处都指同一实体；
- 复合词中的“气”不能脱离整个词直接定义；
- 《内业》的密集气论不能自动覆盖《老子》《庄子》；
- 本专题未纳入医学、内丹等后世体系，不能宣称已经得到完整“中国传统气”的定义；
- 阶段4现代人文研究只能证明“解释需要复杂化”，不能替代原文释义。

### 2.4 Q1结论

采用C01，多角色优先。概念-0004已在阶段3撤回旧稿“七义=既定分类”的强度，改为逐文本角色组织。

## 三、Q2：“气”是不是呼吸、氧气、能量或气感？

### 3.1 当前判断（TOPIC-004-C02）

> **当前材料不足以支持任何直接等号。**
>
> “气”可以在某些历史语境与呼吸、生命、身体状态等发生联系，但“可能相关”不等于“就是”。本专题不使用现代科学术语替代古文词义。

### 3.2 对直接等同的限制

| 现代/后起说法 | 当前判断 | 原因 |
| ---- | ---- | ---- |
| 气 = 呼吸 | 当前不支持直接等同 | 冻结材料中大量用法并非可由“呼吸”一词无损替换 |
| 气 = 空气/氧气 | 当前不支持 | 属现代自然科学对象；原文未给出该定义 |
| 气 = 物理能量 | 当前不支持 | “能量”有现代严格定义，不能凭功能相似倒灌 |
| 气 = 能量场 | 当前不支持 | 冻结文本无此现代概念 |
| 气 = 主观气感 | 当前不支持 | 个体体验不能反向确定经典词义 |

### 3.3 阶段4回读

王弼、河上公对“专气”本身就给出不同解释；郭象/成玄英处理心斋之“气”时也没有把它统一成呼吸或空气；刘绩《内业》注释则把气放在德、心静、精、形色等多种关系中。

因此阶段4没有发现任何材料足以把C02升级成某一现代对应。

### 3.4 与TOPIC-005“息”的边界

本专题只建立：**不能先把“气=息/呼吸”写成等式。**

“息”在传统文本中的具体含义、气与息何时相关、何时分离，移交TOPIC-005，不在这里提前完成。

## 四、Q3：“心—气”是不是控制关系？

### 4.1 当前判断（TOPIC-004-C03）

> 当前不支持“心控制气/以意领气”作为冻结文本的统一机制。

### 4.2 直接证据

| 依据 | 文本 | 对控制模型的影响 |
| ---- | ---- | ---- |
| 原文-0004 | “心使气曰强” | “使气”并未作为正面技术目标；TOPIC-003阶段4王弼注进一步限制技术化读法 |
| 原文-0007 | “此气也，不可止以力，而可安以德” | 直接反限“以力控制/强制停止”的简单模型 |
| 原文-0009 | “心静气理，道乃可止” | 呈现心静—气理—道止关系，但不自动等于主动控制命令 |
| 原文-0005 | “无听之以心而听之以气” | 心斋结构从“以心”转向“以气”，不符合单向心指挥气模型 |

### 4.3 阶段4解释层增强

- 王弼第十章把“专”释为“任”，使“专气”不能被简单归入主动控制范式；
- 刘绩把“心静气理”注为“气自调理”，并把“不可止以力”解释为用力反而不能止；
- 郭象/成玄英心斋注疏继续把该处“气”放在虚待与任气性自得的解释层中。

这些都不是现代机制证明，但共同加强了C03的反限。

### 4.4 与TOPIC-003的关系

TOPIC-003-C03已冻结：“当前不支持心控制气/以意领气统一模型”。TOPIC-004继承这一边界并增加原文-0007与阶段4注疏作为气专题自己的反限证据，但**不修改TOPIC-003-C03**。

### 4.5 不允许的推论

- 不从“心静气理”生成调息步骤；
- 不从“专气”生成聚气/导气方法；
- 不从“听之以气”生成气感观察方法；
- 不从“不可止以力”反推某种替代操作技术。

## 五、Q4：不同含“气”表述是否同一种“气”？

### 5.1 当前判断（TOPIC-004-C04）

> 可以比较，但不能先验合并。阶段4已经证明，即使同一短语内部也存在传统注释或文本解释竞争。

### 5.2 当前分层

| 表述 | 文本 | 当前最小定位 |
| ---- | ---- | ---- |
| 专气 | 道德经10章 | 王弼“专=任”与河上公“专守精气”形成真实解释竞争；见争议-0009 |
| 使气 | 道德经55章 | 与心、强相连的限制性语境 |
| 听之以气 | 庄子·心斋 | 心斋听/虚待结构中的“气”；郭象/成玄英注疏只作解释层 |
| 此气 | 管子·内业 | 与精、生、德连续的语境 |
| 气理 | 管子·内业 | 与心静、道止相连；刘绩释“气自调理” |
| 善气/恶气 | 管子·内业 | 与迎人、亲/害、形容肤色等社会表现语境相连 |
| 搏气 | 管子·内业 | 刘绩释“结聚”，同时记录《心术》平行文本作“专”；见争议-0010 |
| 精气 | 管子·内业 | 与“精气之极”相关；不自动等于后世内丹三宝 |
| 血气 | 管子·内业 | “四体既正，血气既静”复合语境 |

### 5.3 关键边界

- “善气/恶气”不翻译成“正能量/负能量”；
- “血气”不拆解成“血液+能量”；
- “搏气”不写成已经确定的聚气技术；
- “听之以气”不翻译成“听呼吸”或“感受内气”；
- 《内业》的“精气”不自动等于后世内丹“精气神”。

### 5.4 阶段4结论

C04从“待训释”推进为“解释竞争已确认”：

- “专气”存在王弼/河上公不同注释；
- “搏气”存在刘绩“结聚”与平行《心术》“专”线索；
- 现代《管子》研究也把道、气、精气关系视为需要专门辨析的问题。

这加强逐文本处理的必要性，但不产生新的C06。

## 六、《内业》“精—气”关系（TOPIC-004-C05）

### 6.1 当前判断

原文-0010“精也者，气之精者也”是本专题少数可以直接确认的关系句。

当前允许表述：

> 在《内业》这一具体文本语境中，“精”被表述为“气之精者”，说明文本内部对精与气作了内在关联。

刘绩进一步解释“气之尤精者为之精”，属于后世注释层。

### 6.2 当前不允许扩写

- “所有道家都认为精是气的浓缩”；
- “精气神三宝理论在《内业》已经完整形成”；
- “炼精化气就是这一句的实践应用”；
- “精、气对应某两种现代物质/能量形态”。

原文-0011“精气之极”可作为相关语境，但不能单独把后世体系读回先秦。

### 6.3 阶段4现代研究限定

现代《管子》气论研究会建立更完整的道—气/精气结构解释，但这些属于学术理论建构，不能替换“精也者，气之精者也”本身的直接证据层。

因此C05维持“有限支持 + 历史限定”。
