## 二、Q1：“气”能否用单一定义概括？

### 2.1 当前判断（TOPIC-004-C01）

> 当前最稳妥的处理不是先回答“气究竟是什么东西”，而是逐文本记录“气在这里做什么、和什么发生关系、组合成什么词”。
>
> 本项目采用多角色分析框架，但不把它写成古人的统一气论。

### 2.2 支持证据

| 依据 | 文本 | 当前可支持的最小判断 |
| ---- | ---- | ---- |
| 原文-0002 | “专气致柔” | 气进入“专—致柔”结构；具体“专”义需解释层 |
| 原文-0004 | “心使气曰强” | 气进入心—使—气关系结构 |
| 原文-0005 | “听之以气”“气也者，虚而待物者也” | 心斋语境中“气”参与听/虚待结构 |
| 原文-0007 | “凡物之精……此气也……不可止以力，而可安以德” | “气”与精、生、天地/胸中、德等连续出现 |
| 原文-0009 | “心静气理，道乃可止” | “气理”与心静、道关系相连 |
| 原文-0010 | “精也者，气之精者也” | 《内业》内部明确给出精—气关系 |
| 原文-0011 | 善气/恶气、心气、搏气、精气、血气 | 同篇同段中出现多种含“气”复合/关系表达 |

### 2.3 限定

- 同一个“气”字出现，不等于每处都指同一实体；
- 复合词中的“气”不能脱离整个词直接定义；
- 《内业》的密集气论不能自动覆盖《老子》《庄子》；
- 本专题未纳入医学、内丹等后世体系，不能宣称已经得到完整“中国传统气”的定义。

### 2.4 Q1结论

采用C01，多角色优先；阶段3重构概念-0004时撤回旧稿“七义=既定分类”的强度，重新按证据分层。

## 三、Q2：“气”是不是呼吸、氧气、能量或气感？

### 3.1 当前判断（TOPIC-004-C02）

> **当前材料不足以支持任何直接等号。**
>
> “气”可以在某些历史语境与呼吸、生命、身体状态等发生联系，但“可能相关”不等于“就是”。本专题尤其不使用现代科学术语替代古文词义。

### 3.2 对直接等同的限制

| 现代/后起说法 | 当前判断 | 原因 |
| ---- | ---- | ---- |
| 气 = 呼吸 | 当前不支持直接等同 | 冻结材料中大量用法并非可由“呼吸”一词无损替换 |
| 气 = 空气/氧气 | 当前不支持 | 属现代自然科学对象；原文未给出该定义 |
| 气 = 物理能量 | 当前不支持 | “能量”有现代严格定义，不能凭功能相似倒灌 |
| 气 = 能量场 | 当前不支持 | 冻结文本无此现代概念 |
| 气 = 主观气感 | 当前不支持 | 个体体验不能反向确定经典词义 |

### 3.3 与TOPIC-005“息”的边界

本专题只建立：**不能先把“气=息/呼吸”写成等式。**

“息”在传统文本中的具体含义、气与息何时相关、何时分离，移交TOPIC-005，不在这里提前完成。

## 四、Q3：“心—气”是不是控制关系？

### 4.1 当前判断（TOPIC-004-C03）

> 当前不支持“心控制气/以意领气”作为冻结文本的统一机制。

### 4.2 直接证据

| 依据 | 文本 | 对控制模型的影响 |
| ---- | ---- | ---- |
| 原文-0004 | “心使气曰强” | “使气”并未作为正面技术目标；TOPIC-003阶段4王弼注进一步限制技术化读法 |
| 原文-0007 | “此气也，不可止以力，而可安以德” | 直接反限“以力控制/强制停止”的简单模型 |
| 原文-0009 | “心静气理，道乃可止” | 呈现心静—气理—道止关系，但不自动等于主动控制命令 |
| 原文-0005 | “无听之以心而听之以气” | 心斋结构甚至从“以心”转向“以气”，不符合单向心指挥气模型 |

### 4.3 与TOPIC-003的关系

TOPIC-003-C03已经冻结：“当前不支持心控制气/以意领气统一模型”。TOPIC-004继承这一边界并增加原文-0007作为气专题自身的反限证据，但**不修改TOPIC-003-C03**。

### 4.4 不允许的推论

- 不从“心静气理”生成调息步骤；
- 不从“专气”生成聚气/导气方法；
- 不从“听之以气”生成气感观察方法；
- 不从“不可止以力”反推某种替代操作技术。

## 五、Q4：不同含“气”表述是否同一种“气”？

### 5.1 当前判断（TOPIC-004-C04）

> 可以比较，但在逐文本解释完成前不能合并。

### 5.2 当前分层

| 表述 | 文本 | 当前最小定位 |
| ---- | ---- | ---- |
| 专气 | 道德经10章 | “专气致柔”结构；王弼释“专=任”进入阶段4 |
| 使气 | 道德经55章 | 与心、强相连的限制性语境 |
| 听之以气 | 庄子·心斋 | 心斋听/虚待结构中的“气” |
| 此气 | 管子·内业 | 与精、生、德连续的语境 |
| 气理 | 管子·内业 | 与心静、道止相连 |
| 善气/恶气 | 管子·内业 | 与迎人、亲/害等社会表现语境相连 |
| 搏气 | 管子·内业 | “搏/抟”训释待阶段4 |
| 精气 | 管子·内业 | 与“精气之极”相关 |
| 血气 | 管子·内业 | “四体既正，血气既静”复合语境 |

### 5.3 关键边界

- “善气/恶气”不翻译成“正能量/负能量”；
- “血气”不拆解成“血液+能量”；
- “搏气”不在训释未清前写成“聚气技术”；
- “听之以气”不翻译成“听呼吸”或“感受内气”；
- 《内业》的“精气”不自动等于后世内丹“精气神”。

## 六、《内业》“精—气”关系（TOPIC-004-C05）

### 6.1 当前判断

原文-0010“精也者，气之精者也”是本专题少数可以直接确认的关系句。

当前允许表述：

> 在《内业》这一具体文本语境中，“精”被表述为“气之精者”，说明作者/文本系统对精与气作了内在关联。

当前不允许扩写为：

- “所有道家都认为精是气的浓缩”；
- “精气神三宝理论在《内业》已经完整形成”；
- “炼精化气就是这一句的实践应用”；
- “精、气对应某两种现代物质/能量形态”。

原文-0011“精气之极”可作为相关语境，但不能单独把后世体系读回先秦。

## 七、阶段2证据缺口与阶段3/4待核

1. **“专”字：** 王弼释“专=任”已见；需阶段4比较其他重要训释，不能单凭现代字面“专注”定义；
2. **“搏气”：** 搏/抟等校勘与训释需要黎翔凤及相关校释；
3. **“善气/恶气”：** 需要解释其在《内业》语境究竟偏气象、态度、形色还是综合表现，不先现代化；
4. **“精气”：** 需区分《内业》内部用法与后世精气神体系；
5. **气—息：** 本专题只定“不直接等同”边界，完整关系留TOPIC-005；
6. **现代对应：** 如阶段4引入现代研究，只用于说明对应限制，不能证明传统机制。

## 八、批次一阶段2结论

当前C01—C05已足够进入阶段3，不需要增加核心文献或原文：
