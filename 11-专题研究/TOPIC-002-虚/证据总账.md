## 二、Q1：“虚”主要是什么意思？（C01）

### 2.1 当前处理

不寻找一个覆盖所有文本的唯一词典定义，而按语境分组。五义是项目分析框架，不是古人使用的分类。

### 2.2 支持证据

| 依据 | 语境 | 支持方向 | 强度/限定 |
| ---- | ---- | -------- | --------- |
| 原文-0020 道德经5章 | “虚而不屈，动而愈出” | 器之空/功能性中空 | 直接（T2） |
| 原文-0019 道德经3章 | “虚其心，实其腹” | 心之清空候选/主动使动 | 直接；首先为治民语境 |
| 原文-0005 庄子心斋 | “虚而待物”“唯道集虚。虚者心斋也” | 心斋/道之虚 | 直接（T2） |
| 原文-0023 管子·心术上 | “虚其欲，神将入舍” | 心性条件/主动表达 | 直接；关键补充文献 |
| 原文-0001 道德经16章 | “致虚极” | 方法/过程/完成态候选 | 直接（T2） |
| 原文-0016 坐忘论 | “自入虚无”“名曰虚心” | 后世方法/状态体系 | 直接；唐代 |
| 原文-0018 坐忘论 | “虚静至极” | 完成态候选 | 直接；唐代 |

### 2.3 限定

- 《内业》当前核对文本未见“虚”字直接出现，只能说明该篇选词，不推出黄老传统整体结论；
- “虚其心”首先是治民语境，不直接写成个人修炼步骤；
- 五义名称中的“清空、方法、过程、结果”等均是项目整理语言。

## 三、Q2：“虚”是否等于什么都没有？（C02）

### 3.1 当前判断

当前不支持“虚=绝对空无/意识空白”。

### 3.2 支持与限制材料

| 依据 | 文本现象 | 对C02的作用 |
| ---- | -------- | ----------- |
| 原文-0020 | 虚而不屈、动而愈出 | 虚与作用并存，限制“绝对空无” |
| 原文-0005 | 虚而待物 | 虚与“待物”并存，限制“什么都没有” |
| 原文-0018 | 虚静至极则道居而慧生 | 虚静之后仍有“慧生”表述，限制“意识空白” |
| 原文-0016 | 守静而不着空 | 建立文本中的“空”边界，但不自动等同佛教空性 |
| Machek 2016 | 将Zhuangzi的“empty/xu”解释为“不被固定结构化的自我” | 现代解释候选，与C02相容，但不证明古义 |

### 3.3 不采用的改写

- “虚就是没有任何念头”；
- “虚就是无意识”；
- “虚就是现代心理学的开放注意”；
- “虚就是佛教空性”。

## 四、Q3：“致虚”是方法、过程还是结果？（C03）

### 4.1 当前判断

“致虚”可从主动达到、过程与完成态分析；只限定于当前材料说“尚未见完整明确的先秦操作流程”，不外推成“先秦不存在相关实践”。

### 4.2 证据

| 依据 | 内容 | 作用 |
| ---- | ---- | ---- |
| 原文-0001 | “致虚极” | “致”提供主动达到/过程分析基础 |
| 原文-0019 | “虚其心” | 主动使动表达；治民语境限定 |
| 原文-0023 | “虚其欲” | 主动表达；关键补充文献 |
| 原文-0016 | “住无所有，不着一物，自入虚无” | 后世更系统操作化展开 |
| 原文-0018 | “虚静至极” | 完成态候选 |
| 王弼注16章 | 注释“致虚/守静”，但未给固定操作链 | 解释层限定：不能以王注补出先秦技术流程 |
| 张彩拢2010（摘要级） | 专门比较庄子坐忘与司马承祯坐忘论异同 | 方向性支持历史分层，不承担细节结论 |

### 4.3 边界

- 不把《坐忘论》七层/心法直接读回《道德经》或《庄子》；
- 不写“致虚=具体冥想技术”；
- 不从文本研究转成练习教程。

## 五、Q4之一：“虚”与“静”（C04）

### 5.1 原文层

- 原文-0001：“致虚极，守静笃”——同句并列；
- 原文-0005：心斋明确使用“虚”；
- 原文-0009：《内业》有“静”直接用例，当前检索未见“虚”字；
- 原文-0018：《坐忘论》“虚静至极”——后世合用。

### 5.2 注疏层（阶段4新增）

王弼对16章分别注“致虚”“守静”，随后又说“以虚静观其反复”“卒复归于虚静”。

**能支持：** 虚静关系紧密，同时存在分别解释的空间。

**不能支持：** 王弼没有提出“虚=清除/容纳、静=安定/少扰”这一现代二分公式。

### 5.3 当前结论

因此 C04 **维持项目分析框架，不升级历史结论**：

> 为组织材料暂用“虚偏清除/容纳、静偏安定/少扰”，但公开时必须标注“工作性区分”。

概念-0001暂不回写成更强的古义断言。

## 六、Q4之二：“虚”与“无、冲、空”（C05）

### 6.1 “无”

原文-0021“有之以为利，无之以为用”说明“无”有自己的文本语境。本专题只据此限制“虚=无”的简单替换，不展开“有无”本体论。

### 6.2 “冲”（阶段4完成第一轮训诂核对）

朱谦之《老子道德经校释》对“冲/盅”指出：古本有“盅”，并引《说文》“盅，器虚也”；对45章“大盈若冲”作“大盈若虚”的训诂说明。

**更新后的边界：**

- 可以说45章这一具体“冲”字有“盅/器虚”的训诂依据；
- 不可进一步说“冲”和“虚在所有道家文本中完全同义”；
- 训诂关联不等于哲学概念无条件互换。

### 6.3 “空”

原文-0016“守静而不着空”只能证明《坐忘论》文本中存在“空”的边界性表述。

本专题不以一句“不着空”承担完整道佛概念比较，也不展开佛教空性史。

## 七、C06：心斋、“若一志”与操作化边界

### 7.1 原文层

原文-0005直接包含：“若一志”“虚而待物”“唯道集虚。虚者心斋也”。

原文-0023《心术上》“虚其欲，神将入舍”作为关键补充比较材料，不预设同构。

### 7.2 郭象/成玄英注疏（阶段4新增）

- “若一志”：郭象注“去异端而任独也”；成玄英疏释为一其志心、无复异端；
- “虚而待物”：郭象注强调遗耳目、去心意而任气性自得；
- “唯道集虚”：郭象注“虚其心则至道集于怀也”，成玄英亦以虚心解释。

### 7.3 能说到哪里

**可以说：**

- 传统注疏并不把“若一志”解释成“什么都不想”，而强调去异端、志趋一；
- 心斋注疏把“虚”与待物、自得、虚心、道集联系起来；
- 因而“心斋=意识空白/把所有念头压掉”缺乏文本与注疏支持。

**仍不能说：**

- “若一志”已经被证明等于现代“注意集中”；
- “若一志”与心理学的thought suppression（思想压制）机制已经证明不同；
- 心斋是一种经现代心理学验证的情绪调节技术。

### 7.4 现代研究反限

- Machek 2016把Zhuangzi的“empty/xu”用于“不被固定结构化的自我”解释；
- Q. Li 2025在心斋的情感/心理意义上与Machek等研究提出不同解读。

这些材料说明**现代解释存在竞争**，因此项目更不能选一个现代模型反写古义。
