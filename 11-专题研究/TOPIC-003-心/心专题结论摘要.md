## 一、这个概念是什么

在本专题冻结的《道德经》《庄子》《管子·内业》《坐忘论》中，“心”不能用一个现代词统一定义。它在不同文本中分别进入“虚、静、定、收、使气、听、止”等关系结构，并在唐代《坐忘论》中出现“一身之主”等更明确的主位表述。项目因此采用**多角色分析框架**，而不是给“心”建立跨时代统一实体定义（TOPIC-003-C01）。

## 二、它不是什么

- **不是“心脏、大脑、意识、注意力、执行功能”中的任何一个现代概念的直接古代同义词。** 这是解释边界，不是说传统文本完全排除身体器官含义（TOPIC-003-C05）。
- **不是“静”或“虚”的同义词。** 当前文本更适合逐条讨论“心静”“虚其心”“虚心”等不同结构（TOPIC-003-C02）。
- **不能统一概括成“心控制气/以意领气”。** 《道德经》《内业》《庄子》中的心—气关系并不相同（TOPIC-003-C03）。
- **不能把虚其心、心斋、一志、定心、收心、虚心、安心直接拼成一套跨时代方法。** 它们来自不同文本和历史层次（TOPIC-003-C04）。

## 三、当前可以确认什么

| 结论编号 | 当前处理 |
| ---- | ---- |
| TOPIC-003-C01 | 用多角色项目框架整理“心”；不采用覆盖全部文本的单一定义 |
| TOPIC-003-C02 | 心与静、虚关系密切，但必须逐文本表达，不能建立“心=静=虚”或固定流程 |
| TOPIC-003-C03 | 当前不支持“心控制气/以意领气”作为冻结文本的统一机制 |
| TOPIC-003-C04 | 心斋、定心、收心等可以比较，但不能先验合并成同一种方法 |
| TOPIC-003-C05 | 传统“心”与现代心脏/大脑/意识等概念只可做后续有限比较，不能直接等同 |

## 四、当前不能确认什么

- 不能确认“中国古代的心”有一个统一定义；本专题只覆盖四部冻结文献；
- 不能仅凭“凡心之刑/形”建立“心有固定形体”的历史结论；该处存在校勘与训释问题；
- 不能确认“心中之心”就是后世所谓本心、真心、元神或现代元认知；
- 不能从“心静气理”的语序直接证明某种生理因果机制；
- 不能把唐代《坐忘论》的收心结构反向当作先秦老庄、《内业》的共同操作程序。

## 五、主要争议

| 争议 | 主要解释竞争 | 项目当前处理 |
| ---- | ---- | ---- |
| 心与气是不是控制关系 | 主动控制模型 / 状态关系模型 / 逐文本多关系 | 采用逐文本多关系；不支持统一“控制”模型（C03） |
| 心斋、定心、收心是否同一种方法 | 连续传统模型 / 历史分层模型 | 保持历史分层，允许有限比较，不合并（C04） |
| “凡心之刑/形” | 刑=法 / 形体义等 | 保留校勘与训释问题，不据此建立实体定义 |
| “心中之心” | 本心/更深层之心/修辞层次等 | 保留解释竞争，不选择唯一实体模型 |

## 六、安全边界（摘要版）

本专题是 **A类纯知识研究**。可以解释文本中的“心”“心斋”“定心”“收心”等概念，但不把它们改写成练习教程。

重点防止两类误读转实践：

1. 把“心使气/心静气理”改写成意念控制呼吸、气机或身体能量的操作指令；
2. 把“收心/一志/虚心”改写成强制压制念头、追求意识空白的练习要求。

具体边界见 `心专题安全边界.md`。纸本底本复核完成前，公开状态继续维持“可公开草稿”。
