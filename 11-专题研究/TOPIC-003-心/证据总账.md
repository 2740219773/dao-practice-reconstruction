## 二、Q1：“心”主要承担哪些角色？

### 2.1 当前判断（TOPIC-003-C01）

> 当前最稳妥的做法不是先回答“心是什么”，而是先记录“心在不同文本里做什么、处在什么关系中”。
>
> 本项目暂用多角色框架整理材料，但不把这些角色合成一套古代统一心论。

### 2.2 支持证据

| 依据 | 文本 | 可支持的最小判断 | 证据强度 |
| ---- | ---- | ---- | ---- |
| 原文-0019 | 道德经3章“虚其心” | “心”可进入“虚其心”的使动结构；首先是治民语境 | 直接（T2） |
| 原文-0008 | 内业“凡心之刑，自充自盈……忧乐喜怒欲利……” | “心”与情欲扰动、安宁/和相关；“刑/形”仍待校 | 直接（T2，校勘限定） |
| 原文-0009 | 内业“心静气理，道乃可止” | “心”可被表述为“静”，并与气、道关系相连 | 直接（T2） |
| 原文-0010 | 内业“定心在中”“心以藏心”“心全于中” | “心”进入定、藏、全等多种结构 | 直接（T2，具体训释待核） |
| 原文-0004 | 道德经55章“心使气曰强” | “心”与气之间存在“使”关系表述 | 直接（T2） |
| 原文-0005 | 庄子心斋“听之以心”“心止于符” | “心”参与听/止语境，并在心斋转化结构中出现 | 直接（T2） |
| 原文-0016 | 坐忘论“夫心者，一身之主……”“收心离境” | 唐代文本明确赋予“心”主位并把它作为收/虚/安的对象 | 直接（T2；后世体系） |

### 2.3 反对/限定

| 限定 | 影响 |
| ---- | ---- |
| “凡心之刑/形”底本未最终核定 | 不能据0008建立“心有实体形体”之类结论 |
| 《坐忘论》为唐代系统化文本 | “一身之主”不能直接回读为先秦老庄/内业统一定义 |
| 《道德经》3章是“圣人之治”语境 | “虚其心”不能直接改成个人心法教程 |
| 本专题未纳入《孟子》《荀子》《黄帝内经》、佛教等 | 不能宣称本专题给出了“中国古代心”的完整定义 |

### 2.4 Q1结论

- 采用C01多角色项目框架；
- 暂不采用旧概念卡“心=思维、情绪、意志的统一主体”等覆盖性定义；
- 阶段3概念卡要从“定义心”改为“按冻结文本区分心的角色与关系”。

## 三、Q2：“心”与“静、虚”是什么关系？

### 3.1 当前判断（TOPIC-003-C02）

> 在冻结材料中，“静”“虚”经常围绕“心”出现，但不能写成“心=静=虚”。
>
> 更稳妥的是分别记录：心可以“静”、可以被“虚”，后世还出现“虚心”等命名；“心斋”又把“虚”置于心斋定义附近。关系密切，但句法、文本功能与历史层次并不相同。

### 3.2 支持证据

| 依据 | 文本 | 支持内容 |
| ---- | ---- | ---- |
| 原文-0019 | “虚其心” | 心是“虚”的对象；但治民语境限制个人修养化 |
| 原文-0009 | “心静气理” | “静”直接修饰/描述心 |
| 原文-0005 | 心斋“唯道集虚。虚者，心斋也” | “虚”是心斋核心表述，但不等于“心就是虚” |
| 原文-0016 | “心不受外，名曰虚心；心不逐外，名曰安心” | 后世文本明确形成“虚心/安心”命名 |
| TOPIC-001-C01/C06 | 静专题 | “静”有过程/结果与项目多义框架，不是单一实体概念 |
| TOPIC-002-C04 | 虚专题 | “虚—静”分工仅是项目工作性辨析，不能历史化 |

### 3.3 限定

- 不把TOPIC-001/002的项目分析框架变成TOPIC-003的上位定义；
- 不预设“虚是前置、静是结果、心是主体”这一固定三段式；
- “虚其心”与“虚心”来自不同文本/时期，不能因为现代汉语形式相近就视为同义结构。

### 3.4 Q2结论

C02维持“相关但不同层级”的暂定处理。阶段3如果建立“心—静—虚关系表”，必须逐文本列关系，不写统一流程箭头。

## 四、Q3：“心—气”能否理解为心控制气？

### 4.1 当前判断（TOPIC-003-C03）

> **当前不支持把冻结材料概括为“心控制气”。**
>
> 三个直接文本给出的关系并不相同：
>
> - 《道德经》：“心使气曰强”；
> - 《内业》：“心静气理，道乃可止”；
> - 《庄子·心斋》：“无听之以心而听之以气”。
>
> 这些材料至少说明“心—气”关系需要逐文本解释，而不是先套入“意念操控能量/呼吸”的现代模型。

### 4.2 支持证据

| 依据 | 关键文本 | 对简化“控制模型”的影响 |
| ---- | ---- | ---- |
| 原文-0004 | “心使气曰强” | “使气”被称为“强”，且后文接“物壮则老，谓之不道”；王弼注亦把“使气”放在需要警惕的语境中，不能直接正向技术化 |
| 原文-0009 | “心静气理，道乃可止” | 关系表现为“心静—气理—道止”，不是明确的主动操控命令 |
| 原文-0005 | “无听之以心而听之以气” | 心斋语境中甚至出现从“听之以心”转向“听之以气”，不符合单向“心指挥气”的简单模型 |

### 4.3 反对/限定

- “使”字的训诂、王弼注文与55章整体义需要阶段4继续核；
- “心静气理”是否表达因果、并行状态或修辞链，不能仅从语序断定机制；
- 心斋中的“气”不能直接等同呼吸、现代生理气体或所谓“能量”；
- 本专题不研究“气”的完整定义，相关问题移交后续气专题。

### 4.4 Q3结论

- 不采用“心控制气/以意领气”作为传统统一机制；
- 阶段3概念卡只能写“心与气在冻结文本中存在多种关系”；
- 所有操作化解释禁止进入本专题结论。

## 五、Q4：虚心、心斋、一志、定心、收心是否同一种方法？

### 5.1 当前判断（TOPIC-003-C04）

> 当前材料不支持把这些词拼成一套跨时代统一方法。
>
> 它们可以互相比较，但第一原则是保留文本身份与历史层次。

### 5.2 分文本证据

| 表述 | 文本 | 当前最小定位 |
| ---- | ---- | ---- |
| 虚其心 | 道德经3章 | 治民语境中的使动表达；是否个人修养义需旁证 |
| 一志 / 心斋 | 庄子·人间世 | 心斋对话中的过程性表述；注疏解释存在层次 |
| 定心在中 | 管子·内业 | 与耳目、四枝、精舍等结构相连的“定心”表述 |
| 收心离境 | 坐忘论·收心 | 唐代坐忘体系中的明确步骤性/体系性表述 |
| 虚心 / 安心 | 坐忘论·收心 | 对“心不受外/不逐外”的后世命名 |

### 5.3 直接限定

- 《坐忘论》不能作为先秦文本的操作手册；
- 《坐忘论》自身又明确出现“若心起皆灭……入于盲定”等反面表述，因此“收心”也不能简化成压掉全部念头；
- “虚其心”首先是治理排比语境；
- “定心在中”与“心斋”的文献结构不同；
- 相似词汇可以建立关系卡，但不能用现代“都是冥想/注意训练”直接合并。

### 5.4 Q4结论

C04暂定为“相似但不合并”。阶段3优先考虑建立解释竞争/辨析，而不是建立统一“心法流程”。

## 六、现代对应边界（TOPIC-003-C05）

### 6.1 项目规则

本专题不写：

- “古人的心就是大脑”；
- “传统心就是现代意识”；
- “心使气就是注意力调节自主神经”；
- “心以藏心就是元认知”；
- “收心就是抑制默认模式网络”。

这些都需要独立现代研究与对应论证，且即使存在主题相似，也不能倒推为传统原义。

### 6.2 允许的表达

> “心”在冻结文本中承担多种角色；现代概念只能作为后续解释候选，不能取代文本自己的词义与关系结构。
