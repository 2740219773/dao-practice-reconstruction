## 二、Q1：“心”主要承担哪些角色？

### 2.1 当前判断（C01）

当前最稳妥的做法不是先回答“心是什么”，而是先记录“心在不同文本里做什么、处在什么关系中”。

本项目使用多角色框架整理材料，但不把这些角色合成一套古代统一心论。

### 2.2 支持证据

| 依据 | 文本 | 可支持的最小判断 | 强度 |
| ---- | ---- | ---- | ---- |
| 原文-0019 | “虚其心” | 心可进入“虚其心”的使动结构；首先是治民语境 | 直接（T2） |
| 原文-0008 | “凡心之刑，自充自盈……忧乐喜怒欲利……” | 心与情欲扰动、安宁/和相关；“刑/形”解释有竞争 | 直接（T2，校勘限定） |
| 原文-0009 | “心静气理，道乃可止” | 心可被表述为“静”，并与气、道关系相连 | 直接（T2） |
| 原文-0010 | “定心在中”“心以藏心”“心全于中” | 心进入定、藏、全等多种结构 | 直接（T2，训释开放） |
| 原文-0004 | “心使气曰强” | 心与气之间存在“使”关系表述 | 直接（T2） |
| 原文-0005 | “听之以心”“心止于符” | 心参与心斋听/止结构 | 直接（T2） |
| 原文-0016 | “一身之主”“收心离境” | 唐代文本明确赋予心主位并将其作为收/虚/安的对象 | 直接（T2；后世体系） |

### 2.3 阶段4解释核对

#### “凡心之刑”

- 当前网络传本正文作“刑”；
- 刘绩《管子补注》明确按“刑=法”解释；
- 现代学术又存在按“刑/形”理解为“心之表现形态”的路径。

因此本专题不把“刑/形”直接用来证明“心有某种实体形状”，也不在当前阶段强行定谳校勘取舍。

#### “心以藏心，心之中又有心焉”

现代研究中存在多种解释模型，例如官能之心/更根源之心、一般心/得道后之心等层次化理解。

这些可以说明**解释竞争真实存在**，但不能直接把原文写成“两颗心实体”或后世“本心论”。

### 2.4 Q1结论

- 采用C01多角色项目框架；
- 不采用旧稿“心=思维、情绪、意志统一主体”等覆盖性定义；
- “刑/形”“心中之心”保留解释开放性。

## 三、Q2：“心”与“静、虚”是什么关系？

### 3.1 当前判断（C02）

在冻结材料中，“静”“虚”经常围绕“心”出现，但不能写成“心=静=虚”。

更稳妥的是逐文本记录：心可以“静”、可以被“虚”，后世还出现“虚心”；心斋又把“虚”置于定义附近。关系密切，但句法、文本功能与历史层次不同。

### 3.2 支持证据

| 依据 | 文本 | 支持内容 |
| ---- | ---- | ---- |
| 原文-0019 | “虚其心” | 心是“虚”的对象；治民语境限制个人修养化 |
| 原文-0009 | “心静气理” | “静”直接修饰/描述心 |
| 原文-0005 | “唯道集虚。虚者，心斋也” | 虚是心斋核心表述，但不等于“心就是虚” |
| 原文-0016 | “心不受外，名曰虚心；心不逐外，名曰安心” | 后世文本明确形成“虚心/安心”命名 |
| TOPIC-001/002 | 已冻结专题 | 静、虚已有各自多义和工作性边界，不能反过来定义“心” |

### 3.3 阶段4限定

郭象/成玄英及现代心斋研究都只能帮助理解心斋本身；不能据此把“心—静—虚”写成一条固定技术链。

现代研究对心斋的哲学/心理解释本身存在竞争，也进一步说明不宜用一个现代模型统一“心”。

### 3.4 Q2结论

C02维持“相关但不同层级”。任何关系图都必须逐文本列关系，不写统一流程箭头。

## 四、Q3：“心—气”能否理解为心控制气？

### 4.1 当前判断（C03）

**当前不支持。**

三个直接文本给出的关系不同：

- 《道德经》：“心使气曰强”；
- 《内业》：“心静气理，道乃可止”；
- 《庄子·心斋》：“无听之以心而听之以气”。

阶段4传统解释层又进一步限制“控制模型”：

- 王弼注：“心宜无有，使气则强”；
- 刘绩注“心静气理”时解释为“气自调理”。

因此文本与注释层都不适合被改写成“意念发出指令，气按指令运行”。

### 4.2 支持/反限证据

| 依据 | 内容 | 对控制模型的影响 |
| ---- | ---- | ---- |
| 原文-0004 | 心使气曰强 | “使气”处于“强”及“不道”附近语境，不是正面技术口号 |
| R01 王弼注 | 心宜无有，使气则强 | 进一步限制“使气”技术化 |
| 原文-0009 | 心静气理 | 表现为状态关系，不是明确操控命令 |
| R02 刘绩注 | 静心则气自调理 | 后世解释也不采用单向“心强制控气”模型 |
| 原文-0005 | 听之以心→听之以气 | 与“心始终指挥气”的单向模型不一致 |

### 4.3 限定

- “气”的完整定义移交TOPIC-004；
- “气理”的具体训释仍可继续研究，但不影响当前反限；
- 不把气等同呼吸、现代生理气体或“能量”；
- 不从C03生成导气、调息或气感训练。

### 4.4 Q3结论

C03在阶段4后保持“当前不支持”，且反限依据比阶段2更强。

## 五、Q4：虚心、心斋、一志、定心、收心是否同一种方法？

### 5.1 当前判断（C04）

当前材料不支持把这些词拼成一套跨时代统一方法。

它们可以互相比较，但第一原则是保留文本身份与历史层次。

### 5.2 分文本证据

| 表述 | 文本 | 当前最小定位 |
| ---- | ---- | ---- |
| 虚其心 | 道德经3章 | 治民语境中的使动表达 |
| 一志/心斋 | 庄子·人间世 | 心斋对话中的过程性表述；古注有自身解释 |
| 定心在中/心以藏心 | 管子·内业 | 与精、道、官、气等结构相连 |
| 收心离境 | 坐忘论·收心 | 唐代坐忘体系中的明确系统化表述 |
| 虚心/安心 | 坐忘论·收心 | 对“不受外/不逐外”的后世命名 |

### 5.3 阶段4解释核对

- 郭象/成玄英可帮助理解心斋，但不能把心斋翻成现代压念技术；
- 现代心斋研究存在不同理论框架，不足以建立唯一心理模型；
- 《坐忘论》本身形成系统化“收心/虚心/安心”结构，但这只能证明唐代文本自身，不反向证明先秦已有同一程序。

### 5.4 Q4结论

C04维持“相似可比较，但不合并”。阶段3已建立争议-0008记录这一解释竞争。

## 六、现代对应边界（C05）

本专题不写：

- 古人的心就是大脑；
- 传统心就是现代意识；
- 心使气就是注意力调节自主神经；
- 心以藏心就是元认知；
- 收心就是抑制某个脑网络。

阶段4现代人文学术自身就使用不同的解释模型，这恰好说明现代概念只能作为比较候选，不能取代传统文本。

允许的表达是：

> “心”在冻结文本中承担多种角色；现代概念若要比较，必须说明对应的是哪条文本关系、哪一层解释，且不能倒推为古义。
