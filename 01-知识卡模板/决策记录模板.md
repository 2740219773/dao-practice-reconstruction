# 决策记录模板

本模板依据《基础规范 V0.1》编制，字段键英文值中文

模板版本：V0.2

---

决策记录用于保存项目的重要规则变化和判断变化。

---

```yaml
---
id:                      # 决策编号，示例：决策-0001
title:                   # 决策标题
decision_type:           # 决策类型
proposed_at:             # 提出日期，格式：年-月-日
effective_at:            # 生效日期，格式：年-月-日
proposer:                # 提出人员
participants:            # 参与讨论人员
impact_scope:            # 影响范围
text_reliability:        # T1—T5
interpretation_level:    # I1—I5
counterevidence_status:  # C0—C4
risk_level:              # S0—S4
review_status: 草稿      # 当前状态，九种中文状态之一
related_documents:       # 关联文献
related_texts:           # 关联原文
related_concepts:        # 关联概念
related_claims:          # 关联主张
related_hypotheses:      # 关联假说
created_at:              # 创建日期，格式：年-月-日
updated_at:              # 最后修改日期，格式：年-月-日
creator:                 # 创建人员
---
```

# 决策标题

## 1. 原有做法或原有判断

说明修改前项目是怎样处理的。

------

## 2. 发现的问题

说明原有判断哪里不准确、是否出现新文献、是否发现概念混淆、是否出现反例、是否存在安全风险、是否由外部审核指出。

------

## 3. 可选方案

### 方案一

**内容：**

**优点：**

**问题：**

### 方案二

**内容：**

**优点：**

**问题：**

------

## 4. 最终决定

明确写出项目采用的新做法。

------

## 5. 决定依据

列出：原始文献、历代注释、现代研究、逻辑分析、安全要求、外部审核意见。

------

## 6. 反对意见

记录没有被采纳的不同意见，不能只保留最终获胜的观点。

------

## 7. 影响范围

列出需要修改的内容：项目章程、证据等级规范、安全边界、文献卡、原文卡、概念卡、主张卡、假说卡、网站内容、人工智能规则、其他。

------

## 8. 需要回溯修改的文件

| 文件或卡片编号 | 原有内容 | 需要怎样修改 | 完成状态 |
| -------------- | -------- | ------------ | -------- |
|                |          |              |          |

------

## 9. 生效说明

说明从什么时间开始执行、旧内容如何处理、是否保留旧版本、是否需要发布公开说明。

------

## 10. 后续复审条件

在什么情况下重新讨论这项决定？
