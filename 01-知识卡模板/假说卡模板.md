# 假说卡模板

本模板依据《基础规范 V0.3》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.4

---

假说卡用于记录尚未获得充分支持，但具有研究价值的解释模型。

---

```yaml
---
编号:                      # 假说编号，示例：假说-0001
标题:                   # 假说名称
假说内容:      # 假说内容
假说类型:         # 假说类型
传统依据:       # 传统依据
关联概念:        # 涉及概念
关联原文:           # 涉及原文
文献可靠等级:        # 文献可靠等级 T1—T5
最低解释层级: # 解释等级 I1—I5
最高推论层级: # 解释等级 I1—I5
现代证据等级:         # 现代证据等级 E1—E5、EX
对应强度:        # 对应强度 M0—M4
实践重复等级:       # 实践重复等级 R0—R5
```

# 假说名称

## 1. 假说内容

用明确方式表达。

> 示例：传统静功中部分被称为“气感”的体验，可能与注意增强后身体内部感觉变得更加清晰有关。

------

## 2. 提出背景

说明为什么提出这个假说、它试图解释什么问题、现有解释有什么不足、是否由人工智能辅助生成。

------

## 4. 现代研究依据

| 研究编号 | 研究主题 | 主要结果 | 与假说的关系 | 局限 |
| -------- | -------- | -------- | ------------ | ---- |
|          |          |          |              |      |

------

## 5. 推理过程

将推理拆成若干步骤，并指出其中哪些步骤已经有证据，哪些步骤仍是推测。

```text
传统文本描述某种体验
↓
该体验可能与注意状态有关
↓
现代研究发现注意会影响身体内部感觉
↓
因此提出两者可能存在联系
```

------

## 6. 可以观察什么

说明假说如果成立，可能观察到哪些现象。

------

## 7. 支持条件

什么结果出现时，可以增强该假说？

------

## 8. 反驳条件

什么结果出现时，需要否定或大幅修改该假说？假说不能设计成任何结果都能解释。

------

## 9. 替代解释

至少列出：生理解释、心理解释、期待或暗示、环境因素、记录偏差、其他传统解释。

------

## 10. 风险分析

说明该假说是否可能被误解为实践指导、是否会诱导参与者追求某种体验、是否可能将异常体验神秘化、是否涉及呼吸、睡眠或精神状态。

------

## 11. 是否允许进入实践设计

选择：否、仅允许知识研究、需要专业审核、可以设计低风险观察、暂停研究。

------

## 12. 当前判断

> 示例：该假说目前具有一定解释价值，但传统文本与现代研究之间仅存在间接联系，暂不能视为已得到验证。
