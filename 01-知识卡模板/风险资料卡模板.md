# 风险资料卡模板

本模板依据《基础规范 V0.3》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.5

---

## 一、模板用途

风险资料卡用于记录与传统修炼内容相关的风险信息，包括风险类型、可能诱因、表现、严重程度、停止条件和处理原则。

本模板依据《一阶段计划》第六步和《安全边界 V0.2》编制。

### 基本立场

- 人的安全高于项目结论；
- 不适不是效果证明；
- 主观真实不等于解释正确；
- 异常体验首先作为安全事件记录，不作为成果宣传；
- 项目不使用"走火入魔"作为统一医学诊断；
- "走火入魔"只能作为传统文化术语进行研究，实际安全处理必须拆分成具体、可观察的事件。

### 风险等级 S0—S4

| 等级 | 名称 | 说明 |
| ---- | ---- | ---- |
| S0 | 纯知识内容 | 文献整理、历史介绍、概念分析，通常无直接实践风险 |
| S1 | 低风险日常观察 | 记录作息、自然呼吸、正常情绪变化，不强制改变状态 |
| S2 | 需要专业审核的实践 | 较长时间静坐、主动改变呼吸节律、持续集中注意身体部位 |
| S3 | 高风险实践 | 长时间闭气、快速或强力呼吸、禁食、睡眠剥夺等 |
| S4 | 禁止性内容 | 不明丹药、有毒物质、危险身体操作、拒绝正常医疗等 |

### 异常事件分级 L1—L3

| 等级 | 名称 | 可能表现 | 处理要点 |
| ---- | ---- | -------- | -------- |
| L1 | 轻度异常 | 短暂头晕、轻微恶心、短暂麻木或刺痛、轻度焦虑、注意难以集中 | 立即停止当前练习，当天不再继续相同练习；症状持续、加重或反复出现时升级为 L2 |
| L2 | 中度异常 | 持续或反复失眠、明显恐慌、持续情绪低落、持续现实感减弱、无法自主停止练习 | 停止相关实践，暂停参加项目活动，不再接受人工智能生成的练习建议，建议专业评估，启动安全复审 |
| L3 | 严重或紧急异常 | 晕厥、抽搐、严重胸痛、明显呼吸困难、意识不清、持续幻觉或妄想、自伤或伤人 | 立即停止一切练习，联系紧急医疗服务，不让当事人独处，启动重大安全事件审查 |

不得使用"走火入魔"统一概括上述事件，必须按具体表现分级记录。

## 二、卡片编号

按《基础规范 V0.1》统一编号体系：

```text
风险资料-0001
风险资料-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用；被废弃卡片的编号保留，状态标记为"不予采用"或"已归档"。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：

| 状态 | 含义 |
| ---- | ---- |
| 草稿 | 卡片刚建立，内容可能不完整 |
| 待核对 | 原文、出处、版本或引用尚未完成核对 |
| 来源已核对 | 原始资料已确认，解释仍未审核 |
| 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 |
| 待综合审核 | 内容基本完成，等待整体审核 |
| 已审核 | 符合当前版本规则，可进入正式知识库 |
| 需要修订 | 已发现问题，需要修改 |
| 不予采用 | 存在严重来源、逻辑或安全问题 |
| 已归档 | 被新版本取代，保留用于追溯 |

新建卡片默认状态：草稿。

状态迁移必须同步更新最后修改日期和修改记录。

## 四、YAML 字段

```yaml
---
编号: 风险资料-0001
标题: 风险资料标题
当前状态: 草稿
网站发布状态: 不公开      # 网站发布状态：不公开／内部预览／可公开草稿／正式公开／已撤回
公开摘要: 待补录      # 面向公众的公开摘要，正式公开前必须填写
公开注意事项: 待补录      # 面向公众的注意事项，正式公开前必须填写
文献可靠等级: T2
最低解释层级: I3
最高推论层级: I3
现代证据等级: E3
反证状态: C1
卡片发布风险: S0
所含实践最高风险: S2
来源可信等级: 待考      # 甲级／乙级／丙级／丁级／待考／禁用（《来源可信等级规范》）
是否适合自学: 待判断      # 是／否／需教师／待判断
是否需要教师: 待判断      # 是／否／视方法而定
前置条件: 待补      # 练习该内容所需的前置条件
创建日期: 2026-08-01
最后修改日期: 2026-08-01
创建人员: 创建人员
---
```

### 字段说明

- 编号：卡片编号，格式为"风险资料-四位流水号"；
- 标题：风险资料标题；
- 当前状态：使用 9 个中文状态，默认"草稿"；
- 文献可靠等级：文献可靠度 T1—T5；
- 最低解释层级：解释层级 I1—I5，卡内最接近字面的解释层级；
- 最高推论层级：解释层级 I1—I5，卡内最远的推论层级；
- 现代证据等级：现代证据等级 E1—E5 或 EX，如有研究支持时填写；
- 反证状态：C0—C4；
- 卡片发布风险：S0—S4，发布层面（卡片本身），本类卡以此替代"风险等级"（《字段映射表》V0.6）；
- 所含实践最高风险：S0—S4，按卡内所涉实践逐段评价（S0 不涉及任何实践或人体干预；S1 一般注意、认知或低干预观察；S2 主动调节呼吸、持续身体关注、长时间保持姿势；S3 闭气、强力呼吸、明显精神状态干预或较高风险练习；S4 丹药、辟谷及其他严重风险内容），防止 S0 被误读为内容无风险；
- 来源可信等级：甲级／乙级／丙级／丁级／待考／禁用，按《来源可信等级规范》填写；
- 是否适合自学：是／否／需教师／待判断——按《修持方法分级》第零—四级语义判断（知识了解可自学；建议有人指导/需要教师级别的不得标"适合自学"）；
- 是否需要教师：是／否／视方法而定；
- 前置条件：练习该内容所需的前置条件，待补时写"待补"；
- 创建日期：格式为 年-月-日；
- 最后修改日期：格式为 年-月-日；
- 创建人员：创建人员。

等级字母作为正式技术名称保留原样。

## 五、正文结构

# 风险资料标题

## 1. 风险类型

选择或补充，例如：

- 呼吸相关；
- 注意和意守相关；
- 静坐相关；
- 饮食和作息相关；
- 意识体验相关；
- 心理影响；
- 身体不适；
- 社会或生活影响；
- 其他。

## 2. 可能诱因

记录可能引起该风险的练习内容、环境条件或个体因素。

## 3. 表现

用具体、可观察的语言描述，不使用境界判断。

记录时严格区分以下内容：

- 参与者原话：当事人自己描述的内容；
- 观察者现象：他人能够观察到的表现；
- 人工智能解释：人工智能提出的可能解释，仅供参考；
- 专业人员判断：专业人员给出的评估；
- 项目最终处理决定：项目采取的正式处理。

记录示例：

> 参与者报告下腹部温热感，原因暂不确定。

不得记录为：

> 丹田开启导致发热。

## 4. 严重程度

按《安全边界 V0.2》异常事件分级填写：

- L1：轻度异常；
- L2：中度异常；
- L3：严重或紧急异常。

同时标注本条资料对应的风险等级 S0—S4。

不得使用"走火入魔"作为统一诊断。

## 5. 停止条件

明确列出出现哪些表现时必须停止练习。

## 6. 处理原则

按异常事件分级选择处理原则。

### L1 处理原则

1. 立即停止当前练习；
2. 回到正常呼吸和日常活动；
3. 不继续追求或重复该感觉；
4. 记录发生时间、练习内容和持续时间；
5. 当天不再继续相同练习；
6. 若症状持续、加重或反复出现，升级为 L2。

### L2 处理原则

1. 停止相关实践；
2. 暂停参加项目实践活动；
3. 不再接受人工智能生成的练习建议；
4. 建议寻求合格的医疗或心理专业评估；
5. 记录事件，但不得在公开社区讨论当事人身份；
6. 在专业人员确认前不得恢复相关练习；
7. 对所涉协议启动安全复审。

### L3 处理原则

1. 立即停止一切练习；
2. 不通过网络继续分析所谓修炼原因；
3. 联系当地紧急医疗服务或立即前往医疗机构；
4. 不让出现严重意识或行为异常的人独处；
5. 在确保安全的前提下联系其可信任亲友；
6. 保存必要事件记录；
7. 暂停相关项目功能或实践协议；
8. 启动重大安全事件审查。

## 六、填写要求

- 风险内容必须单独标记，不能混入普通知识卡；
- 表现记录必须区分参与者原话、观察者现象、人工智能解释、专业人员判断和项目最终处理决定；
- 不得使用"走火入魔"统一概括异常事件；
- 不得将异常体验解释成气感增强、排病反应、气冲病灶、经脉打通、境界突破或修炼正在起效；
- 出现严重异常后，禁止使用"再坚持一下就过去了""这是冲关反应"等表达要求当事人坚持；
- 项目成员不得凭个人经验判断严重胸痛、呼吸困难、晕厥等一定由紧张或练习引起；
- 本卡不构成实践指导，也不构成医疗建议。
