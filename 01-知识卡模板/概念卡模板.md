# 概念卡模板

本模板依据《基础规范 V0.1》编制，字段键英文值中文

模板版本：V0.2

---

概念卡用于整理一个传统术语在不同文献、时代和流派中的含义。概念卡不是词典释义，也不是寻找唯一标准答案。

---

```yaml
---
id:                      # 概念编号，示例：概念-0001
title:                   # 概念名称
alternative_names:       # 其他名称
related_glyphs:          # 相关字形
concept_category:        # 概念类别
earliest_source:         # 最早资料
main_periods:            # 主要时期
traditions:              # 涉及传统
schools:                 # 涉及流派
definition_status:       # 当前定义状态
text_reliability:        # T1—T5，概念卡如有直接引用必填
interpretation_level:    # 解释等级 I1—I5
modern_evidence:         # 现代证据等级 E1—E5、EX
mapping_strength:        # 对应强度 M0—M4
counterevidence_status:  # 反证状态 C0—C4
risk_level:              # 风险等级 S0—S4
review_status: 草稿      # 当前状态，九种中文状态之一
related_concepts:        # 关联概念
related_texts:           # 关联原文
created_at:              # 创建日期，格式：年-月-日
updated_at:              # 最后修改日期，格式：年-月-日
creator:                 # 创建人员
last_editor:             # 最后修改人员
---
```
