# 导引术资料卡模板

本模板依据《基础规范》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.1

---

## 一、模板用途

导引术资料卡用于登记一个完整的身体训练系统（如八段锦、五禽戏等），覆盖历史来源、版本演变、动作结构、呼吸意念要求、传统功效主张、现代研究、适用人群与禁忌风险。

本模板依据项目模块结构（导引术与身体训练模块，DAOYIN-）编制。模块是独立研究主线，与概念专题（TOPIC-）平级。

### 核心原则

> 历史功法 ≠ 现代标准化功法 ≠ 临床研究中的干预方案。

- 导引术资料卡不负责定义"静""气""心"等概念的完整理论；涉及概念处只建立关联（如"八段锦使用了'松静'要求 → 关联概念：静"）；
- 每次描述必须核对：采用哪个动作版本、每周练习几次、每次练多久、是否配合呼吸、是否有教练、研究对象是什么人群、对照组是什么；
- 传统功效主张与现代研究证据分层记录，不互相替代；
- 具体动作与呼吸意念要求属低—中风险内容，按《安全边界》逐段审查，不转化为无监督操作指导。

## 二、卡片编号

按《基础规范》统一编号体系：

```text
导引术-0001
导引术-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用；被废弃卡片的编号保留，状态标记为"不予采用"或"已归档"。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：

| 状态 | 含义 |
| ---- | ---- |
| 草稿 | 卡片刚建立，内容可能不完整 |
| 待核对 | 原文、出处、版本或引用尚未完成核对 |
| 来源已核对 | 原始资料已确认，解释仍未审核 |
| 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 |
| 待综合审核 | 内容基本完成，等待整体审核 |
| 已审核 | 符合当前版本规则，可进入正式知识库 |
| 需要修订 | 已发现问题，需要修改 |
| 不予采用 | 存在严重来源、逻辑或安全问题 |
| 已归档 | 被新版本取代，保留用于追溯 |

新建卡片默认状态：草稿。

状态迁移必须同步更新最后修改日期和修改记录。

### 字段说明

- 编号：卡片编号，格式为"导引术-四位流水号"；
- 名称：功法名称（如 八段锦）；
- 其他名称：别名（如 八段锦 又称"八段锦功"等）；
- 资料类型：本类卡固定"导引术"；
- 历史时期：功法出现、流行的大致时期；
- 最早可核来源：目前可核实的最早文献出处；
- 主要历史版本：历史上有影响的版本或流派；
- 当前采用版本：本项目整理所依据的版本，必须明确；
- 版本制定机构：当前版本的制定/推广机构（如体育总局健身气功管理中心），如适用；
- 动作数量：如八段锦"八式"；
- 主要姿势：立式、坐式等；
- 是否包含呼吸要求／意念要求／发声：是／否，均需在正文中给出出处；
- 传统功效主张：传统文献中的功效说法（只记录"传统文本怎么说"）；
- 现代研究状态：已有哪些现代研究、证据等级如何（详见正文第 9 节）；
- 主要适用人群：传统与研究中的人群描述；
- 已知不良事件：文献或研究中报告的不良事件；
- 所含实践最高风险：S0—S4，按卡内所涉实践逐段评价；
- 卡片发布风险：S0—S4，发布层面（卡片本身）；
- 当前状态：使用 9 个中文状态，默认"草稿"；
- 网站发布状态：不公开／内部预览／可公开草稿／正式公开／已撤回；
- 公开摘要／公开注意事项：正式公开前必须填写；
- 创建日期／最后修改日期：格式为 年-月-日；
- 创建人员：创建人员。

等级字母作为正式技术名称保留原样。

## 五、正文结构

# 功法名称

## 1. 名称与定义

说明功法名称的含义、其他名称、本卡的定义边界。

## 2. 历史来源

记录最早的文献出处、历史时期、与养生/医疗传统的关联。

## 3. 版本演变

列出主要历史版本及其差异；同一功法不同版本的取舍必须说明。

## 4. 当前采用版本

明确本项目整理所依据的版本、制定机构、动作规范出处。

## 5. 动作结构

逐个说明动作名称、顺序、姿势要点（只作整理记录，不构成操作指导）。

## 6. 呼吸要求

记录是否配合呼吸、呼吸方式（自然呼吸／配合动作的呼吸等）及其出处。

## 7. 意念要求

记录是否要求意守、宁神、松静等意念活动及其出处；只建立概念关联，不展开概念研究。

## 8. 传统功效主张

只记录传统文献中的功效说法及其出处（"传统文本怎么说"），不作证实判断。

## 9. 现代研究

记录现代研究现状：有哪些研究、研究设计、样本、结果、证据等级；"能支持什么／不能支持什么"分层记录。现代研究不能直接证明传统理论。

## 10. 反方和限定材料

记录反对性证据与限定材料（人群限制、条件限制、阴性结果等）。

## 11. 适用人群

传统与研究中的人群描述；不得据此替代个体评估。

## 12. 禁忌与停止条件

记录禁忌人群、停止条件、风险提示；出现异常按《安全边界》作安全事件处理。

## 13. 不能直接推出的结论

明确本卡不能推出的结论，例如：

> 不能从八段锦研究直接证明"气"的运行理论。

> 传统功效主张未经现代研究证实前，不当作医学结论。

## 14. 关联概念

| 概念 | 关联说明 | 所属模块 |
| -------- | -------- | -------- |
| 静 | 八段锦使用了"松静"要求 | TOPIC-001 |

只建立关联链接，不重新完成概念史。

## 15. 待解决问题

列出尚未核实、待补录、待研究的问题。

## 六、填写要求

- 历史功法、现代标准化功法、临床研究中的干预方案三者必须持续区分，每次引用八段锦等名称都要说明版本与语境；
- 传统功效主张与现代研究分层记录，不互相替代；
- 呼吸、意念、动作内容只作整理记录，不构成操作指导；
- 现代研究按《现代研究卡》规则引用，不重复建卡；
- 不得把相关性当成因果，不得把现代术语直接包装成传统说法的"科学证明"。
