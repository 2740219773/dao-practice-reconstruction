# 问题卡模板

本模板依据《基础规范》与《来源可信等级规范》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.1

---

## 一、模板用途

问题卡用于登记初学者的具体疑问，作为**入口节点**连接相关概念卡、原文卡、争议卡、辨析卡与修持相关内容。问题卡不写成孤立文章，不直接充当权威答案。

本模板依据《增量建设方案》"初学者问题地图"方向编制。

### 核心原则

> 问题从真实用户出发，答案从正式知识库来。

- 问题卡回答必须连接正式知识区卡片（概念/原文/争议/辨析），不凭空发挥；
- 社区观察转化的问题只保留"问题与需求"，社区结论不进入问题卡；
- 每条问题卡标注「来源可信等级」（甲/乙/丙/丁/待考/禁用）。

---

## 二、卡片编号

按《基础规范》统一编号体系：

```text
问题-0001
问题-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：草稿／待核对／来源已核对／待解释审核／待综合审核／已审核／需要修订／不予采用／已归档。新建默认"草稿"。

---

## 四、YAML 字段

```yaml
---
编号: 问题-0001
问题: 问题原文
问题分类: 入门认知      # 入门认知／经典阅读／概念理解／修持实践／历史宗派／现实应用／资料辨伪
用户真实意图: 用户真实意图
简要回答: 简要回答
需要先理解的概念: 需要先理解的概念
关联经典: 关联经典
关联人物: 关联人物
关联流派: 关联流派
关联修持: 关联修持
常见误解: 常见误解
进一步阅读: 进一步阅读
来源可信等级: 待考      # 甲级／乙级／丙级／丁级／待考／禁用
当前状态: 草稿
网站发布状态: 不公开      # 不公开／内部预览／可公开草稿／正式公开／已撤回
公开摘要: 待补录
公开注意事项: 待补录
创建日期: 2026-08-03
最后修改日期: 2026-08-03
创建人员: 创建人员
---
```

### 字段说明

- 编号：卡片编号，格式为"问题-四位流水号"；
- 问题：用户的原问题（可合并同类问题，保留典型说法）；
- 问题分类：七个类别之一（对应 18-问题地图/ 子目录）；
- 用户真实意图：问题背后想解决什么（如"无为是不是不努力"背后的意图可能是"如何面对行动焦虑"）；
- 简要回答：不超过三句，指向正式知识卡；
- 需要先理解的概念／关联经典／关联人物／关联流派／关联修持：连接正式知识区卡片编号；
- 常见误解：与该问题相关的常见误解；
- 进一步阅读：延伸阅读入口；
- 来源可信等级：按《来源可信等级规范》填写；
- 当前状态／网站发布状态／公开摘要／公开注意事项：同通用规则；
- 创建日期／最后修改日期／创建人员：格式与通用规则一致。

## 五、正文结构

# 问题原文

## 1. 问题与背景

记录问题的典型说法、出现场景（社区/教学/自学）与用户真实意图。

## 2. 简要回答

不超过三句的概要回答，须注明依据来源（概念卡/原文卡编号）。

## 3. 需要先理解的概念

列出回答前需要理解的基础概念，链接到概念卡。

## 4. 关联内容

| 类型 | 编号 | 关联说明 |
| ---- | ---- | -------- |
| 概念 | 概念-0001 | ... |
| 原文 | 原文-0001 | ... |
| 争议 | 争议-0001 | ... |
| 辨析 | 辨析卡-0001 | ... |

## 5. 常见误解

记录该问题常见的错误回答或误解，并注明正确依据。

## 6. 进一步阅读

延伸阅读入口（按学习路线或专题）。

## 7. 来源可信等级

说明本条回答各部分的来源可信等级（甲/乙/丙/丁/待考/禁用）。

## 8. 待解决问题

尚未有正式知识库支撑、需要新建或修改卡片的内容。

| 版本 | 日期 | 修改内容 | 修改原因 | 修改人员 |
| ---- | ---- | -------- | -------- | -------- |
| 0.1  |      | 初始建立 |          |          |

## 六、填写要求

- 问题卡是入口节点，不是最终结论；回答必须指向正式知识卡；
- 社区观察转化的问题只保留"问题与需求"，不保留社区结论；
- 每条回答标注来源可信等级，丁级/待考内容须明确标注；
- 无正式依据的问题保持"待解决"，不臆造回答。
