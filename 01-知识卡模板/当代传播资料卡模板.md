# 当代传播资料卡模板

本模板依据《基础规范 V0.2》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表 V0.2》。

模板版本：V0.3

---

当代传播资料卡用于登记视频、网络文章、网络课程等当代网络修炼传播材料（决策-0003）。这类材料不是古代原典、不是历代注释、不是师承明确的近现代传承文献，也不是现代学术研究，其项目身份是"当代传统修炼传播样本"。

## 基本立场

- 资料性质：当代网络修炼传播材料；
- 不能直接作为古籍依据：其中的古籍引文必须回到原始来源核验；
- 不能作为现代学术证据；
- 其中包含的具体实践方法不得直接进入实践协议，必须单独进行风险审查；
- 效果承诺必须建立主张卡，不得作为课程事实直接传播；
- 公开仓库不保存未经许可的完整视频、完整音频与完整逐字稿。

---

## 一、资料暂存与来源

原始材料先进入 12-待处理资料/当代传播资料/（按"传播资料-XXXX-系列名"建子目录），其中至少包含：

- 00-资料说明.md：账号、主页、系列名称、发布者身份是否核实、视频数量、资料获取日期、整理人员、当前处理状态；
- 01-原视频索引.md：每条视频的编号、标题、发布时间、原链接、时长、主要内容、当前状态；视频被删除时仍可追溯来源；
- 03-内容整理稿.md：结构化整理稿，开头必须带"资料性质说明"，注明非古籍原文、非项目认可的练习方案，可能包含视频原有观点、整理者归纳、补充安全说明与未核实古籍出处；**不得命名为"原文.md"**。

视频本身是原始来源，整理稿是二次加工材料。整理稿中"原视频直接表达"与"整理者归纳/补充的安全说明"必须分开记录。

## 二、卡片编号

按《基础规范 V0.2》统一编号体系：

```text
传播资料-0001
传播资料-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：

| 状态 | 含义 |
| ---- | ---- |
| 草稿 | 卡片刚建立，内容可能不完整 |
| 待核对 | 原文、出处、版本或引用尚未完成核对 |
| 来源已核对 | 原始资料已确认，解释仍未审核 |
| 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 |
| 待综合审核 | 内容基本完成，等待整体审核 |
| 已审核 | 符合当前版本规则，可进入正式知识库 |
| 需要修订 | 已发现问题，需要修改 |
| 不予采用 | 存在严重来源、逻辑或安全问题 |
| 已归档 | 被新版本取代，保留用于追溯 |

新建卡片默认状态：草稿。

## 四、YAML 字段

```yaml
---
编号: 传播资料-0001
标题: 资料名称
当前状态: 待核对
文献可靠等级: 不适用
最低解释层级: I3
最高推论层级: I4
反证状态: C1
风险等级: S0
卡片发布风险: S0
所含实践最高风险: 至少S2（具体逐段评估）
资料编号: 传播资料-0001
发布平台:
发布账号:
发布者身份: 待核实
师承或流派: 待核实
发布时间范围: 待补
资料类型: 当代网络修炼传播材料
内容形式: 短视频系列
是否包含古籍引用: 是
是否包含具体操作: 是
是否包含效果承诺: 是
是否涉及呼吸控制: 是
是否涉及意守: 是
是否涉及身体动作: 是
是否允许进入实践: 否
创建日期:
最后修改日期:
创建人员:
---
```

### 字段说明

- 编号：卡片编号，格式为"传播资料-四位流水号"；
- 标题：资料名称（与"资料编号"字段并用时，本字段写资料名称即可）；
- 当前状态：使用 9 个中文状态，默认"草稿"；资料尚未核对完成前用"待核对"；
- 文献可靠等级：本类资料不适用，写"不适用"；
- 最低解释层级／最高推论层级：按卡内解释范围填写 I1—I5；
- 反证状态：C0—C4；
- 风险等级：S0—S4（发布层面，卡片本身）；
- 卡片发布风险：S0—S4，与"风险等级"同义，突出"发布"层面，避免与内容风险混淆；
- 所含实践最高风险：至少S2（具体逐段评估），表示资料中实践内容的最高风险必须逐段评估，不能因卡片是 S0 就认为内容无风险；
- 资料编号：同一资料系列可能有多个视频/文章时使用（如传播资料-0001-01）；单一资料可省略；
- 发布平台：如抖音、微信公众号、B 站、小红书；
- 发布账号：账号名称，是否核实注明；
- 发布者身份：待核实／已核实，附核实说明；
- 师承或流派：待核实；不得依据自称填写"已核实"；
- 发布时间范围：待补／具体日期；
- 资料类型：当代网络修炼传播材料；
- 内容形式：短视频系列、单条短视频、网络文章、网络课程等；
- 是否包含古籍引用／具体操作／效果承诺、是否涉及呼吸控制／意守／身体动作：是／否，用于风险与追溯分级；
- 是否允许进入实践：否（默认），经逐段风险审查后由决策变更；
- 创建日期／最后修改日期：格式为 年-月-日；
- 创建人员：创建人员。

等级字母作为正式技术名称保留原样。

## 五、正文结构

# 资料名称

## 1. 资料简介

简要说明该资料的主题、内容范围、在当代传播中的定位，以及为什么与本项目有关（如作为传播研究、出处追溯、风险分析样本）。

## 2. 发布者及背景核查

记录发布平台、账号、发布者自称身份（是否说明师承）、主页信息、粉丝与互动情况（仅作传播背景，不作为可信度依据）、是否找到可交叉核实的第三方信息。

## 3. 视频内容结构

按整理稿列出视频/文章结构，例如：

| 视频编号 | 标题 | 对应整理稿章节 | 主要内容 | 是否已核对 |
| -------- | ---- | -------------- | -------- | ---------- |
| 视频-001 |      | 整理稿 01       |          | 待核对     |

## 4. 声称引用的传统文献

| 声称引用 | 视频原话 | 声称出处 | 实际核对结果 | 待查状态 |
| -------- | -------- | -------- | ------------ | -------- |
|          |          |          |              | 待查     |

核对结果必须回到原始文献，见 04-传统出处待查表.md 与 12-待处理资料/当代传播资料/传播资料-XXXX-系列名/。

## 5. 具体练习方法

按内容性质拆分记录，不把整套流程当作一个整体：

- 环境与生活建议；
- 姿势与运动准备；
- 主动呼吸方法（吸气/呼气时长、屏息、提肛等，须逐项列出）；
- 意守与观想；
- 仪式和象征内容；
- 效果和时间承诺。

## 6. 传统象征与仪式内容

记录方向、颜色、口诀、仪式等，注明是视频原话还是整理者归纳。

## 7. 现代生活经验内容

记录其中与现代生活相关的合理建议（如避免酒后练习、不强行盘坐、手机静音等），同样注明来源。

## 8. 效果承诺

| 承诺编号 | 视频原话 | 声称时限 | 是否建立主张卡 | 当前处理 |
| -------- | -------- | -------- | -------------- | -------- |
|          |          |          | 是／否         |          |

效果承诺必须建立主张卡，不得作为课程事实直接传播。

## 9. 风险初筛

按《安全边界 V0.2》异常事件分级与风险等级 S0—S4 初筛，至少回答：

- 是否涉及呼吸控制、意守、身体动作；
- 是否存在"气冲病灶""坚持就过去"等危险表述；
- 是否适合普通初学者直接照做；
- 所含实践最高风险的初步判断（至少S2，具体逐段评估）。

## 10. 可以保留的内容

只列出可单独审查的候选组件（例如：环境减少干扰、不强压膝盖、椅坐替代盘坐、练习后缓慢恢复活动），每项注明来源与风险等级。

## 11. 当前不能接受的内容

列出未经核实的古籍出处、效果承诺、危险操作与无根据的健康表述。

## 六、填写要求

- 整理稿必须带"资料性质说明"，不得命名"原文.md"；
- "原视频直接表达"与"整理者归纳/补充的安全说明"不得混写；
- 古籍引文必须回到原始来源核验后才能写入正式结论；
- 效果承诺必须建立主张卡；
- 具体实践方法不得直接进入实践协议；
- 本卡不构成实践指导，也不构成医疗建议。
