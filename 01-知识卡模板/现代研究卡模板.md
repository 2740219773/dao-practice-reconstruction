# 现代研究卡模板

本模板依据《基础规范 V0.2》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表 V0.2》。

模板版本：V0.3

---

## 一、模板用途

现代研究卡用于记录一篇现代生理、心理、医学或社会科学研究，帮助解释和检验项目假说。

本模板依据《一阶段计划》第六步"建立现代研究资料库"编制。

### 核心原则

> 现代研究是用来帮助解释和检验假说，不是给传统说法寻找"科学包装"。

- 现代研究只能说明某种传统体验存在一种可能的解释；
- 现代研究不能直接证明传统"气"等概念的完整理论；
- 例如，现代研究发现注意会影响身体内部感觉，只能说明某些传统体验存在一种可能的解释，不能直接证明传统"气"的完整理论；
- 每项研究必须同时记录"能支持什么"和"不能支持什么"。

### 第一阶段研究范围

第一批只研究七个方向：

1. 呼吸与自主神经活动；
2. 注意力调节；
3. 身体内部感觉；
4. 情绪调节；
5. 睡眠与身心状态；
6. 冥想和静坐研究；
7. 静坐、呼吸练习的不良反应。

## 二、卡片编号

按《基础规范 V0.1》统一编号体系：

```text
现代研究-0001
现代研究-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用；被废弃卡片的编号保留，状态标记为"不予采用"或"已归档"。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：

| 状态 | 含义 |
| ---- | ---- |
| 草稿 | 卡片刚建立，内容可能不完整 |
| 待核对 | 原文、出处、版本或引用尚未完成核对 |
| 来源已核对 | 原始资料已确认，解释仍未审核 |
| 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 |
| 待综合审核 | 内容基本完成，等待整体审核 |
| 已审核 | 符合当前版本规则，可进入正式知识库 |
| 需要修订 | 已发现问题，需要修改 |
| 不予采用 | 存在严重来源、逻辑或安全问题 |
| 已归档 | 被新版本取代，保留用于追溯 |

新建卡片默认状态：草稿。

状态迁移必须同步更新最后修改日期和修改记录。

## 四、YAML 字段

```yaml
---
编号: 现代研究-0001
标题: 研究题目
当前状态: 草稿
文献可靠等级: T2
最低解释层级: I4
最高推论层级: I4
现代证据等级: E2
对应强度: M1
反证状态: C1
风险等级: S0
创建日期: 2026-08-01
最后修改日期: 2026-08-01
创建人员: 创建人员
---
```

### 字段说明

- 编号：卡片编号，格式为"现代研究-四位流水号"；
- 标题：研究题目；
- 当前状态：使用 9 个中文状态，默认"草稿"；
- 文献可靠等级：文献可靠度 T1—T5，用于评价研究来源文本的可靠程度；
- 最低解释层级：解释层级 I1—I5，卡内最接近字面的解释层级；
- 最高推论层级：解释层级 I1—I5，卡内最远的推论层级；
- 现代证据等级：E1—E5 或 EX，用于评价该研究主张本身获得的支持强度；
- 对应强度：对应关系强度 M0—M4，用于评价该研究与传统概念的对应直接程度；
- 反证状态：C0—C4；
- 风险等级：S0—S4；
- 创建日期：格式为 年-月-日；
- 最后修改日期：格式为 年-月-日；
- 创建人员：创建人员。

等级字母作为正式技术名称保留原样。

## 五、正文结构

# 研究题目

## 1. 研究基本信息

**研究题目：**

**作者：**

**发表时间：**

**研究类型：**

例如：

- 随机对照试验；
- 队列研究；
- 横断面研究；
- 纵向研究；
- 系统综述或荟萃分析；
- 个案研究；
- 其他。

## 2. 研究对象

说明研究针对什么人、什么现象或什么方法。

## 3. 样本情况

记录：

- 样本数量；
- 人群特征；
- 纳入和排除条件；
- 招募方式；
- 退出情况。

## 4. 使用方法

说明：

- 研究设计；
- 干预或观察方式；
- 对照和随机情况；
- 测量工具；
- 数据收集与分析方法。

## 5. 主要发现

客观记录研究得到的结果，不加入项目自己的推论。

## 6. 研究局限

记录：

- 样本限制；
- 方法限制；
- 结果适用范围；
- 作者自己指出的问题；
- 项目补充发现的局限。

## 7. 能支持什么

说明该项研究可以支持哪些有限结论。

## 8. 不能支持什么

明确说明该项研究不能支持什么，例如：

> 不能证明传统"气"的完整理论。

> 不能从冥想研究直接推断"坐忘"已被科学证明。

> 研究结果只适用于其研究样本，不能推算所有修炼者的风险比例。

## 9. 与传统概念的关系

| 传统概念 | 对应说明 | 对应方向 | 对应强度 |
| -------- | -------- | -------- | -------- |
|          |          |          |          |

对应强度使用 M0—M4。

说明：

- 两者是直接对应、主题相似还是仅存在推理联系；
- 哪些对应点属于项目推论；
- 是否存在更简单的替代解释；
- 该项研究能否用于解释传统文本，不能用于证明什么。

## 10. 结论表达等级

按《证据等级规范 V0.2》统一表达方式选择：

- 确定存在；
- 较有支持；
- 初步支持；
- 合理假说；
- 纯粹推测；
- 当前不支持。

推荐表达示例：

> 现有资料提供初步支持，但尚不足以得出确定结论。

> 这可以作为一种待验证的解释。

## 六、填写要求

- 每篇现代研究只回答：研究了什么、参与者是谁、使用什么方法、得到什么结果、有哪些局限、能否用于解释传统文本、不能用于证明什么；
- "能支持什么"和"不能支持什么"必须同时填写；
- 不得看到"冥想对焦虑有效"就推断"坐忘论已经被科学证明"；
- 不得只保留支持项目方向的资料；
- 不得把相关性当成因果；
- 不得把现代术语直接包装成传统说法的"科学证明"；
- 研究等级发生变化时，必须记录原因并同步更新修改记录。
