# 医学观察资料卡模板

本模板依据《基础规范》与《医学观察资料分层规范》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.1

---

## 一、模板用途

医学观察资料卡用于登记内证记录、身体经验资料与医家个人观察（如《内证观察笔记》），回答：观察者记录了什么、作者如何解释、与传统/现代医学有什么关系、是否有独立验证、是否存在替代解释、哪些内容可以作为假说、哪些内容不能作为医学结论。

本模板依据项目模块结构（医学观察与身体经验模块，MEDOBS-）编制。模块是独立研究主线，与概念专题（TOPIC-）、导引术模块（DAOYIN-）平级。

### 核心原则

> 观察到了什么 ≠ 作者认为这意味着什么。

- **最重要规则：观察内容与作者解释必须分开记录**——例如"练习时腹部出现温热感"（观察）不能直接写作"气机变化"（解释）；
- 个人内证与身体观察只用于描述经验、提出假说、提供待验证线索；
- 不能用于证明解剖结构、确诊疾病、证明治疗有效；
- 不建立练功教程，不诊断疾病，不把个人观察直接推广为普遍规律。

### 证据四层（《医学观察资料分层规范》）

| 层 | 内容 | 能说明什么 |
| ---- | ---- | ---- |
| 第一层 | 传统医学原文（《黄帝内经》、传统导引文献、藏腑经络气血相关原文） | 传统文本怎么说 |
| 第二层 | 历代和当代医学解释（注释、中医教材、医家理论、当代传统医学著作） | 后人如何理解和发展 |
| 第三层 | 个人内证与身体观察（《内证观察笔记》、修炼者记录、医家个人观察、口述经验） | 描述经验、提出假说、提供待验证线索 |
| 第四层 | 现代医学研究（生理测量、影像学、随机对照试验、队列研究、系统综述、临床指南、不良事件资料） | 是否可以测量、是否有重复结果、是否有因果证据、适用于哪些人群、有什么风险、证据质量如何 |

## 二、卡片编号

按《基础规范》统一编号体系：

```text
医学观察-0001
医学观察-0002
```

流水号按类别独立计数，从 0001 开始，不作废、不复用；被废弃卡片的编号保留，状态标记为"不予采用"或"已归档"。

---

## 三、状态字段

当前状态字段使用 9 个中文状态：

| 状态 | 含义 |
| ---- | ---- |
| 草稿 | 卡片刚建立，内容可能不完整 |
| 待核对 | 原文、出处、版本或引用尚未完成核对 |
| 来源已核对 | 原始资料已确认，解释仍未审核 |
| 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 |
| 待综合审核 | 内容基本完成，等待整体审核 |
| 已审核 | 符合当前版本规则，可进入正式知识库 |
| 需要修订 | 已发现问题，需要修改 |
| 不予采用 | 存在严重来源、逻辑或安全问题 |
| 已归档 | 被新版本取代，保留用于追溯 |

新建卡片默认状态：草稿。

状态迁移必须同步更新最后修改日期和修改记录。

### 字段说明

- 编号：卡片编号，格式为"医学观察-四位流水号"；
- 资料名称：资料名称（如《内证观察笔记》）；
- 作者或讲述者：作者或讲述者，未明时写"待核对"；
- 出版或记录年代：出版或记录年代，待补时写"待补"；
- 资料类型：医学观察／内证记录／身体经验；
- 观察方式：自我观察、记录他人观察等；
- 记录形式：日记、笔记、论著章节等；
- 是否第一人称／是否有连续记录／是否有外部观察者／是否有医学检查／是否有独立验证：是／否；
- 涉及传统医学概念：经络、气、脏腑等；
- 涉及现代医学概念：生理、解剖、影像等；
- 证据用途：该资料可以支撑什么（如提出假说、提供线索），不能支撑什么；
- 可验证程度：高／中／低／不可验证（按是否有独立验证与可重复性判断）；
- 主要替代解释：对该观察的替代解释；
- 医学风险：误用可能造成的风险（如以主观感觉替代医学检查）；
- 卡片发布风险：S0—S4，发布层面（卡片本身）；
- 所含实践最高风险：S0—S4，按卡内所涉实践逐段评价；
- 当前状态：使用 9 个中文状态，默认"草稿"；
- 网站发布状态：不公开／内部预览／可公开草稿／正式公开／已撤回；
- 公开摘要／公开注意事项：正式公开前必须填写；
- 创建日期／最后修改日期：格式为 年-月-日；
- 创建人员：创建人员。

等级字母作为正式技术名称保留原样。

## 五、正文结构

# 资料名称

## 1. 资料基本信息

记录名称、作者或讲述者、出版或记录年代、版本。

## 2. 作者或记录者背景

记录作者的训练/职业背景（医家、修炼者、学者等）、与所记内容的利益关系（如是否推广某种方法）。

## 3. 观察方法

记录观察方式（自我观察、他人观察）、记录形式、是否有连续记录、是否有外部观察者、是否有医学检查。

## 4. 原始观察内容

**只记录观察到了什么**，不混入作者解释。例如：

> 练习时腹部出现温热感；持续时间约 X 分钟；重复出现 N 次。

## 5. 作者自己的解释

**单独记录作者认为这意味着什么**，与第 4 节严格分开。例如：

> 作者认为与某种气机变化有关。

## 6. 传统医学来源

按《医学观察资料分层规范》第一层、第二层记录：相关传统原文怎么说、历代和当代解释怎么说。

## 7. 现代医学对应候选

按第四层记录：现代医学可能的对应候选（局部血流、肌肉活动、呼吸变化、注意放大等）及其证据状态；没有证据的写"无对应研究支持"。

## 8. 独立验证情况

是否有独立验证、是否可重复、验证质量如何。

## 9. 可能的替代解释

记录该观察的替代解释（生理、心理、方法学等）。

## 10. 可以用于什么

该资料可以用于什么（描述经验、提出假说、提供待验证线索等）。

## 11. 不能用于什么

明确不能用于什么，例如：

> 不能依据该感觉确认某种器官、经络或病理状态。

> 不能用于确诊疾病或替代医学检查。

> 不能把个人观察直接推广为普遍规律。

## 12. 医学误用风险

记录误用该资料可能造成的风险（如以主观感觉替代医学检查、延误就医等）。

## 13. 待解决问题

列出尚未核实、待补录、待研究的问题。

## 14. 修改记录

| 版本 | 日期 | 修改内容 | 修改原因 | 修改人员 |
| ---- | ---- | -------- | -------- | -------- |
| 0.1  |      | 初始建立 |          |          |

## 六、填写要求

- "观察到了什么"与"作者认为这意味着什么"必须分节记录，任何一处混用都视为填写错误；
- 每条内容标注所处证据层级（第一—四层）；
- 传统医学对应只说明"传统文本怎么说"，现代医学对应候选必须有证据状态说明；
- 不出现"证明经络""确诊疾病""治疗有效"类结论表述；
- 出现异常体验按《安全边界》作安全事件记录，不解释为"突破""排病"。
