# 主张卡模板

本模板依据《基础规范 V0.3》编制。卡片属性字段统一使用中文；程序字段映射见《字段映射表 V0.3》。

模板版本：V0.4

---

主张卡用于记录一句可以被支持、限制或反驳的判断。

---

```yaml
---
编号:                      # 主张编号，示例：主张-0001
标题:                   # 主张标题
主张内容:           # 主张内容
主张类型:              # 主张类型
提出来源:         # 提出来源
关联文献:       # 涉及文献
关联概念:        # 涉及概念
文献可靠等级:        # 文献可靠等级 T1—T5
最低解释层级: # 解释等级 I1—I5
最高推论层级: # 解释等级 I1—I5
现代证据等级:         # 现代证据等级 E1—E5、EX
对应强度:        # 对应强度 M0—M4
反证状态:  # 反证状态 C0—C4
风险等级:              # 风险等级 S0—S4
当前判断:        # 当前判断
当前状态: 草稿      # 当前状态，九种中文状态之一
网站发布状态: 不公开      # 网站发布状态：不公开／内部预览／可公开草稿／正式公开／已撤回
公开摘要: 待补录      # 面向公众的公开摘要，正式公开前必须填写
公开注意事项: 待补录      # 面向公众的注意事项，正式公开前必须填写
创建日期:              # 创建日期，格式：年-月-日
最后修改日期:              # 最后修改日期，格式：年-月-日
创建人员:                 # 创建人员
最后修改人员:             # 最后修改人员

```

# 主张标题

## 1. 主张内容

用一句完整、明确、可以判断真假的话表达，避免使用无法判断的空泛表达。

> 示例：《庄子》中的“听之以气”指的是腹式呼吸。

------

## 2. 主张来源

说明谁提出、出自哪篇文章、书籍或讨论、是否来自人工智能、是否来自个人体验、是否为项目内部提出。

------

## 3. 主张类型

- 文献事实
- 历史判断
- 文字解释
- 概念关系
- 现代机制
- 实践效果
- 安全判断
- 其他

------

## 7. 适用范围

说明该主张即使成立，能够适用于哪部文献、哪个时期、哪个流派、哪类人群、哪种实践条件。

------

## 8. 不能推广到的范围

例如：不能从一部书推广到全部道家传统；不能从单一个人体验推广到所有人；不能从现代冥想研究推广到所有传统静功；不能从词义相似推断两者机制相同。

------

## 9. 风险分析

如果该主张被公众误解，可能带来什么风险？

------

## 10. 当前判断

选择：暂时支持、部分支持、证据不足、高度不确定、当前不支持、已被反驳、暂不判断。

------

## 11. 判断理由

用完整文字说明为什么得出当前判断。

------

## 12. 升级条件

什么新材料出现后，可以提高可信程度？

------

## 13. 降级或否定条件

什么结果出现后，需要降低或否定该主张？
