# 问道志视觉升级方向 V0.1（存档）

**存档日期：** 2026-08-02
**来源：** 项目负责人提供的《参考网站定位与下一版视觉方向》第六～九节
**处置状态：** 暂不执行（2026-08-02 决定）。理由：与"网站工程收尾、转向研究（80% 研究 / 20% 网站）"冲突；视觉主体依赖内容积累，当前概念卡 6 张、原文卡 6 张信息量不足。**启动条件：第一批主张/争议/风险卡建立、知识卡规模翻倍后**。期间若做只做"最近整理"区块。

---

## 一、方向定位

不建议把网站改成仙山、云雾、黑金、法阵式网站。

建议升级为：

> **现代知识图谱＋传统文献编辑设计**

即保留研究项目的可信度，同时增加中国传统书籍和档案馆的视觉语言。

核心视觉关键词：

```text
书卷、题签、印记、索引、线索、校勘、层次、关联、留白、墨与朱
```

## 二、首页建议（七屏结构）

1. **第一屏（品牌记忆点）**："问道志"竖排题签；抽象文献关系线；极淡书页格线/索引线/文字残片背景；朱红小印章。主标题"问道志"；副标题"重新整理传统修炼知识的来源、解释与边界"；只保留两个主入口："进入'静'专题""浏览知识库"。"项目说明""研究方法"不下沉为第一屏主按钮。
2. **第二屏（当前专题）**："静"做成横跨页面的大专题卡（从"守静笃"到心斋与坐忘，再到后世静坐体系）；右侧配文献关系路线：道德经 → 庄子 → 管子·内业 → 坐忘论 → 近现代解释 → 当代传播。
3. **第三屏（知识地图）**：六概念关系图（虚─静─心，身─静─气/息，仅栏目导航非理论结论）；悬停显示当前状态/已关联文献/已建立原文数/未解决问题。
4. **第四屏（研究路径）**：发现资料 → 核对原文 → 拆解概念 → 记录争议 → 对照现代研究 → 风险审查 → 形成暂定结论，每步用不同简洁图形符号。
5. **第五屏（精选文献）**：书目卡式（竖排书名、文献编号、年代、层级、已公开条目、当前审核状态）。
6. **第六屏（能确认与不能确认）**：强左右对照（"已有依据 / 尚无充分依据"），将成为品牌区块。
7. **第七屏（最近整理）**：简单动态更新区（日期 + 一句话），让网站呈现持续生长感。

## 三、详情页升级建议

- **文献页**：顶部题签式版式（编号、竖排书名、年代·层级、版本行），下方再放状态/版本/风险。
- **原文页**：原文成为视觉中心（更大宋体、更宽行距、独立暖色背景、左侧原文编号、右下角版本）；直译/注释/项目解释用不同区块。
- **概念页**：顶部"概念谱系"（如"静"的分支），每个分支标注"原文直接支持/项目整理/待核实"。

## 四、可借鉴但不要复制的元素

观察维度：首页视觉中心、大图或文化背景、卡片层次、分类入口直观度、搜索明显度、文献阅读沉浸感、品牌语言连续性。

禁止复制：黑金风、发光文字、旋转八卦、大量云雾、仙鹤道人炼丹炉堆叠、"改命/开运/筑基成功"措辞、法事商品化页面结构、效果承诺和倒计时营销。

## 五、执行顺序（将来启动时）

1. 只重做首页（品牌视觉、"静"专题大卡、概念关系图、文献书目卡、研究流程图、最近整理）；
2. 升级三张样板页（道德经文献页、"致虚极守静笃"原文页、"静"概念页），确定全站设计规范；
3. 基于三样板页规范再考虑全站推广。
