# 15-参考网站

本目录登记项目在研究中参考的外部网站（决策-0005），属于**研究辅助资料**，不是知识卡类别，不进入十种知识卡模板清单，内容不进入公开网站。

## 定位与边界

参考网站只承担三种作用：

1. 帮助发现资料（书目、篇目线索）；
2. 帮助定位原文（章节、检索）；
3. 帮助比较当代传播方式（传播观察样本）。

它自身通常不承担最终证据。外部网站资料进入项目的唯一链条：

```text
发现外部网站
→ 建立参考网站卡
→ 记录有价值的页面
→ 提取资料线索
→ 找到原始出处
→ 建立正式文献卡或原文卡
```

严禁"网站上写了 → 直接写进问道志"。

## 规则

- 网站编号从"网站-0001"开始，按收录顺序独立计数，不作废、不复用；
- 每站一张卡，字段见各卡（网站编号/名称/地址、收录与核对日期、性质与主体、参考价值、可借鉴与不建议借鉴内容、页面结构与视觉、版权与引用注意、当前处理状态）；
- "可借鉴内容"与"不建议借鉴内容"为必填核心字段，无法确认的字段标"待补录"；
- 截图存放于 assets/（命名：`网站-XXXX-页面.png`），每站至少记录：首页、导航、列表页、详情页、移动端首页；截图日期记入卡内；
- 网站电子文本不得作为正式底本；需要追溯的来源记入卡内，回到可靠整理本、影印本、学术校勘本核实；
- 与 13-参考资料/ 的边界：参考资料登记"确实支撑项目判断"的现代学术专著论文；参考网站是"发现与检索工具"，不支撑判断；
- 与 14-当代传播资料卡/ 的边界：传播资料卡登记"当代网络修炼传播材料"本身（视频、文章、课程）；参考网站卡登记"传播内容的载体站点"（含此类站点的观察样本，如网站-0003 全真法事通）。
