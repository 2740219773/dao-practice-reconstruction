# 道家修行体系图谱

## 模块定位

道家修行并非单一方法，而是在长期历史发展中形成的多层次体系。本模块用于整理不同修行路径的来源、理论、方法、历史背景及现代研究观点。

本模块不以宗派宣传为目标，而关注：

- 一个修行体系来自哪些经典和历史背景；
- 不同流派之间的关系与差异；
- 理论、方法、经验和现代解释之间的区别。

## 主要分类

### 修命体系

研究生命实践相关内容，包括内丹、精气神、筑基等。

### 修性体系

研究心性变化，包括清静、坐忘、心斋等思想和方法。

### 身体实践体系

研究导引、呼吸、养生等身体训练方法。

### 宗教实践体系

研究符箓、科仪等道教宗教实践。

### 历史技术体系

研究外丹、炼丹术及其历史影响。
