# 修行路线图

本目录建立于 V3 关系语义规范之前，当前定位调整为：**问道志的研究导航与比较框架**，不是对历史上统一存在的“道家修行路线”的直接断言。

## 现有导航

- 清修路线；
- 内丹路线；
- 养生路线；
- 路线比较；
- 路线演化关系（已进入重新审计）。

这些文件可以帮助读者选择阅读方向，但其中的箭头默认只表示“研究导航”。除非另有具体来源和关系类型，不表示：

- 师承；
- 历史因果；
- 经典直接产生后世方法；
- 所有传统共享同一先后次第。

V3 暂不把这些路线直接加入正式 `route` 节点。后续需要先增加 `route_kind` 或等价字段，以区分“历史路线”和“项目分析导航”。

详细审计见：`31-知识图谱整合/阶段与路线类型审计-v1.md`。
