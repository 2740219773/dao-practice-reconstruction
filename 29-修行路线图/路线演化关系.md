# 路线演化关系审计

## 一、文件定位

本文件旧版曾使用三组线性箭头描述“思想路线、内丹路线、养生路线”的演化。经过 V3 关系规范审计，这些箭头混合了文本、人物、思想分类、方法和现代研究导航，不能继续作为历史演化关系使用。

本页现改为**待验证关系清单**，不再直接提供单线演化图。

## 二、先秦思想相关关系

旧版：

```text
老子 → 庄子 → 清静思想 → 心性修养
```

问题：

- 老子与庄子之间不能仅凭思想相近就写成直接历史传承；
- “清静思想”“心性修养”是跨文本的分析标签，不是同一时代的组织或阶段；
- 《道德经》《庄子》内部也存在不同文本层次。

V3 处理：

- 老子、庄子分别保留人物与传统归属问题；
- “道、虚、静、心”等使用具体文本关系；
- 只有有历史材料支持时才新增 `influences` 或 `develops`。

## 三、内丹相关关系

旧版：

```text
《参同契》 → 《悟真篇》 → 丹鼎派 → 内丹 → 性命双修
```

问题：

- 《参同契》到《悟真篇》可以讨论文本和概念影响，但不等于形成一条完整宗派师承；
- “丹鼎派”已经在 V3 中改为“丹道传统”，不是统一组织；
- “内丹”是复杂的历史实践传统，不是由单一经典一次产生；
- “性命双修”更适合作为后世内丹理论原则，不是固定末端阶段。

V3 当前只保留已有证据支持的具体关系，例如：

```text
《参同契》 --influences--> 《悟真篇》
```

其余关系逐项核对，不自动串联。

## 四、养生相关关系

旧版：

```text
《黄帝内经》 → 气血观 → 导引 → 吐纳 → 身体调养
```

问题：

- 《黄帝内经》是传统医学经典，不是所有导引或呼吸传统的唯一来源；
- 导引有独立的早期出土资料传统；
- 导引与吐纳可在部分语境中结合，但不是必然先后阶段；
- “身体调养”是现代概括性标签，不是一个可直接作为历史终点的实体。

V3 处理：

- 《黄帝内经》、导引、吐纳分别建立独立节点；
- 只有能定位到具体文献时，才建立更强的来源或影响关系；
- MEDOBS 继续冻结，不能由本路线自动连接或解锁。

## 五、当前结论

本项目暂不维护一张“道家修炼总演化树”。

更合适的结构是：

```text
具体节点
+
明确关系类型
+
适用时期/文本范围
+
来源
+
争议状态
```

由这些可审计关系动态形成知识图，而不是先画一条方便理解的直线，再反过来寻找证据。

详细类型决策见：`31-知识图谱整合/阶段与路线类型审计-v1.md`。
