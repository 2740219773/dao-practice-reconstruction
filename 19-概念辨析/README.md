# 19-概念辨析

本目录存放"辨析卡"（编号前缀"辨析卡-"，辨析卡-0001 起）：专门处理容易混淆的概念对（道家与道教、无为与不作为、坐忘与冥想等）。

## 规则

- 每张辨析卡固定处理**一对或一组易混概念**，回答：共同点、核心差异、历史关系、现代常见误用、是否可以互相替代；
- 模板见 01-知识卡模板/辨析卡模板.md；
- 辨析卡必须标注「来源可信等级」；
- 辨析结论不提前合并：差异与误用都须有来源依据；
- 辨析卡是 AI 术语判断的基础规则来源，术语使用必须以此为准，防止混用。
