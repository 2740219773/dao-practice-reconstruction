# 正一道

## 一、传统定位

正一道是道教历史中的重要长期传统。为了避免把不同历史阶段的天师道、正一盟威、龙虎山天师制度和后世正一教团完全压成一个静态组织，V3 使用：

```yaml
school_kind: religious_tradition
```

而不是把它与十二世纪形成的全真道完全按同一种宗派模型处理。

## 二、与天师道的历史关系

东汉二世纪形成的天师道是中国制度化道教早期最重要的宗教共同体之一。早期文献显示，“正一盟威”等名称和制度元素已经出现在天师传统中。

但从东汉早期天师共同体到后世龙虎山正一传统，经历了：

- 地域迁移；
- 组织变化；
- 仪式整合；
- 经典与授箓体系变化；
- 不同时期的国家与地方宗教关系。

因此不能画成一条未经说明的：

```text
张道陵 → 正一道 → 今天正一道
```

完全不变的直线。

## 三、与符箓科仪的关系

正一传统与符箓、章表、斋醮、授箓等宗教实践关系非常密切，因此可以建立与 `method.fulu_keyi` 的一般关联。

但以下表达过于简单：

```text
正一道 = 符箓
```

因为正一传统还涉及组织制度、戒律、经典、神谱、地方宗教服务和历史身份等多重内容。

## 四、与全真道的比较

后世和现代常把“全真—正一”作为道教两大传统进行比较，这种比较有导航价值，但不能机械化为：

```text
全真 = 出家 + 内丹
正一 = 在家 + 符箓
```

历史上不同地区、时期和支派的实践存在大量交叉和变化。

问道志将比较维度拆开记录：

- 组织制度；
- 出家/家族与传承方式；
- 仪式；
- 内修；
- 授箓；
- 地域发展。

## 五、研究边界

- 不能用现代宫观现状替代整个正一道历史；
- “天师道”“正一盟威”“龙虎山正一”需在具体时期下区分；
- 符箓科仪属于宗教史与仪式研究对象，不转写成宣称超自然效果的操作指南；
- 与民间宗教、地方仪式传统的交叉需要单独研究。
