# 天师道

## 一、传统定位

天师道是研究中国早期制度化道教形成时必须单独建立的节点。

它不是“先秦道家思想”的另一个名字，也不是单纯的个人养生术。二世纪的天师共同体已经表现出较明确的宗教组织、共同体身份、教区、宗教职司、戒律和仪式生活。

V3 因此使用：

```yaml
school_kind: religious_tradition
```

## 二、形成时期

现代研究把早期天师道的形成放在东汉二世纪的巴蜀地区，并进一步发展到汉中。

内部传统把张陵/张道陵接受启示作为创建叙事核心，部分早期内部文献把关键日期置于142年。与此同时，外部史料、后世传记与内部文献在人物称谓和细节上并不完全一致。

因此后续若建立张道陵人物节点，需要继续区分：

- 早期可考资料；
- 天师传统内部记忆；
- 葛洪等后出传记；
- 更晚的神圣祖师叙述。

## 三、宗教共同体特征

天师道不能被缩减成“练气”或“符咒”。早期材料涉及：

- 教区与共同体组织；
- 祭酒等宗教职司；
- 戒律与道民身份；
- 请祷、章表等仪式；
- 授箓和宗教身份；
- 《老子》及相关宗教解释；
- 共同体伦理和疾病/罪责解释。

这些内容共同说明，它首先是一种组织化宗教生活传统。

## 四、与正一道的关系

这是本节点最需要防止简化的地方。

早期天师传统中已经出现“正一盟威”等重要术语，后世正一道与天师传统也存在明确历史联系。但两千年间经历了传播、地域变化、仪式重组、授箓体系演变及龙虎山传统的发展。

所以当前只建立：

```text
天师道 related_to 正一道
```

并在 `scope` 中说明历史来源关系。

不写成：

```text
东汉天师道 = 后世正一道 = 当代正一道
```

## 五、与符箓科仪的关系

早期天师共同体已有制度性仪式、章表、请祷和授箓等实践，因此与 `method.fulu_keyi` 存在重要历史关联。

但后世成熟的斋醮、符箓和科仪体系包含上清、灵宝、地方传统及不同时期的整合，不能全部反投射到东汉。

## 六、与“道家”的区别

先秦“道家”在 V3 中属于后起思想史分类；天师道则属于汉代以后具有宗教共同体和制度实践的道教传统。

两者可以共享、解释或重新组织《老子》等思想资源，但不能因为都出现“道”字，就当成同一个历史组织。

## 七、研究边界

- 不把后世神仙传记全部当作二世纪历史事实；
- 不把现代正一道宫观制度直接反投射到东汉；
- 不把早期请祷与疗病实践当作现代医疗有效性证明；
- 具体仪式文本以后按年代和来源单独建卡。

## 八、关联节点

- `school.zhengyi`：正一道
- `method.fulu_keyi`：符箓科仪
- 后续：张道陵、张鲁、《老子想尔注》、正一盟威、授箓制度
