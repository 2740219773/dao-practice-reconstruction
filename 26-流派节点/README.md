# 流派与传统节点

本目录名称暂保留“流派节点”，用于兼容现有路径；但从 V3 起，本目录不再假设所有对象都是同一种“门派”。

## 一、为什么需要细分

当前目录同时包含：

- 先秦道家；
- 黄老思想；
- 丹道传统；
- 全真道；
- 正一道。

它们的性质并不相同：有的是后世思想史分类，有的是早期汉代思想政治传统，有的是跨宗派修炼传统，有的是具有组织制度的宗教宗派。

因此，所有新版 `school` 节点必须使用 `school_kind`。

## 二、第一阶段分类

| 节点 | `school_kind` | 说明 |
| --- | --- | --- |
| 先秦道家 | `intellectual_tradition` | 后世思想史分类，不表示老子、庄子自称属于统一宗派 |
| 黄老思想 | `intellectual_tradition` | 战国末至汉初相关思想传统，具体边界存在学术讨论 |
| 丹道传统（兼容名：丹鼎派） | `practice_tradition` | 炼丹、外丹、内丹相关的跨时代实践与文本传统，不视为单一连续教团 |
| 全真道 | `religious_order` | 十二世纪形成、具有教团与宗派组织意义的道教运动 |
| 正一道 | `religious_tradition` | 与天师道、正一盟威及后世龙虎山正一传统相关的长期宗教传统，不能压成单一时期组织 |

## 三、统一关系原则

原来的：

```text
流派 → 人物 → 经典 → 思想 → 方法 → 实践
```

只能作为知识导航，不能自动解释为历史传承。

新版按照具体对象分别使用：

- `founded`：较明确的宗教运动创建关系；
- `belongs_to`：人物或节点的有依据归属；
- `related_to`：一般关联；
- `influences`：有历史证据的影响；
- `practices`：有直接材料支持的实践关系。

## 四、当前明确禁止的简化

不再建立以下无条件关系：

```text
老子 founded 先秦道家
魏伯阳 founded 丹鼎派
张伯端 founded 丹鼎派
张伯端 → 王重阳
全真道 = 内丹
正一道 = 符箓
```

这些表达要么把后起分类历史化，要么把复杂宗教传统缩减成一种技术。

## 五、后续扩展

完成本批分类后，再继续迁移：

- 上清传统；
- 灵宝传统；
- 天师道；
- 内丹南宗等后世内丹谱系。

新增对象前先判断它属于思想传统、宗教宗派、宗教传统还是修炼传统，不再因为都与道教相关就统一放进“门派”。
