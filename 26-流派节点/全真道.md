# 全真道

## 一、宗派定位

全真道是十二世纪北方形成的重要道教运动，后来发展为影响深远的宗教宗派。

在 V3 分类中：

```yaml
school_kind: religious_order
```

这意味着它与“先秦道家”“黄老思想”“丹道传统”不同：全真具有比较明确的历史创建过程、人物群体、组织发展和宗派身份。

## 二、王重阳与全真创建

王重阳是早期全真运动的创建人物，因此规范关系可以使用：

```text
王重阳 founded 全真道
```

第一代弟子随后推动了全真的传播和发展。

但是，创建关系不能自动推出后世所有支派和神圣谱系都在王重阳时代已经固定。

## 三、祖师谱系的历史层次

后世全真形成了“五祖七真”等著名谱系。现代研究提示，祖师崇拜、墓葬、仪式和宗派制度共同参与了十三世纪全真谱系的建构。

因此图谱要区分：

- 王重阳与第一代弟子的历史关系；
- 后世祖师神圣谱系；
- 龙门等具体支派的组织传承；
- 文本上的思想影响。

不能把它们压成一棵完全等同历史事实的“师承树”。

## 四、全真与内丹

全真与内丹传统关系密切，但全真并不等于内丹本身。

全真宗教生活还包括：

- 戒律与伦理；
- 教团生活；
- 诗文与教化；
- 仪式与宗教组织；
- 祖师崇拜和支派传承。

所以本项目只建立：

```text
全真道 related_to 内丹
```

不写：

```text
内丹 = 全真道
```

## 五、与张伯端及“南宗”的关系

张伯端和《悟真篇》属于北宋内丹史的重要节点，后世形成南宗祖师谱系；王重阳及全真则属于另一历史背景。

二者在内丹史上可以比较和研究，但当前没有证据支持把它们写成：

```text
张伯端 → 王重阳 → 全真道
```

的直接传承链。

## 六、与正一道的关系

全真道和正一道常在后世、尤其近现代叙述中作为道教的重要传统并列，但两者内部都经历长期变化。

问道志不采用“全真只内丹、正一只符箓”“全真都出家、正一都在家”等绝对二分。具体时期、地区和仪式实践必须独立研究。

## 七、研究边界

- 武侠小说中的王重阳和全真形象不作为历史证据；
- 现代某一宫观的做法不能自动代表全部历史全真；
- 内丹、戒律、科仪、出家制度等需按时期和支派分别核对；
- 神圣祖师谱系与可考历史师承必须分层。
