## 六、关系卡模板

```yaml
id: relation.source_target
type: research
name: 起点与终点关系
status: draft
relation_card:
  source: concept.source
  target: method.target
  relation: related_to
  scope: 适用范围
  evidence: C
  source_refs: []
  disputed: false
sources: []
```

关系卡必须解释“为什么有关”，不能只写两个节点名称。

## 七、发布前检查

- [ ] `id` 全库唯一
- [ ] `type` 正确
- [ ] 有一句话定位
- [ ] 至少一个来源
- [ ] 至少两个有效关联节点
- [ ] 重要判断有证据等级
- [ ] 传统解释与现代研究已区分
- [ ] 争议问题已标记
- [ ] 方法类节点已检查风险与边界
- [ ] 节点命名与现有知识图谱一致
