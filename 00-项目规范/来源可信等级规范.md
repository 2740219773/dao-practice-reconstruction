# 道修重构计划来源可信等级规范（甲乙丙丁）

**项目名称：** 道修重构计划
**文档名称：** 来源可信等级规范
**文档版本：** V0.1
**制定日期：** 2026年8月3日
**文档定位：** 面向公众与检索的**来源可信等级**（甲/乙/丙/丁/待考/禁用），与《证据等级规范》的 T/I/E/M/R/C/S 多维证据体系**并行使用、用途分工明确**，不互相替代。

---

## 一、为什么需要第二套等级

- T/I/E 体系是**研究内部的多维证据标注**（文献可靠度、解释层级、现代证据等级），专业、精确，但面向普通访问者不易快速理解；
- 甲乙丙丁是**来源可信度的直观分级**，用于公开页面、问题地图与辨析内容的"可信度标签"，让访问者一眼知道一条内容的分量；
- 两者关系：卡片 YAML 的证据字段（T/I/E 等）保持不变；**甲乙丙丁作为独立字段**（来源可信等级）与卡片并存，由人工依据证据字段综合判定后填写。

> 甲乙丙丁不是 T/I/E 的简化版，二者视角不同：T/I/E 问"这条判断的证据有多强"，甲乙丙丁问"这条内容的来源有多可信"。一张卡可以同时有"文献可靠等级 T2"（底本可靠）与"来源可信等级 乙级"（注疏互证）——两套字段各自独立填写。

---

## 二、六个等级定义

| 等级 | 定义 | 典型来源 | 公开页展示 |
| ---- | ---- | ---- | ---- |
| 甲级 | 有明确经典、文献或高质量学术依据 | 经典原文、权威点校整理本、高质量学术论著 | 甲（权威来源） |
| 乙级 | 有传统注疏、多个可靠来源相互印证 | 历代注疏、多版本互证、多个独立可靠来源一致 | 乙（注疏互证） |
| 丙级 | 特定宗派或教师观点，适用范围有限 | 宗派内部资料、某派传承解释、单一流派主张 | 丙（特定传承） |
| 丁级 | 社区经验、个人体验、现代解释 | 社区讨论、个人体验记录、现代大众解读 | 丁（体验/大众） |
| 待考 | 来源不足、存在明显争议 | 来源不明、相互矛盾、仅见转述 | 待考（待核实） |
| 禁用 | 已知错误、伪造引用或危险内容 | 已被证伪、伪造引文、危险操作、医疗承诺 | 禁用（不采用） |

### 分级规则

1. **甲级**：内容可直接溯源到经典原文或高质量学术依据；若涉及版本差异，须说明所依据版本；
2. **乙级**：多个可靠来源（≥2 个相互独立）印证一致；单一条来源不足以上甲级时可为乙级；
3. **丙级**：明确标注属于哪一宗派/哪一位教师/哪一流派的观点，适用范围限于该传承语境；
4. **丁级**：社区经验与个人体验**只作问题与需求样本**，进入正式知识区时必须有"现代参照，不等同于传统原义"标记；
5. **待考**：无法核实、存在明显矛盾或证据链断裂；
6. **禁用**：已知错误、伪造引用、危险内容、医疗功效承诺——**禁用级内容不进入正式知识区**，如需存档走 99-待考与隔离区（或 12-待处理资料），标记"仅研究记录，不公开"。

### 等级迁移

- 来源可信等级随证据字段变化而更新（如某观点从"待考"获得权威文献支撑后升为"甲级"）；
- 迁移必须记录修改记录，注明依据；
- 一张卡整体有一个等级；卡内不同来源部分可分别标注（如"正文甲级，某注释丁级"）。

## 三、与现有体系的关系

| 维度 | 证据等级规范（T/I/E/M/R/C/S） | 本规范（甲乙丙丁） |
| ---- | ---- | ---- |
| 视角 | 判断的证据强度 | 来源的可信程度 |
| 使用者 | 研究内部标注 | 公开页/问题地图/辨析内容展示 |
| 填写 | 卡片 YAML 必填字段 | 卡片 YAML 新增字段「来源可信等级」 |
| 关联 | 决定甲乙丙丁的依据之一 | 综合 T/I/E 与来源类型判定 |

### 来源类型（方案第八节对应）

| 来源类型 | 项目中的作用 | 通常等级 |
| ---- | ---- | ---- |
| 经典原文 | 第一层原始材料 | 甲级 |
| 历代注疏 | 传统解释依据 | 乙级 |
| 正史、道藏及历史文献 | 历史事实依据 | 甲/乙级 |
| 现代学术研究 | 考证和解释依据 | 甲/乙级 |
| 宗派内部资料 | 特定传承观点 | 丙级 |
| 教师口述或课程 | 实践经验 | 丙/丁级 |
| 社区讨论 | 问题与观点样本 | 丁级 |
| 个人体验 | 个案记录 | 丁级 |
| AI 整理 | 辅助整理，不作为独立来源 | 不得单独定级（须人工复核后并入对应来源） |

---

## 四、填写位置

- 新增卡片 YAML 字段：`来源可信等级: 甲级`（取值：甲级／乙级／丙级／丁级／待考／禁用）；
- 字段映射表同步登记（程序字段 `source_credibility`）；
- 公开页在元信息区展示该标签；
- 问题地图与辨析卡**必须**标注可信等级，防止把丁级体验写成甲级结论。
