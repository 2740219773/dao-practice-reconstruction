# 道修重构计划来源可信等级规范 V0.2

**项目名称：** 道修重构计划
**文档名称：** 来源可信等级规范
**文档版本：** V0.2
**制定日期：** 2026年8月3日（V0.2 修订同日）
**文档定位：** 面向公众与检索的**来源可信等级**（甲/乙/丙/丁）。内部多维证据体系（T/I/E/M/R/C/S）**继续保留**（见《项目结构总图》与决策-0006 修订）；甲乙丙丁仅作为**公开展示的简化标签**，不替代解释层级、现代证据与反证状态。

---

## 一、三个字段，三个维度（V0.2 核心修订）

V0.1 曾把"甲/乙/丙/丁 + 待考 + 禁用"放在一个枚举中，造成语义混叠（"待考"是核对状态、"禁用"是处置结果，都不是来源可信度）。V0.2 拆为**三个独立字段**：

```yaml
来源可信等级: 甲级      # 甲级／乙级／丙级／丁级（来源本身的可信程度）
来源核对状态: 待核对   # 未核对／待考／已核对／存在争议（核对进度）
项目采用状态: 采用     # 采用／限制使用／仅研究记录／禁用（项目处置结果）
```

| 字段 | 回答的问题 | 取值 |
| ---- | ---- | ---- |
| 来源可信等级 | 来源本身是否可靠 | 甲级／乙级／丙级／丁级 |
| 来源核对状态 | 资料核对到哪一步 | 未核对／待考／已核对／存在争议 |
| 项目采用状态 | 项目如何处理该内容 | 采用／限制使用／仅研究记录／禁用 |

三个字段互相独立：一条来源可靠（甲级）但含危险操作的经典原文，可标「甲级 / 已核对 / 限制使用」；一个已被证伪但有研究价值的案例，可标「丙级 / 存在争议 / 仅研究记录」。

危险内容的风险判断由 S 级风险体系（S0—S4）负责，**不由"禁用"等级承担**。

## 二、来源可信等级（甲/乙/丙/丁）

| 等级 | 定义 | 典型来源 | 公开页展示 |
| ---- | ---- | ---- | ---- |
| 甲级 | 有明确经典、文献或高质量学术依据 | 经典原文、权威点校整理本、高质量学术论著 | 甲（权威来源） |
| 乙级 | 有传统注疏、多个可靠来源相互印证 | 历代注疏、多版本互证、多个独立可靠来源一致 | 乙（注疏互证） |
| 丙级 | 特定宗派或教师观点，适用范围有限 | 宗派内部资料、某派传承解释、单一流派主张 | 丙（特定传承） |
| 丁级 | 社区经验、个人体验、现代解释 | 社区讨论、个人体验记录、现代大众解读 | 丁（体验/大众） |

### 分级规则

1. **甲级**：内容可直接溯源到经典原文或高质量学术依据；若涉及版本差异，须说明所依据版本；
2. **乙级**：多个可靠来源（≥2 个相互独立）印证一致；单一条来源不足以上甲级时可为乙级；
3. **丙级**：明确标注属于哪一宗派/哪一位教师/哪一流派的观点，适用范围限于该传承语境；
4. **丁级**：社区经验与个人体验**只作问题与需求样本**，进入正式知识区时必须有"现代参照，不等同于传统原义"标记。

### 等级迁移

- 来源可信等级随证据变化而更新，迁移须记录修改记录与依据；
- 一张卡整体有一个等级；卡内不同来源部分可分别标注。

## 三、来源核对状态

| 取值 | 含义 |
| ---- | ---- |
| 未核对 | 尚未进行来源核对 |
| 待考 | 来源不足、存在明显矛盾或证据链断裂，无法核实 |
| 已核对 | 来源已确认，版本/出处/页码已核 |
| 存在争议 | 多个来源相互矛盾，尚未裁定 |

---

## 四、项目采用状态

| 取值 | 含义 | 处理方式 |
| ---- | ---- | ---- |
| 采用 | 进入正式知识区 | 正常公开流程 |
| 限制使用 | 部分可用（如含危险操作、特定语境） | 按 S 级风险分级处理，限制公开范围 |
| 仅研究记录 | 已被证伪/失效/个案，但有研究价值 | 存档于待考区或研究记录，不公开为知识 |
| 禁用 | 已知错误、伪造引用、危险内容、医疗承诺 | 不进入正式知识区；如存档走待考区，标记"仅研究记录，不公开" |

## 五、与内部多维证据体系的关系（决策-0006 修订后）

| 维度 | 用途 | 公开页 |
| ---- | ---- | ---- |
| 来源可信等级（甲/乙/丙/丁） | 来源本身是否可靠 | **默认展示** |
| 来源核对状态 | 核对进度 | 展示（与引文核对状态并列） |
| 项目采用状态 | 处置结果 | 按需展示 |
| 解释层级（I1—I5） | 判断离原文字面有多远 | 折叠或内部使用 |
| 现代证据等级（E1—E5） | 现代研究证据强弱 | 折叠或内部使用 |
| 反证状态（C0—C4） | 是否存在反方材料 | 折叠或内部使用 |
| 风险等级（S0—S4） | 实践风险 | **默认展示（风险提示）** |

> 内部研究：保留 T/I/E/M/R/C/S 多维字段。
> 公开展示：默认只展示甲乙丙丁来源标签、核对状态和风险提示；详细证据字段折叠展示或仅供内部使用。

## 六、来源类型（参考）

| 来源类型 | 项目中的作用 | 通常等级 |
| ---- | ---- | ---- |
| 经典原文 | 第一层原始材料 | 甲级 |
| 历代注疏 | 传统解释依据 | 乙级 |
| 正史、道藏及历史文献 | 历史事实依据 | 甲/乙级 |
| 现代学术研究 | 考证和解释依据 | 甲/乙级 |
| 宗派内部资料 | 特定传承观点 | 丙级 |
| 教师口述或课程 | 实践经验 | 丙/丁级 |
| 社区讨论 | 问题与观点样本 | 丁级 |
| 个人体验 | 个案记录 | 丁级 |
| AI 整理 | 辅助整理，不作为独立来源 | 不得单独定级（须人工复核后并入对应来源） |

## 七、填写位置

- 正式知识层与用户入口层卡片填写「来源可信等级」；采集观察层与治理记录层不填写（见《项目结构总图》）；
- 问题卡**不填写**来源可信等级（问题本身无可信度），改填「答案依据等级」与「答案依据」（见问题卡模板）；
- 社区观察卡、AI 审校记录卡、项目决策**不填写**来源可信等级（非知识卡）；
- 字段映射表同步登记三字段的程序映射。
