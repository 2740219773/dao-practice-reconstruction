# 知识图谱来源字段规范

## 一、目的

为知识图谱中的节点和关系建立来源追踪机制，避免知识关系只有结论而缺少依据。

## 二、来源字段

每个重要知识节点建议包含：

```yaml
source:
  - type: classic
    name: 经典名称
    reference: 章节或位置
```

## 三、来源类型

### classic

经典文献来源。

例如：

- 《道德经》
- 《庄子》
- 《悟真篇》

### historical

历史研究资料。

包括：

- 学术研究
- 历史考证
- 流派研究

### traditional

传统流派解释。

用于记录：

- 丹家解释
- 道教内部观点
- 师承体系观点

### modern

现代研究。

包括：

- 哲学分析
- 文化研究
- 身心科学研究

## 四、关系来源

知识关系也应记录来源。

例如：

```yaml
from: concept.qi
to: system.neidan
relation: related_to
source:
  - 悟真篇
```

## 五、原则

- 来源和观点分离；
- 传统解释不等同现代事实；
- 不明确来源的内容标记待考证；
- AI生成内容必须经过来源检查。
