# 决策记录模板

本模板依据《基础规范 V0.6》编制。属性字段统一使用中文；程序字段映射见《字段映射表》。

模板版本：V0.5

---

决策记录用于保存项目的重要规则变化和判断变化。决策属于**治理审校层（治理记录，非知识卡）**（《项目结构总图》）：不填写知识证据字段（文献可靠等级/解释层级/现代证据等级/反证状态/风险等级），不进入知识卡统计与公开流程。

---

```yaml
---
编号:                      # 决策编号，示例：决策-0001
标题:                   # 决策标题
决策类型:           # 决策类型
提出日期:             # 提出日期，格式：年-月-日
生效日期:            # 生效日期，格式：年-月-日
提出人员:                # 提出人员
参与讨论人员:            # 参与讨论人员
影响范围:            # 影响范围
当前状态: 草稿      # 决策审核状态：草稿／已审核／需要修订／已归档（治理记录状态，非知识卡状态机）
关联文献:       # 关联文献
关联原文:           # 关联原文
关联概念:        # 关联概念
关联主张:          # 关联主张
关联假说:      # 关联假说
创建日期:              # 创建日期，格式：年-月-日
最后修改日期:              # 最后修改日期，格式：年-月-日
创建人员:                 # 创建人员
---
```

> **旧版遗留说明（V0.5 起）：** 决策记录不再填写「文献可靠等级／最低解释层级／最高推论层级／反证状态／风险等级」等知识证据字段（决策-0006 修订、框架收口）。已有决策-0001～0006 中保留的这些字段为**旧版遗留，不再使用**，等 TOPIC-001 完成后统一迁移清理，不逐张修改。

# 决策标题

## 1. 原有做法或原有判断

说明修改前项目是怎样处理的。

------

## 2. 发现的问题

说明原有判断哪里不准确、是否出现新文献、是否发现概念混淆、是否出现反例、是否存在安全风险、是否由外部审核指出。

------

## 3. 可选方案

### 方案一

**内容：**

**优点：**

**问题：**

### 方案二

**内容：**

**优点：**

**问题：**

------

## 4. 最终决定

明确写出项目采用的新做法。

------

## 5. 决定依据

列出：原始文献、历代注释、现代研究、逻辑分析、安全要求、外部审核意见。

------

## 6. 反对意见

记录没有被采纳的不同意见，不能只保留最终获胜的观点。

------

## 7. 影响范围

列出需要修改的内容：项目章程、证据等级规范、安全边界、文献卡、原文卡、概念卡、主张卡、假说卡、网站内容、人工智能规则、其他。

------

------

## 9. 生效说明

说明从什么时间开始执行、旧内容如何处理、是否保留旧版本、是否需要发布公开说明。

------

## 10. 后续复审条件

在什么情况下重新讨论这项决定？
