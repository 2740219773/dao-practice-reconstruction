## 一、核心定位

> **面向现代人的道家知识整理、修习引导与个人实践记录平台。**

主要解决五个问题：

1. 道家内容从哪里开始学；
2. 不同典籍、流派和说法是什么关系；
3. 理论如何转化为可执行的日常实践；
4. 如何记录自己的学习与修习过程；
5. 如何避免伪知识、混杂信息和过度神秘化。

**中心不是"问一个问题，得到一个卦象"，而是：**

> 了解一个概念，学习一套方法，进行一次实践，记录实际感受，再回过头修正自己的认识。

## 三、关键页面结构与内容分层

### 1. 学道（知识页）——"短课 + 图示 + 深入阅读"结构

以"什么是无为"为例，不直接放长文，而分层：

```text
一句话理解 → 它不是什么 → 原典中的含义 → 历代解释
→ 现代常见误解 → 生活中的应用 → 延伸阅读
```

### 2. 典籍（单篇）统一结构

```text
原文 → 字词解释 → 白话译文 → 历代注解 → 问道志整理
→ 相关概念 → 相关修习 → 参考来源
```

参考做法：原文、现代解释、智能内容、个人记录**分别标识**。

### 3. 修习（可执行流程，非文章）

```text
修习目的 → 适合人群 → 前置准备 → 操作步骤 → 时间与频率
→ 正常反应 → 异常情况 → 停止条件 → 记录模板 → 参考来源
```

参考做法：安静仪式感、一页一个主要动作；进入一次十分钟静坐时可临时隐藏普通导航，只保留"当前步骤／剩余时间／简短提示／提前结束／完成后记录"。

**阶段性定位（2026-08-03 明确）：** 当前以道家概念、典籍和修习知识的研究整理为主；经过风险审核的实践内容将逐步建立，**不把"修习引导"表达成已经具备的主要能力**。

**修习内容与网站处理（沿用项目《安全边界 V0.2》A—D 分类，不另设分级）：**

| 项目分类（安全边界 V0.2） | 定义 | 网站处理 |
| ---- | ---- | ---- |
| A 类：纯知识研究 | 古籍整理、文献校对、概念分析、历史研究 | 可以公开 |
| B 类：自然状态观察 | 记录正常作息/自然呼吸/日常情绪，不改变呼吸、姿势、饮食 | 经隐私与记录规范审核后提供 |
| C 类：主动身心干预 | 主动调整呼吸、持续意守、较长时间静坐、特定导引 | 完整风险审核＋专业审核后才能决定是否提供 |
| D 类：高风险或禁止性活动 | 闭气、胎息、辟谷、丹药、强力意念、长时间闭关等 | 只作文献和风险研究，不提供教程 |

> **说明（2026-08-03）：** 不再另设网站自己的 A/B/C 分级——项目《安全边界 V0.2》已有 A—D 活动分类，两套体系易混淆（如"普通舒展""短时间放松"可能已属主动干预，不一定属于安全规范的 B 类）。修习模块直接沿用项目分类，网站只做"公开／审核后提供／不提供"的处理映射。C 类与 D 类的边界判定以安全边界 V0.2 §3 为准。

### 4. 志录（单次记录字段）

```yaml
日期与时间 / 修习项目 / 时长 / 修习前状态 / 修习中感受 / 修习后状态
身体反应 / 心理变化 / 是否出现不适 / 下一次调整 / 关联知识或典籍
```

长期可生成：本月次数、平均时长、持续情况、反复出现的问题与身体感受、主题变化、阶段性总结。

## 四、产品主线（三条）

| 主线 | 路径 |
| ---- | ---- |
| 知识线 | 概念 → 人物 → 流派 → 典籍 → 专题研究 |
| 实践线 | 准备 → 入门 → 单项练习 → 阶段计划 → 复盘调整 |
| 个人线 | 阅读记录 → 修习记录 → 问题记录 → 阶段总结 → 个人知识体系 |

**易学与卜筮只属于知识线中的一个专题分支，不参与产品主线控制。**

## 五、借鉴清单（来自参考网站，剥离卜卦核心后）

> 参考来源：网站-0005 Yi Path（https://i-ching-three.vercel.app/，2026-08-03 收录于 15-参考网站/）。该站以起卦为首页入口，**不作为内容定位参考**，仅借鉴其界面与交互。其站内声明"use the Yijing as a mirror for reflection—not a promise about the future"（以易为镜作反思，不作未来承诺）与"your questions and journal stay on this device"（问题与日志留在本机）分别对应下表"占问定位声明"与"尊重隐私"两项。

| 借鉴项 | 说明 |
| ---- | ---- |
| 安静克制的视觉语言 | 纸色、墨色、青玉色、少量铜色；视觉重心在阅读/思考/修习/记录 |
| 分场景页面氛围 | 首页开阔平静／学道清晰结构化／典籍近阅读器／修习简洁弱干扰／志录温和有时间积累感／易学工具克制说明性强 |
| 内容逐层展开 | 简明解释 → 原典 → 注解 → 争议 → 深入研究 |
| 学习—实践—记录闭环 | 学到概念 → 找到实践 → 完成练习 → 写下感受 → 回看原典 → 修正理解 |
| 明确内容来源 | 每篇标明：典籍／章节／版本／注家／历史材料或现代整理／是否争议／是否人工校核 |
| 尊重隐私 | 笔记与修习记录优先本地保存，支持导出备份，不强制注册（参考 Yi Path"记录留在本机"） |
| 一页一个主要动作 | 主流程单页化、弱干扰导航（参考 Yi Path 起卦流程页；用于修习页专注模式） |
| 占问定位声明 | 易学工具页明确"不作未来承诺、不替用户作重大决定"（参考 Yi Path 站内声明） |

**不借鉴：** 以起卦作首页入口、以占问作核心流程、以卦象结果作内容中心、过度强调仪式与预测体验。
