## 2. 统一编号体系

### 2.1 规则

卡片编号格式统一为：

```text
类别前缀-四位流水号
```

| 卡片类别 | 前缀 | 示例 |
| -------- | ---- | ---- |
| 文献卡 | 文献 | 文献-0001 |
| 原文卡 | 原文 | 原文-0001 |
| 概念卡 | 概念 | 概念-0001 |
| 主张卡 | 主张 | 主张-0001 |
| 假说卡 | 假说 | 假说-0001 |
| 争议卡 | 争议 | 争议-0001 |
| 现代研究卡 | 现代研究 | 现代研究-0001 |
| 风险资料卡 | 风险资料 | 风险资料-0001 |
| 决策记录卡 | 决策 | 决策-0001 |
| 参考资料 | 参考资料 | 参考资料-0001 |
| 当代传播资料卡 | 传播资料 | 传播资料-0001 |

参考资料编号用于登记现代学术专著、论文、工具书等支撑项目判断的文献，暂不新增卡片类型，集中登记于 13-参考资料/ 索引中（条目字段见《字段映射表 V0.2》第 8 节）。卡片正文引用格式：`（参考资料-0001）`。

当代传播资料卡（决策-0003 确认）用于登记视频、网络文章、网络课程等当代网络修炼传播材料，存放于 14-当代传播资料卡/，暂存区见 12-待处理资料/当代传播资料/。

### 2.2 规则说明

- 流水号按类别独立计数，从 0001 开始，**不作废、不复用**；被废弃卡片的编号保留，状态标记为"不予采用"或"已归档"；
- 决策记录卡的日期由 YAML"提出日期"字段记录，不写入编号；
- 文献归属（某原文卡属于哪部文献）通过 YAML"所属文献编号"字段关联，不依赖编号；
- 当某一类别卡片超过 100 张时，可升级为加文献简称的编号（如 `原文-庄子-0001`），升级需先发决策记录卡；
- 其他文件中的 SRC-0001、PAS-0001、CON-QI-001、DEC-2026-001 等编号写法**一律作废**，不进入正式卡片。

## 3. 统一状态名称

### 3.1 卡片状态（9 个，中文）

| 序号 | 状态 | 含义 | 英文对照（仅作技术映射） |
| ---- | ---- | ---- | ------------------------- |
| 1 | 草稿 | 卡片刚建立，内容可能不完整 | draft |
| 2 | 待核对 | 原文、出处、版本或引用尚未完成核对 | source_pending |
| 3 | 来源已核对 | 原始资料已确认，解释仍未审核 | source_verified |
| 4 | 待解释审核 | 原文可靠，翻译、解释或概念关系待审查 | interpretation_pending |
| 5 | 待综合审核 | 内容基本完成，等待整体审核 | review_pending |
| 6 | 已审核 | 符合当前版本规则，可进入正式知识库 | reviewed |
| 7 | 需要修订 | 已发现问题，需要修改 | revision_required |
| 8 | 不予采用 | 存在严重来源、逻辑或安全问题 | rejected |
| 9 | 已归档 | 被新版本取代，保留用于追溯 | archived |

### 3.2 使用规则

- 正式卡片必须填写"当前状态"；
- "已审核"不代表永久正确，只表示符合当前版本标准；
- 状态只允许按流程顺序迁移（草稿 → 待核对 → 来源已核对 → 待解释审核 → 待综合审核 → 已审核），出现问题时转入"需要修订"；严重问题直接"不予采用"；
- 状态迁移必须同步更新"最后修改日期"和"修改记录"。

## 4. 统一 YAML 写法

### 4.1 规则

- **键用中文**（研究正文与元数据统一使用中文表达；程序读取需求由《字段映射表 V0.2》单独维护）；
- **值用中文**（含状态、类型、类别等枚举）；
- 字母等级（T1—T5、I1—I5、E1—E5、EX、M0—M4、R0—R5、C0—C4、S0—S4）作为正式技术名称保留原样；
- 正文一律中文，不中英混排；软件名（Obsidian、GitHub、Markdown、YAML、VitePress、Zotero）允许出现；
- 中文字段与程序字段的对应关系见《字段映射表 V0.2》，不得在卡片中出现英文键。

### 4.2 各卡必需字段（第一阶段最小要求）

所有正式卡片必须包含：

```yaml
编号:          # 卡片编号，按第 2 节规则
标题:          # 卡片标题（概念卡为概念名称）
当前状态:      # 状态，按第 3 节 9 个中文状态
文献可靠等级:  # T1—T5（原文卡、文献卡必填；概念卡如有直接引用必填）
最低解释层级:  # I1—I5，卡内最接近字面的解释层级
最高推论层级:  # I1—I5，卡内最远的推论层级
反证状态:      # C0—C4
风险等级:      # S0—S4
创建日期:      # YYYY-MM-DD
最后修改日期:  # YYYY-MM-DD
创建人员:      # 创建人员
```

涉及现代研究时增加：

```yaml
现代证据等级:  # E1—E5 / EX
对应强度:      # M0—M4
```

涉及实践记录时增加：

```yaml
实践重复等级:  # R0—R5
```

原文卡另须包含：

```yaml
页码状态:      # 待补录／已补录
引文核对状态:  # 尚未逐字核对／已逐字核对
```

文献卡如为近现代传承文献，另须包含：

```yaml
传承归属:          # 例如：全真龙门派
编纂性质:          # 原典辑录、编者注释、图解、实践经验等
含古籍引文:        # 是／否
含编者实践解释:    # 是／否
含具体实践方法:    # 是／否
需逐段风险审查:    # 是／否
属现代学术研究:    # 是／否
```

### 4.3 统一示例

```yaml
编号: 文献-0001
标题: 道德经
文献可靠等级: T2
最低解释层级: I1
最高推论层级: I4
反证状态: C1
风险等级: S0
当前状态: 来源已核对
创建日期: 2026-08-01
最后修改日期: 2026-08-01
创建人员: 项目负责人
```

### 4.4 等级语义说明

- "文献可靠等级"只表示底本可靠程度，不表示引文是否已核对；引文核对状态与页码状态由原文卡专属字段单独表达；
- "最低解释层级"与"最高推论层级"分开填写：一张卡内同时存在直译（低层级）与现代推论（高层级）是正常情况，不允许用单一等级掩盖两者；
