## 模板体系说明（三类模块共用外壳、各用内容模板）

本包跑通后提取的是**全项目通用的外壳流程**（范围冻结 → 资料清单 → 证据分层 → 正反审查 → 风险边界 → 网站公开 → 发布审核 → 用户验收），可直接复用到八段锦与医学观察；

但**内容模板不能照搬**，三模块各用一套：

- 概念型（TOPIC）：原文 → 概念 → 主张 → 争议；
- 导引术型（DAOYIN）：历史版本 → 动作结构 → 干预方案 → 功效研究 → 禁忌风险；
- 医学观察型（MEDOBS）：观察现象 → 作者解释 → 传统对应 → 现代对照 → 替代解释。

最终形成：一套通用专题生产规范 + 三套模块专用内容模板。
