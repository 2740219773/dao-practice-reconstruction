# DAOYIN-001 八段锦研究样板

**模块：** 导引术与身体训练（DAOYIN-）
**状态：** 冻结待开始（TOPIC-001 静进入「待用户验收」前不激活、不收集资料、不建卡；2026-08-03 项目负责人确认冻结）

## 1. 唯一目标

把八段锦作为**导引术型生产线**完整跑通：历史来源 → 名称演变 → 版本演变 → 当前采用版本 → 动作结构 → 呼吸配合 → 意念要求 → 传统功效主张 → 现代研究 → 适用人群 → 禁忌与风险。产出可复制的导引术研究生产规范，供 DAOYIN-002（五禽戏）直接复用。

## 2. 允许读取

- 16-导引术资料卡/（本模块资料卡）
- 02-文献卡/（相关文献，如涉及八段锦的养生文献）
- 08-现代研究卡/（与八段锦相关的研究）
- 09-风险资料卡/
- 04-概念卡/（仅限建立关联，不重新研究）

## 3. 允许修改

- 16-导引术资料卡/（导引术-0001 起）；
- 11-专题研究/DAOYIN-001-八段锦/（证据关系表、版本对照表、公开版专题文章等）；
- website/docs/daoyin/（导引术模块公开页，按公开批次）；
- 本工作包范围卡与 context 文件。

## 4. 禁止修改

- **不定义"静""气""心"等概念的完整理论**：八段锦中出现"调息""宁神""松静"等表述，只建立关联（如"八段锦使用了'松静'要求 → 关联概念：静"），不在本模块重新完成概念史；
- 不修改 04-概念卡/ 中概念的定义与证据等级；
- 不建立无监督操作教程，不提供个性化修炼方案；
- 不扩展到五禽戏及其他导引术的研究（DAOYIN-002 另行激活）；
- 不处理内证观察与医学观察内容。

## 5. 已知输入

- 待开始，无既有资料卡；首次研究需先完成资料收集与版本梳理；
- 可参考已有导引术资料卡模板（01-知识卡模板/导引术资料卡模板.md）。

## 6. 预期输出

1. 导引术-0001（八段锦）资料卡；
2. 八段锦版本对照表（历史功法／现代标准化功法／临床研究干预方案三分）；

4. 导引术型生产线流程记录（供 DAOYIN-002 复用）。

## 7. 验收标准

- 八段锦采用哪个动作版本、每周几次、每次多久、是否配合呼吸、有无教练、研究人群与对照组，均已明确并逐项核对；
- 历史功法、现代标准化功法、临床干预方案三者清晰分离；
- 概念关联（松静→静）只建立链接，不展开概念研究；
- 禁忌与风险、停止条件、已知不良事件完整记录。

## 8. 旁支问题

- 与"静"概念的关联点登记，移交 TOPIC 模块。
