# 概念型内容模板 V0.1（模板提取）

**来源：** TOPIC-001 静专题全链路样板（2026-08-03 至 2026-08-04 跑通）
**用途：** 供 TOPIC-002（虚）及后续概念模块直接复用——各产出物的**内容模板**。使用方式：替换 `【占位】` 与结论编号前缀（如 TOPIC-002-Cxx），不改变结构与字段。
**配套：** 概念型专题生产规范 V0.1.md（十环节流程）；01-知识卡模板/（各卡模板）

---

## 一、manifest.yml（环节 0）

```yaml
专题编号: TOPIC-0XX
专题名称: 【概念名】
模块: 概念与思想研究
当前阶段: 【当前环节】
状态: 进行中
激活日期: 【日期】
工作包范围卡: 00-项目规范/工作包/【范围卡文件名】.md

核心问题:
  - id: Q1
    question: 【问题1】
  - id: Q2
    question: 【问题2】

核心原文:
  - 原文-XXXX
```

**要点：** 核心问题冻结后不再变更；核心原文/固定现代研究清单为本专题范围。

---

## 二、来源核对记录（环节 1）

```markdown
# 【专题】来源核对记录

| 原文编号 | 网络文本核对状态 | 指定底本核对状态 | 核对方式 | 异文备注 |
| ---- | ---- | ---- | ---- | ---- |
| 原文-XXXX | 已逐字核对 | 未复核（阻塞） | 【比对来源】 | 【异文】 |
```

**要点：** 双字段（网络文本/指定底本）逐张明确；异文与页码留痕；底本阻塞如实登记。

---

## 三、证据总账（环节 2，含结论编号表）

```markdown
# 【专题】证据总账

## 〇、专题结论编号表（唯一权威来源）
| 结论编号 | 结论内容 | 状态 | 核心依据 |
| ---- | ---- | ---- | ---- |
| TOPIC-0XX-C01 | 【结论1】 | 【状态】 | 【依据编号】 |
| ... |

状态枚举：暂定／当前不支持／支持／有限支持／限定／不采用／项目分类模型（非证据结论）

## 一、核心问题（manifest 冻结）
## 二、Q1：...（判断结论 + 支持证据清单 + 反对证据清单）
## 三、Q2：...
## 四、汇总表
## 五、修改记录
```

**要点：** 结论编号表是**唯一权威源**；其他文档只引用编号；C0X 若为"项目分类模型"须在总账内直接维护（如八义原文映射），不引用概念卡形成循环。

---

## 四、核心卡片修订（环节 3）

概念卡/主张卡/争议卡三字段（来源可信等级/来源核对状态/项目采用状态）+ Q 问题结论引用编号：

```markdown
> **TOPIC-0XX Q1 锚点：** 本卡对应结论 **TOPIC-0XX-C01**——结论内容与证据清单以
> 【专题】/证据总账.md 结论编号表为唯一权威来源，本卡不重复维护完整结论。
```

---

## 五、研究引用核对表（环节 4）

```markdown
| 编号 | 研究 | 现代证据等级 | 在专题中的角色 | 用途分类 |
| ---- | ---- | ---- | ---- | ---- |
| 现代研究-XXXX | 【研究】 | E2/E3 | 【方向】 | 限定／反限 |
```
每张研究卡标注：能支持什么 / 不能支持什么 / 专题用途 / 过度使用检查。

## 七、结论摘要（中间层，环节 3.5 后追加）

```markdown
# 【专题】结论摘要
## 一、这个概念是什么
## 二、它不是什么

## 四、当前不能确认什么
## 五、主要争议
## 六、安全边界（摘要版）
## 七、延伸资料
## 八、修改记录
```

## 八、问题卡（用户入口，环节 7.5）

```yaml
编号: 问题-XXXX
问题: 【问题】
问题分类: 【入门认知／经典阅读／概念理解／修持实践／历史宗派／现实应用／资料辨伪】
用户真实意图: 【意图】
简要回答: 【回答，引用结论编号】
答案依据等级: 【甲/乙/丙/丁——按最低关键依据确定】
文本判断依据等级: 【可选：混合问题时拆分】
风险判断依据等级: 【可选：混合问题时拆分】
答案依据: [【正式知识卡编号列表】]
网站发布状态: 可公开草稿
公开摘要: 【完整句，60-100 汉字，不在编号/书名/引文中截断】
```

**要点：** 答案依据等级按**最低关键依据**（不是最高）；公开摘要必须完整句；引用结论编号。

---

## 九、辨析卡（用户入口，环节 7.5）

```markdown
# 【概念甲】与【概念乙】
## 1. 辨析对象（含范围注记：本卡不处理【超出范围】的术语完整含义）
## 2. 共同点
## 3. 核心区别
## 4. 历史关系（限定表述：不作出范围外历史判断）
## 5. 可否互换（慎用"可互换"；多为"不可直接互换"）
## 6. 常见误用
## 7. 典型错误案例
## 8. 关联（引用结论编号）
## 9. 修改记录
```

**要点：** 辨析对象须明确"处理什么、不处理什么"；"不可直接互换"为默认立场；历史判断限定在已建文献范围内。
