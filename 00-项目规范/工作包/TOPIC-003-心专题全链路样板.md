## 1. 唯一目标

把“心”专题限制在第一轮最小可研究范围内，回答冻结的四个问题，并验证“静 → 虚 → 心”的概念关系能否形成稳定、可追溯的知识网络。

本专题**不研究“中国思想中的心”**，也不把所有出现“心”的道家、儒家、佛教、医学、内丹材料全部纳入。第一轮只处理《道德经》《庄子》《管子·内业》《坐忘论》中直接服务Q1—Q4的材料。

## 2. 核心问题（阶段0冻结）

| 编号 | 问题 |
| ---- | ---- |
| Q1 | 在本专题冻结材料中，“心”主要承担哪些不同角色，能否用单一定义概括？ |
| Q2 | “心”与已经完成的“静、虚”分别是什么关系？ |
| Q3 | “心”与“气”的关系在《道德经》《管子·内业》中如何表达，能否简单理解为“心控制气”？ |
| Q4 | “虚心、心斋、一志、定心、收心”等表述，是同一种方法，还是不同文本中的不同语境？ |

四个问题覆盖：概念多义、承接前两专题、连接后续“气”、防止把不同文本拼成一套统一操作法。
