## 1. 唯一目标

把“气”限制在第一轮最小可研究范围内，回答四个冻结问题，并承接已完成的“静—虚—心”主线，同时为后续“息”建立边界，而不是一次性研究中国思想史中的全部“气论”。

第一轮核心只处理《道德经》《庄子》《管子·内业》。**《坐忘论》本轮不列核心文献**：现有材料中它并未提供足以改变Q1—Q4的关键“气”论述，不为延续前面专题的文献名单而机械保留。

## 2. 核心问题（阶段0冻结）

| 编号 | 问题 |
| ---- | ---- |
| Q1 | 在冻结材料中，“气”主要承担哪些不同文本角色，能否用单一定义概括？ |
| Q2 | 传统文本中的“气”能否直接等同于呼吸、空气、氧气、能量或主观“气感”？ |
| Q3 | “气”与“心、静”的关系如何表达，能否简单理解为“心控制气”或“意念调气”？ |
| Q4 | “专气、听之以气、气理、精气、血气、善气/恶气”等表述，是同一种“气”还是不同文本语境中的不同用法？ |

四问分别控制：多义、现代对应边界、承接TOPIC-003、同字跨语境误合并。

### 6.3 现有概念-0004的主要问题

现有 `概念-0004-气.md` 是早期草稿，阶段3应整体重构而不是补丁式续写。当前已发现：

- 把云气、呼吸、生命、宇宙生成、情绪精神、精气、血气等多层用法先行归为“七义”，证据分层不足；
- 将《坐忘论》、医学、内丹、气功等后世/异体系材料放在同一张概念卡历史展开中；
- “宇宙生成义”“生命本源”等表述强度可能高于冻结文本直接支持程度；
- “专气=收敛气息”等解释尚需回到王弼及其他注释层核定；
- 易让读者把“气”理解成一种跨文本、跨时代、性质恒定的东西；
- “气≠呼吸”“气≠能量”等正确边界与历史事实判断混在一起，需要重新分层。
