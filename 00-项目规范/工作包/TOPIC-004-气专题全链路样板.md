## 1. 唯一目标

把“气”限制在第一轮最小可研究范围内，回答四个冻结问题，并承接“静—虚—心”主线、为后续“息”建立边界，而不是一次性研究中国思想史中的全部气论。

第一轮核心只处理《道德经》《庄子》《管子·内业》。《坐忘论》本轮不列核心文献，避免为了名单一致性机械纳入低价值材料。

## 2. 核心问题（阶段0冻结）

| 编号 | 问题 |
| ---- | ---- |
| Q1 | 冻结材料中的“气”主要承担哪些不同文本角色，能否用单一定义概括？ |
| Q2 | “气”能否直接等同呼吸、空气、氧气、能量或主观气感？ |
| Q3 | “气”与心、静的关系能否简单理解为“心控制气/意念调气”？ |
| Q4 | 专气、听之以气、气理、精气、血气、善气/恶气等是否属于同一种“气”？ |

## 3. 冻结材料范围

### 核心文献

- 《道德经》；
- 《庄子》；
- 《管子·内业》。

### 核心原文

1. 原文-0002：专气致柔；
2. 原文-0004：心使气曰强；
3. 原文-0005：听之以气、气也者虚而待物者也；
4. 原文-0007：此气也，不可止以力，而可安以德；
5. 原文-0009：心静气理，道乃可止；
6. 原文-0010：精也者，气之精者也；
7. 原文-0011：善气/恶气、搏气、精气、血气。

补充读取：TOPIC-001/002/003只作关系回读；原文-0012与《坐忘论》只作必要背景，不自动升级核心。

## 4. 结论治理

`11-专题研究/TOPIC-004-气/证据总账.md` 是唯一正式结论源。

| 编号 | 最终处理 | 状态 |
| ---- | ---- | ---- |
| C01 | “气”按多种文本角色整理，不先统一为单一实体 | 项目分析框架 |
| C02 | 不直接等同呼吸、空气、氧气、能量、能量场或气感 | 限定/当前不支持直接等同 |
| C03 | 当前不支持“心控制气/以意领气”统一模型 | 当前不支持 |
| C04 | 不同含气表达逐文本处理，专气/搏气解释竞争保留 | 暂定（阶段4增强） |
| C05 | 《内业》精—气关系仅在该文本内部有限成立 | 有限支持+历史限定 |

冻结后一般补充来源不得静默改写C01—C05；若新证据足以改变结论，必须显式重开专题或建立修订版本。

### 阶段3：概念与解释竞争

`概念-0004-气.md`整体重构：撤回旧“七义”既定分类，删除医学、内丹、气功等范围外展开，不再预设跨文本“气”是性质恒定的统一实体，改为逐文本角色整理。

### 阶段5：A类安全边界

建立 `气专题安全边界.md`，只处理四类真实风险：

1. 专气/搏气 → 聚气、守气、憋气、意守；
2. 心—气关系 → 以意领气；
3. 气 → 能量/气感，并用主观体验验证经典；
4. 气 → 呼吸，并提前生成调息、吐纳、屏息教程。

明确不提供聚气位置、导气路线、呼吸节拍、屏息时长、意守、气感强化或“气到了”的体验判断。
