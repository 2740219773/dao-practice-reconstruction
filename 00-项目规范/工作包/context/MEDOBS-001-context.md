# MEDOBS-001 内证观察笔记上下文包

## 工作包定位

医学观察与身体经验模块第一条生产线样板：以《内证观察笔记》为对象，跑通医学观察型生产线（观察者记录了什么 → 作者如何解释 → 与传统医学关系 → 与现代医学关系 → 独立验证 → 替代解释 → 可作假说的内容 → 不能作医学结论的内容）。

## 允许 / 禁止范围

- 允许：17-医学观察资料卡/、相关传统医学文献卡、相关现代研究卡、09-风险资料卡/、00-项目规范/医学观察资料分层规范.md、11-专题研究/MEDOBS-001-内证观察笔记/、website/docs/medical-observations/；
- 禁止：建立练功教程；诊断疾病；证明经络现代解剖结构；据主观感觉判断脏腑状态；替代医学检查；把个人观察推广为普遍规律；导引术动作研究。
