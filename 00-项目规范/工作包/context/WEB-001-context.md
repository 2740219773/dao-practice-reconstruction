# WEB-001 上下文包

**用途：** 执行 WEB-001（网页端视觉升级）时只读本文件 + 范围卡，不重复读取整个仓库。

---

## 网站定位

- 站点名称：问道志（研究工作台公开预览版）
- 定位：把传统道家修炼中高度抽象、依赖师承解释和个人悟性的内容，转化为有来源、有语境、有争议、可追溯、可修订的现代知识体系
- 不是宗教组织、医疗机构、修炼培训机构或商业课程；不预设传统说法必然正确，不把个人体验直接视为客观规律
- 仓库为源头，网站为展示层（决策-0004）；公开内容按批次上线

## 目标用户

- 对传统道家文献感兴趣、希望获得可靠来源与清晰边界的研究型读者；
- 不需要营销化、神秘化包装；需要的是可信、克制、层次分明的阅读体验。

## 当前视觉问题

1. 首页是 VitePress 默认 Hero + 功能卡布局，"太素"，无品牌识别；
2. 「静」专题与概念、统计混在平级卡片里，没有首要入口地位；
3. 内容统计（wd-stat 大数字）占据过强视觉位置；
4. 原文事实／项目归纳／尚未确认三层虽有 wd-threecol，但视觉上不够醒目；
5. 六概念卡只是平铺文字卡，无关系感；
6. 无研究路径、无书目卡、无品牌区块。

## 视觉方向（已存档，V0.1 视觉升级方向）

- 定位：**现代知识图谱＋传统文献编辑设计**（不是仙山云雾黑金法阵风）
- 核心视觉关键词：书卷、题签、印记、索引、线索、校勘、层次、关联、留白、墨与朱
- 首页七屏：①品牌记忆屏（竖排题签＋朱红小印＋两入口）②当前专题「静」大卡（含文献关系路线）③六概念关系图（虚─静─心、身─静─气/息）④研究路径图 ⑤精选文献书目卡 ⑥能确认/不能确认对照 ⑦最近整理
- 详情页：文献页题签式版式；原文页原文为中心（更大宋体、独立暖色背景、版本行）；概念页概念谱系＋分级标注
- 可借鉴不复制；禁止：黑金风、发光文字、旋转八卦、云雾仙鹤炼丹炉堆叠、效果承诺、倒计时营销

## 品牌与配色基调（存档建议，未定稿）

- 墨色（正文主色）＋ 朱红（印章/强调点缀）
- 留白充分；书页格线/索引线/文字残片作为极淡背景元素
- 传统但不老气；克制不花哨

## 已知技术约束

- 首页由生成脚本维护两块占位区：`<!-- GEN:BEGIN 内容统计 -->` 与 `<!-- GEN:BEGIN 最近整理 -->`，占位符之间内容不可手改（会被覆盖）；
- 详情页是构建产物（生成脚本写出），样式源头在 `website/docs/.vitepress/theme/style.css` 与生成脚本模板；本轮样板页改生成脚本模板 + CSS，不手改生成产物；
- 组件已有：wd-section / wd-card / wd-stat / wd-threecol / wd-twocol / wd-grid；
- VitePress 默认首页 frontmatter（hero/features）可整体替换为自定义布局（使用自定义组件或纯 HTML 区块）。
