# WEB-003 上下文包

**用途：** 执行 WEB-003（统一索引页样式）时只读本文件 + 范围卡，不重复读取整个仓库。

---

## 工作包定位

- 唯一目标：library/concepts/originals 三个索引页升级为与详情页一致的书卷式视觉体系；
- 禁止：改知识卡正文、改首页、改详情页模板、新建研究卡。

## 现状（renderIndex 生成）

- 三个 index.md 均为 Markdown 表格（`rows()` 函数）：编号 | 标题 | 发布状态（原文库多"引文核对"列）；
- 文献库按 `LIBRARY_GROUPS` 分组（原始文献 L1/历代注释 L2/近现代传承 L3/现代学术 L4），其余未分组；
- 表格样式在移动端横向滚动，视觉弱。

## 详情页书卷式体系（WEB-001/002 成果，索引页需呼应）

- `wd-oh-seal`：竖排朱红印章（writing-mode: vertical-rl），显示 YAML 编号；
- `wd-oh-meta`：元信息行（胶囊式 span）；
- 品牌色：--wd-ink 墨 / --wd-paper 暖白 / --wd-vermilion 暗朱红 / --wd-line 分隔线；
- 区块卡片：wd-card（圆角+暖白底+hover 边框变色）。

## 索引页设计方案（WEB-003）

1. **题签式标题区**：复用 `wd-original-header` 结构——竖排印章（"文献库/原文库/概念库"或类型图标）+ 右侧库名标题 + 公开说明文字；
2. **条目卡片**：每个条目一张 `wd-index-item` 卡——左侧编号印章小方块（横向小字如"文献-0001"）、中部标题链接、右侧状态标签（复用 .tag 体系）；
3. **原文库**：条目卡内保留"引文核对"信息（复合表述，小字灰）；
4. **文献库分组**：每组保留 `## 原始文献（L1）` 分组标题，组内用卡片列表；
5. 空库提示保留。

## 技术约束

- 生成页是构建产物（renderIndex 写出），源头在生成脚本与 style.css；
- 死链检查：只链接已生成页面（./xxx 相对链接，同库内安全）；
- 生成器幂等：重复运行不产生 git 差异；
- 验证：`node website/scripts/生成网站页面.mjs` → `npx vitepress build docs` → Chrome headless 截图（1440px/390px）。
