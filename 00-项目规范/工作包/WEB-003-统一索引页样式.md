# WEB-003 统一索引页样式

## 1. 唯一目标

把文献库、原文库、概念库三个索引页升级为与详情页一致的书卷式视觉体系：题签式标题区（竖排印章 + 标题 + 说明）、卡片式条目列表（编号印章小方块、标题、状态标签），保留文献库按 L1—L4 分组。不改动研究内容。

## 2. 允许读取

- website/（scripts、docs、.vitepress 全部）
- 02-文献卡/文献-0001、04-概念卡/概念-0001（只读）
- 详情页书卷式体系样式（style.css 中 WEB-001/002 区块）

## 3. 允许修改

- website/scripts/生成网站页面.mjs（renderIndex 索引页模板、rows 条目函数）
- website/docs/.vitepress/theme/style.css（索引页样式：wd-index-* 组件）
- 本工作包范围卡与 context 文件

## 4. 禁止修改

- 所有知识卡正文（02—09 各目录）
- 证据等级、文献解释、研究结论、风险字段
- 首页（index.md）、详情页模板（docHeader 等）
- 新建现代研究卡、核对古籍原文

## 5. 已知输入

- 索引页现状：三个 index.md 均为纯 Markdown 表格（编号/标题/发布状态），原文库多一列"引文核对"；
- 文献库按资料性质分组（L1 原始文献/L2 历代注释/L3 近现代传承/L4 现代学术，LIBRARY_GROUPS）；
- 详情页书卷式体系：wd-oh-seal（竖排朱红印章）、wd-oh-meta（元信息行）、wd-meta-detail（折叠）；
- 当前公开：library 1 张（文献-0001）、concepts 1 张（概念-0001）、originals 3 张（0001/0003/0004）。

## 6. 预期输出

1. 索引页题签式标题区（竖排印章 + 库名 + 公开说明）；
2. 卡片式条目列表（编号印章、标题、状态标签；原文库保留引文核对信息）；
3. 桌面与移动端适配；
4. 变更清单。

## 7. 验收标准

1. 三个索引页与详情页视觉语言一致（书卷式）；
2. 条目可读性强于原表格（编号/标题/状态一眼可分）；
3. 文献库 L1—L4 分组保留；
4. 桌面与移动端正常；
5. 不修改任何知识卡结论；
6. 构建通过、生成器幂等。

## 8. 旁支问题

- 首页导航与页脚仍为 VitePress 默认样式，未纳入书卷式体系（与索引页同属"全站视觉收口"，留待后续工作包）；
- 移动端索引条目卡片为换行布局（编号/标题/状态标签分行），可接受但后续可优化为横向滚动。
