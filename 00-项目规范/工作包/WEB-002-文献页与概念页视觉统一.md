# WEB-002 文献页与概念页视觉统一

## 1. 唯一目标

把文献页、概念页的展示模板升级到与原文页（WEB-001 样板）一致的书卷式视觉体系：题签式页眉（编号竖排印章 + 元信息行）、区块强化、阅读体验统一。不改动研究内容，不做全站重设计。

## 2. 允许读取

- website/（scripts、docs、.vitepress 全部）
- 02-文献卡/文献-0001、04-概念卡/概念-0001（只读）
- reports/问道志视觉升级方向 V0.1（存档）
- 03-原文卡/原文-0001（WEB-001 样板页参考）

## 3. 允许修改

- website/scripts/生成网站页面.mjs（详情页模板：library/concepts 页眉）
- website/docs/.vitepress/theme/style.css（书卷式页眉统一样式）
- website/docs/.vitepress/config.ts（如需要）
- 本工作包范围卡与 context 文件

## 4. 禁止修改

- 所有知识卡正文（02—09 各目录）
- 证据等级、文献解释、研究结论、风险字段
- 新建现代研究卡、核对古籍原文
- 首页（index.md）与原文页模板（WEB-001 已冻结，本次不动）
- 扩展其他专题页面

## 5. 已知输入

- 原文页样板（WEB-001）：wd-original-header 题签页眉（左侧竖排朱红印章 + 右侧元信息行），CSS 已就位；
- 文献页现状：普通 H1 + statusBanner + tagRow + metaTable（元信息表格），无页眉；
- 概念页现状：同文献页结构；
- 视觉存档方向：文献页"题签式版式（编号、竖排书名、年代·层级、版本行）"；概念页"顶部概念谱系 + 分级标注"；
- 当前公开页：library 1 张（文献-0001）、concepts 1 张（概念-0001）、originals 3 张（0001/0003/0004）。

## 6. 预期输出

1. 文献页题签式页眉（编号印章 + 其他名称/传统署名/大致年代/文献类型/资料性质/使用版本）；
2. 概念页题签式页眉（编号印章 + 概念类别/主要时期/涉及传统/当前定义状态）；
3. 桌面与移动端适配；
4. 变更清单。

## 7. 验收标准

1. 文献页、概念页与原文页视觉语言一致（书卷式页眉体系）；
2. 元信息从表格升级为页眉元信息行，减少表格感；
3. 桌面与移动端正常；
4. 不修改任何知识卡结论；
5. 构建通过、生成器幂等。
