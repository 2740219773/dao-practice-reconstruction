# MEDOBS-001 内证观察笔记研究样板

**模块：** 医学观察与身体经验（MEDOBS-）
**状态：** 待开始（DAOYIN-002 五禽戏验收完成后激活，完成医学观察型生产线）

## 1. 唯一目标

以《内证观察笔记》为对象，把**医学观察型生产线**完整跑通：观察者记录了什么 → 作者如何解释 → 与传统医学有什么关系 → 与现代医学有什么关系 → 是否有独立验证 → 是否存在替代解释 → 哪些内容可以作为假说 → 哪些内容不能作为医学结论。产出可复制的医学观察研究生产规范，供 MEDOBS-002 及后续模块复用。

## 2. 允许读取

- 17-医学观察资料卡/（本模块资料卡）
- 02-文献卡/（《黄帝内经》等传统医学文献）
- 08-现代研究卡/、09-风险资料卡/
- 00-项目规范/医学观察资料分层规范.md

## 3. 允许修改

- 17-医学观察资料卡/（医学观察-0001 起）；
- 11-专题研究/MEDOBS-001-内证观察笔记/；
- website/docs/medical-observations/（医学观察模块公开页，按公开批次）；
- 本工作包范围卡与 context 文件。

## 4. 禁止修改

- 不建立练功教程；
- 不诊断疾病；
- 不证明经络的现代解剖结构；
- 不根据主观感觉判断脏腑状态；
- 不替代医学检查；
- 不把个人观察直接推广为普遍规律；
- 不处理导引术动作研究。

## 5. 已知输入

- 待开始；《内证观察笔记》为公开出版物，激活后按版本、作者背景、记录形式建立资料卡。

## 6. 预期输出

1. 医学观察-0001（内证观察笔记）资料卡；
2. 四层证据分层表（传统医学原文／历代和当代医学解释／个人内证与身体观察／现代医学研究）；
3. "观察到了什么"与"作者认为这意味着什么"分离核对表；
4. 医学观察型生产线流程记录（供 MEDOBS-002 复用）。

## 7. 验收标准

- 「观察内容」与「作者解释」在全卡中明确分离；
- 每条内容标注所处证据层级；
- 哪些内容可作为假说、哪些不能作为医学结论，逐一给出判断与理由；
- 不出现"证明经络""确诊疾病"类结论表述。

## 8. 旁支问题

- 其他内证记录（MEDOBS-002）、近现代医家身体观察（MEDOBS-003）、修炼者身体体验资料（MEDOBS-004）不在本包范围，登记后移交后续工作包。
