> 传统道家并不是一个完全统一的修炼系统。不同历史时期、宗派和文本，对静坐、存思、导引、守一、内丹、精气神等概念的理解并不完全相同。因此，不能一开始就把“炼气—筑基—结丹”设成唯一正确的等级路线，而应先把不同体系分别整理，再研究它们之间能否建立对应关系。([plato.stanford.edu](https://plato.stanford.edu/archives/win2019/entries/daoism-religion/?utm_source=chatgpt.com))

## 一、项目的正式定位

项目暂时可以叫：

**传统道家修炼知识重构与实践研究计划**

也可以起一个便于传播的名字，例如：

- 道修工程
- 修真重构计划
- 道家修炼开放研究计划
- Dao Practice Reconstruction Project

项目包含三个核心目标。

第一，**知识重构**。

把古籍中的概念、方法、阶段、现象和禁忌拆开，说明出处、时代、流派、原义、不同解释和现代可能含义。

第二，**实践建模**。

把原本依赖“悟”的内容，转化为结构化的问题：

- 练习前需要什么条件？
- 具体做了什么？
- 为什么这样做？
- 练习过程中可能出现什么体验？
- 哪些属于正常变化？
- 哪些可能是身体或心理风险？
- 无效时应该修改什么？
- 什么情况下必须停止？

第三，**人本验证**。

让真实参与者进行安全、分级、知情的实践记录，通过多人、长期、重复的数据，判断某个方法究竟是：

- 多数人都可能出现的规律；
- 特定人群才有的反应；
- 纯粹的个人体验；
- 暂时无法解释的现象；
- 可能存在误导或危险的方法。

## 二、项目必须遵守的六条原则

### 1. 原文和解释必须分开

任何内容都要明确属于哪一层：

- 古籍原文；
- 历代注释；
- 当代学者解释；
- 项目团队推理；
- 现代科学假说；
- 实践者个人体验。

不能把“AI推测”写成“古人本意”，也不能把某个人的体验写成普遍规律。

### 2. 不预先证明道家一定正确

项目既不是为了证明“古人全对”，也不是为了证明“传统修炼都是迷信”。

真正的立场应该是：

> 传统体系提供研究方向，但每一项具体解释仍然可以被质疑、修正和否定。

### 3. 不强行把传统概念等同于现代概念

例如：

- “气”不能直接等于氧气；
- “经络”不能直接等于神经；
- “丹田”不能直接等于某个器官；
- “神”不能直接等于大脑活动；
- “周天”不能未经验证就解释成血液循环。

可以提出“可能对应的现代机制”，但必须标成假说。

### 4. 可复现方法，不承诺可复现境界

可以要求不同的人按照同一套流程操作和记录，但不能承诺每个人都会产生相同体验，更不能用所谓“境界”评价参与者高低。

### 5. 安全优先于效果

只要一种方法可能影响呼吸、睡眠、情绪、认知或身体状态，就必须先做风险审查，再谈有没有效果。

冥想和专注练习并非对所有人都只有正面作用，研究中已经记录过焦虑、疼痛、失眠、情绪恶化、解离体验，以及少数严重精神症状。快速呼吸、过度换气和长时间屏息也可能造成头晕、麻木、胸闷和恐慌样体验。([PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC9024164/?utm_source=chatgpt.com))

### 6. 失败和负面结果也必须保存

以下结果同样有价值：

- 没有感觉；
- 感觉与预期不一致；
- 中途退出；
- 出现不适；
- 方法只对少数人有效；
- 无法重复第一次体验。

这个项目不能只收集“成功案例”，否则很快就会变成自我证明。

# 三、项目的整体架构

整个项目可以分成六层。

## 第一层：传统文献库

这一层只负责回答：

> 古代文本到底说了什么？

每条资料至少记录：

- 文献名称；
- 作者或传统归属；
- 大致时代；
- 原文；
- 章节位置；
- 版本来源；
- 不同版本差异；
- 历代注释；
- 是否存在真伪或成书年代争议。

初期文献可以分四条线整理。

### 道家思想基础

例如：

- 《道德经》
- 《庄子》
- 《列子》

重点研究虚静、无为、守一、心斋、坐忘、少私寡欲等概念。《庄子·人间世》中的“心斋”等内容，本身就包含注意、心、气和“虚”的复杂关系，适合进行多种解释并列，而不是直接给出单一答案。([汉字世界](https://ctext.org/text.pl?if=gb&node=41958&show=parallel&utm_source=chatgpt.com))

### 养生与身心理论

例如：

- 《黄帝内经》
- 《养性延命录》
- 导引、行气、服气相关文献

《黄帝内经·上古天真论》把饮食、起居、劳作、情志和“精神内守”等放在同一个养生框架中，说明传统修炼至少不应被缩减成单纯的呼吸技巧。([汉字世界](https://ctext.org/wiki.pl?chapter=306626&if=gb&utm_source=chatgpt.com))

### 静坐与存思体系

例如：

- 《坐忘论》
- 《太上老君内观经》
- 上清派存思类文献

### 内丹体系

例如：

- 《周易参同契》
- 《悟真篇》
- 《钟吕传道集》
- 《性命圭旨》
- 不同内丹流派的注释文献

这部分应放到后期，因为内丹术语高度象征化，而且不同流派解释差异较大。

------

## 第二层：概念图谱

这一层回答：

> 古人所说的某个词，在不同地方分别是什么意思？

每个概念建立一张“概念卡”。

以“气”为例，不应该只写一句定义，而应拆成：

- 哲学宇宙论中的气；
- 中医理论中的气；
- 呼吸语境中的气；
- 情绪和精神状态中的气；
- 身体主观感觉中的气；
- 内丹术语中的气；
- 现代人可能产生的误解；
- 可以提出但尚未证实的现代解释。

概念卡之间建立关系：

- 精—气—神；
- 性—命；
- 心—意—念；
- 静—定—虚；
- 呼吸—注意—身体感受；
- 炼己—筑基—炼精化气；
- 先天—后天；
- 有为—无为。

这一层最终会形成一张“传统修炼知识图谱”，但不能急着把所有流派统一起来。先允许矛盾共存。

------

## 第三层：解释与假说模型

这一层回答：

> 这些传统表达，现代人可以怎样理解？

每一段解释至少并列四个栏目。

### 传统解释

依据古籍和历代注释说明。

### 现代通俗解释

用今天的人能理解的语言重新表达，但不引入未经说明的新结论。

### 可能机制

例如从以下角度提出假说：

- 注意力调节；
- 身体内部感觉；
- 自主神经活动；
- 呼吸节律；
- 情绪调节；
- 睡眠和生活规律；
- 认知期待；
- 群体暗示；
- 象征和仪式作用。

### 反对意见

主动寻找其他可能解释：

- 是否只是安慰剂或期待效应？
- 是否由姿势、缺氧、过度换气造成？
- 是否把普通身体感觉神秘化了？
- 是否存在选择性记录？
- 是否只有相信该体系的人才会报告相关体验？

这里不建议让AI给出“可信度87%”之类的数字。那会制造虚假的精确感。更适合使用证据等级。

例如：

| 等级 | 含义                                 |
| ---- | ------------------------------------ |
| A    | 有较稳定的现代研究支持               |
| B    | 有一定研究或跨体系重复记录           |
| C    | 有传统资料和多人经验，但缺乏可靠验证 |
| D    | 主要来自少量个人经验                 |
| E    | 仅为解释性假说                       |
| X    | 已发现明显风险、矛盾或错误           |

------

## 第四层：实践协议库

这一层回答：

> 某个方法到底怎样被安全、规范地研究？

每个实践项目都必须有独立协议，不能只写一句“意守丹田”或者“调息入静”。

标准协议至少包含：

1. 项目名称；
2. 来源和流派；
3. 研究目的；
4. 适用范围；
5. 排除条件；
6. 环境和时间要求；
7. 具体操作；
8. 单次持续时间；
9. 实践频率；
10. 可调整参数；
11. 禁止自行调整的内容；
12. 主观记录指标；
13. 可选客观指标；
14. 预期现象；
15. 不良反应；
16. 停止条件；
17. 后续观察时间；
18. 协议版本；
19. 审核人员；
20. 尚未解决的问题。

实践协议还要进行风险分级。

### S0：纯文献研究

没有人体练习，可以开放参与。

### S1：低风险观察

例如生活规律记录、自然状态下的身体感受和注意状态观察，不主动控制呼吸，不追求异常体验。

### S2：需要专业审核

涉及持续静坐、呼吸节律调整、特定身体动作或可能影响睡眠、情绪的练习。

### S3：高风险，不向普通社区开放

例如：

- 快速或强制呼吸；
- 长时间闭气；
- 极端禁食；
- 睡眠剥夺；
- 服用未经验证的药物或丹药；
- 强烈追求幻觉或意识改变；
- 涉及性行为或生殖健康的特殊方法；
- 在出现精神异常后继续强化练习。

项目初期只能开展S0和少量S1内容。

------

## 第五层：人体反馈与证据库

这一层回答：

> 真实的人练习以后，究竟发生了什么？

实践记录分成三类。

### 基础状态

- 年龄范围；
- 作息；
- 一般健康状态；
- 是否有长期练习经历；
- 当天睡眠；
- 咖啡因、酒精等影响因素；
- 情绪和压力状态。

涉及健康和心理的信息属于高度敏感内容，不应直接提交到GitHub或公开讨论区。

### 实践过程

- 实际练习时间；
- 是否完整执行；
- 是否自行修改；
- 中途发生了什么；
- 注意状态；
- 呼吸状态；
- 身体感觉；
- 情绪变化；
- 是否产生恐惧或不适。

### 练习后变化

至少观察：

- 即时变化；
- 数小时后变化；
- 当晚睡眠；
- 第二天状态；
- 是否影响工作和日常生活。

项目中的“走火入魔”不应被当作一个神秘化的统一诊断，而应拆成可以观察的风险事件，例如：

- 持续失眠；
- 恐慌或强烈焦虑；
- 明显解离感；
- 无法停止练习；
- 幻听、幻视或严重现实判断受损；
- 情绪失控；
- 日常工作能力下降；
- 持续胸闷、晕厥或身体疼痛；
- 因追求所谓境界而拒绝正常就医。

一旦达到停止条件，项目应停止采集和引导练习，并建议参与者寻求合格的医疗或心理专业人员帮助，而不是用“正在突破”“排病反应”继续解释。

## 第六层：社区协作与治理

项目可以开放，但不能完全依靠“谁说得玄，谁就有权威”。

建议设置以下参与角色：

- 古籍整理者；
- 道教史和宗派研究者；
- 道家实践经验者；
- 中医学专业人员；
- 临床医学与心理专业顾问；
- 神经科学和运动科学研究者；
- 统计与研究方法人员；
- 软件和AI工程人员；
- 普通体验记录者；
- 内容审核人员。

社区的权威来源必须是：

- 是否提供可靠出处；
- 推理过程是否清楚；
- 是否愿意接受反例；
- 是否完整报告负面结果；
- 是否遵守安全规则；
- 内容是否经过同行审核。

不能依据“自称修炼多少年”“达到什么境界”自动获得高权限。

# 四、AI在项目中的位置

AI是研究助手，不是师父，也不是最终裁判。

AI可以负责：

- 古籍检索和段落关联；
- 术语出现位置统计；
- 不同注释比较；
- 自动生成概念关系图；
- 把文言文拆成多个可能解释；
- 查找现代研究；
- 发现前后矛盾；
- 生成待验证假说；
- 检查实践协议是否缺少安全项；
- 汇总匿名反馈；
- 寻找不同参与者之间的共同模式；
- 标记异常反应；
- 维护版本变化记录。

AI不能负责：

- 判断参与者达到什么境界；
- 诊断疾病；
- 代替医生判断风险；
- 根据一次聊天自动制定高强度练习；
- 把主观体验解释为超自然事实；
- 编造古籍出处；
- 隐藏失败案例；
- 鼓励参与者突破明确的停止条件。

整个AI输出都应附带：

- 来源；
- 推理过程摘要；
- 证据等级；
- 反对解释；
- 风险提示；
- 是否经过人工审核。

# 五、平台应该怎样搭建

我建议采用“四个平台分工”，而不是只建一个网站或只建一个GitHub项目。

## 1. 官方网站：对外入口

网站负责：

- 项目介绍；
- 项搭建

我建议采用“四个平台分工”，而不是只建目边界；

- 知识地图；
- 概念卡；
- 文献阅读；
- 研究进展；
- 协议展示；
- 安全说明；
- 贡献入口。

网站是给普通人理解和阅读的，不负责直接保存敏感实践数据。

## 2. GitHub：公开协作中心

GitHub负责：

- 文档版本管理；
- 概念卡和资料卡；
- 网站源码；
- 数据结构；
- Issue讨论；
- Pull Request审核；
- 项目路线图；
- 贡献者记录；
- 公开的匿名汇总数据。

建议使用：

- GitHub Repository；
- GitHub Issues；
- GitHub Discussions；
- GitHub Projects；
- Markdown + YAML作为初期内容格式。

## 3. 研究登记平台：保存研究计划

在正式采集数据前，将研究问题、方法、停止条件和分析方式预先登记，避免看到结果以后再修改标准。

OSF一类平台可以生成带时间戳、只读的研究计划快照，适合做([OSF支持](https://help.osf.io/article/330-welcome-to-registrations?utm_source=chatgpt.com))ch7turn706667search15

## 4. 私有数据系统：保存人体记录

这一部分必须与GitHub分开。

保存：

- 参与者编号；
- 知情同意记录；
- 健康筛查；
- 原始实践日志；
- 不良反应；
- 退出记录；
- 联系信息。

公开时只能发布去标识化、汇总后的结果。

一旦开始系统地收集参与者的生理、心理、行为或健康信息，项目就可能进入涉及人的生命科学、医学研究或科技伦理审查范围。我国现有规范强调参与者权益、知情同意、风险控制和伦理审查；正式开展社区人体研究前，应与有资质的高校、医([国家中医药管理局](https://www.natcm.gov.cn/kejisi/zhengcewenjian/2023-02-28/29341.html?utm_source=chatgpt.com))ch8turn275669search11

# 七、分期实施路线

## 第零期：确定规则，2—4周

这一期不研究怎么修炼，只确定项目怎样工作。

必须完成：

- 项目名称和定位；
- 项目章程；
- 做什么和不做什么；
- 证据等级；
- 风险等级；
- 文献收录标准；
- AI使用规则；
- 社区贡献规则；
- 隐私与伦理原则；
- GitHub目录和模板；
- 网站首页原型。

这一期的核心产物是：

**《项目章程 V0.1》**

没有这份章程，后面参与者越多，项目越容易失控。

## 第一期：知识重构MVP，1—3个月

不要一开始研究完整的“炼气到筑基”。

只选择一个小范围：

> 虚静、心斋、坐忘、自然呼吸、注意与身体感受之间的关系。

完成：

- 3—5部基础文献的来源卡；
- 20—30张概念卡；
- 5—10个争议问题；
- 一套解释模板；
- 一张初步知识关系图；
- 一个静态官网；
- GitHub公开仓库；
- 初步AI检索和问答功能；
- 完整安全声明。

这一期不开展公开人体试验，只验证知识框架是否能跑通。

## 第二期：实践协议模型，3—6个月

完成：

- 标准实践协议模板；
- 不良反应报告模板；
- 停止条件；
- 参与者筛查框架；
- 实践日志系统；
- 第一批S1低风险观察协议；
- 专业顾问审核机制；
- 研究计划预登记流程；
- 小范围内部可用性测试。

这一阶段重点验证：

> 能不能把一句抽象修炼术语，转化成别人看得懂、执行不容易走样、出现问题知道怎样停止的协议。

## 第三期：小规模人本验证，6—12个月

在完成伦理和专业审核的前提下，开展小规模试点。

重点不是证明“修炼有效”，而是检查：

- 协议能否被一致执行；
- 不同人如何理解同一句指导；
- 哪些体验重复出现；
- 哪些记录指标有用；
- 哪些方法容易造成不适；
- 哪些传统解释需要修改；
- 是否存在明显的期待效应。

每一轮试点完成后，发布：

- 原始假说；
- 协议版本；
- 实际偏差；
- 正面结果；
- 负面结果；
- 不良反应；
- 修改原因；
- 下一版本计划。

## 第四期：开放社区，1—2年

完成：

- 贡献者身份和权限体系；
- 专家审核组；
- 社区复现任务；
- 多地区协作；
- 协议版本对比；
- 匿名数据分析；
- AI知识图谱；
- 多流派对照；
- 公开研究报告；
- 对外合作机制。

这时才真正发动全网参与。

## 第五期：长期研究生态，2年以上

长期目标可以包括：

- 与高校、医院、道教研究机构合作；
- 建立标准化研究数据集；
- 不同流派方法对照；
- 不同人群适用性分析；
- 长期随访；
- 发表正式研究成果；
- 建立开放但受控的实践协议库；
- 形成能够自我修正的AI研究Agent。

# 八、现在最应该做的第一件事

不是马上做AI，也不是马上让人练习，而是先写：

## 《项目章程 V0.1》

它只需要回答八个问题：

1. 我们为什么建立这个项目？
2. 我们准备解决什么问题？
3. 哪些问题暂时不解决？
4. 什么可以被称为证据？
5. 传统文本、现代解释和个人体验怎样区分？
6. 哪些练习禁止直接公开？
7. 社区贡献怎样审核？
8. 项目出现错误或伤害时怎样处理？

随后建立一个GitHub仓库和一个最简单的官网，把章程、目录、模板以及第一批概念卡公开。

最合适的第一个研究样板不是“完整筑基法”，而是选择一个较小的概念链：

> 静 → 注意稳定 → 呼吸变化 → 身体感受 → 情绪变化 → 日常状态

用这一个样板把“查原文—比较解释—提出假说—设计记录—识别风险—修正模型”的完整流程跑通。只要这一条链真正跑通，后面的炼气、守一、精气神、性命、周天和筑基，才有可能逐步接入，不会一开始就陷入庞大、混乱和无法验证的体系。



### 项目名称：道修重构计划

完整名称可以写成：

**传统道家修炼知识重构与实践研究计划**

英文可暂定为：

**Daoist Practice Reconstruction Project，DPRP**

“道修重构”比较符合你要做的事情：

- 不是照搬传统；
- 不是证明神秘现象；
- 不是创造网文式等级；
- 而是重新整理概念、方法、证据和实践流程；
- 允许不断推翻、修正和迭代。

“重构”也有一定工程感，和你想用AI、知识图谱、版本管理、社区协作的方法比较匹配。

### 网站名称：问道志

网站标题可以写成：

**问道志｜重新理解传统道家修炼**

或者：

**问道志｜一项关于传统修炼的开放研究**

“问道志”有几个好处：

- “问道”代表探索，而不是宣称掌握真理；
- “志”既有记录、整理的意思，也有长期志向的意思；
- 不像“修仙”“炼气”那么网文化；
- 不会显得像宗教门户或者培训课程；
- 后期可以容纳古籍、概念、实践记录、研究报告和社区讨论。

这套组合可以形成比较清晰的关系：

> **问道志**是公开网站。
>  **道修重构计划**是网站背后的长期研究项目。
