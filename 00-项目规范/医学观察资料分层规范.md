# 道修重构计划医学观察资料分层规范

**项目名称：** 道修重构计划
**文档名称：** 医学观察资料分层规范
**文档版本：** V0.1
**制定日期：** 2026年8月3日
**文档定位：** 医学观察与身体经验模块（MEDOBS-）的证据分层细则。本规范只规定"医学观察类资料怎么分层、各层能说明什么、不能说明什么"；与《证据等级规范》的 T/I/E/M/R/C/S 多维体系并行使用，不替代。

---

## 一、为什么需要单独分层

《内证观察笔记》、修炼者记录、医家个人观察等资料，在传统文献与现代研究之间处于特殊位置：

- 它既不是传统经典原文（不能当作"传统文本怎么说"的权威依据）；
- 也不是现代医学研究（不能当作客观证据）；
- 它是**个人观察记录**——描述经验、提出假说、提供待验证线索有价值，但不能直接推出医学结论。

医学观察资料最容易出现的错误，是把"观察到了什么"和"作者认为这意味着什么"混为一谈，再借传统术语（经络、气、脏腑）获得超出证据的权威感。本规范用固定四层解决这一问题。

---

## 二、固定四层

| 层 | 内容 | 能说明什么 | 不能用于 |
| ---- | ---- | ---- | ---- |
| 第一层：传统医学原文 | 《黄帝内经》；传统导引文献；藏腑、经络、气血相关原文 | 传统文本怎么说 | 证明传统说法必然正确；替代现代研究 |
| 第二层：历代和当代医学解释 | 注释；中医教材；医家理论；当代传统医学著作 | 后人如何理解和发展这些理论 | 把后起解释读回早期原文；当作原文本身 |
| 第三层：个人内证与身体观察 | 《内证观察笔记》；修炼者记录；医家个人观察；口述经验 | 描述经验；提出假说；提供待验证线索 | 证明解剖结构；确诊疾病；证明治疗有效 |
| 第四层：现代医学研究 | 生理测量；影像学；随机对照试验；队列研究；系统综述；临床指南；不良事件资料 | 是否可以测量；是否有重复结果；是否有因果证据；适用于哪些人群；有什么风险；证据质量如何 | 给传统说法"科学包装"；把有限结果推广到一切人群 |

### 层间规则

1. **不跨层引用**：第三层的观察不能直接升为第一层或第四层的结论；
2. **不反向授权**：传统术语（经络、气、脏腑）在第三层出现时，只作为"作者使用的词汇"，不自动获得第四层的客观含义；
3. **不替代检查**：第三层内容不得替代医学检查或临床诊断；
4. **四层都必须可标注**：医学观察资料卡正文的每一条内容，都应能指出自己处于第几层。

---

## 三、核心规则：观察与解释分离

医学观察资料卡最重要的规则是把以下内容分开：

> **观察到了什么**（发生了什么，可被记录的现象）
>
> **和**
>
> **作者认为这意味着什么**（作者的解释）

### 示例

| 项目 | 内容 | 层 |
| ---- | ---- | ---- |
| 观察 | 练习时腹部出现温热感 | 第三层（现象记录） |
| 作者解释 | 认为与某种气机变化有关 | 第三层（解释） |
| 传统医学对应 | 部分传统资料存在类似表述 | 第一层／第二层（文本核对） |
| 现代医学对应候选 | 可能涉及局部血流、肌肉活动、呼吸变化或注意放大 | 第四层（假说，需研究支持） |
| 当前判断 | 不能依据该感觉确认某种器官、经络或病理状态 | 项目判断（约束） |

观察与解释混写是医学观察资料卡的填写错误；正式卡（医学观察-0001 起）中必须分节记录（模板第 4、5 节）。

## 四、用途边界

### 第三层（个人内证与身体观察）允许的用途

- 描述经验；
- 提出假说；
- 提供待验证线索。

### 第三层禁止的用途

- 证明解剖结构；
- 确诊疾病；
- 证明治疗有效；
- 建立练功教程；
- 依据主观感觉判断脏腑状态；
- 替代医学检查；
- 把个人观察直接推广为普遍规律。

---

## 五、医学误用风险提示

- 以主观感觉替代医学检查 → 可能延误就医；
- 将异常体验解释为"突破""排病" → 可能掩盖真实健康问题（按《安全边界》作安全事件记录，不解释）；
- 把个人观察当普遍规律 → 可能误导他人实践；
- 用传统术语包装现代解释或反之 → 混淆证据层级。

---

## 六、与现有证据体系的关系

- 本规范的四层侧重"资料的资料性质分层"；《证据等级规范》的 T/I/E/M/R/C/S 侧重"判断的多维证据标注"，两者并行使用；
- 医学观察资料卡填写时：资料性质分层用本规范；具体判断的证据标注仍用《证据等级规范》与《字段映射表》；
- 本规范与《基础规范》冲突时，以《基础规范》为准；本规范未尽事项，按对应细则文件执行。
