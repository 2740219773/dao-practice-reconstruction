## 六、知识与实践的边界

当前正式采用：

```text
历史 method.* 节点
    ↓  提供历史语境 / 来源 / 边界
现代 practice.* 教学单元
```

禁止直接转换：

```text
古籍一句话 → 现代步骤
method.zuowang → 自动生成坐忘教程
method.tuna → 自动生成调息教程
method.fuqi → 自动生成服气教程
method.neidan → 自动生成内丹实修路线
```

典型边界：

```text
自然察息 ≠ 吐纳 / 服气
注意返回基础 ≠ 《坐忘论》完整收心体系
短时基础安坐 ≠ 坐忘 / 内丹筑基
轻柔动静转换 ≠ 古代导引套路复原
```

## 九、安全分流

已建立绿色 / 黄色 / 红色三级处理：

- 绿色：普通调整、缩短、换姿势、换锚点；
- 黄色：暂停触发单元、回退、观察，必要时寻求专业意见；
- 红色：立即停止并按《安全边界 V0.2》寻求相应专业或紧急帮助。

明确禁止把异常默认解释成：

```text

排病
气冲病灶
开脉
```
