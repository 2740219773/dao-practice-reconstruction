## 当前进行中

### 1. 知识卡标准化

目标：

把现有高连接节点逐步重构为统一知识卡，优先处理：

- 道
- 气
- 虚
- 静
- 心
- 身
- 息

重构时必须补：来源、证据等级、关系、争议状态和探索路径。

### 2. 知识图谱可信关系建设

目标：

从“节点之间看起来有关”升级为“关系有来源、适用范围和证据等级”。

优先关系链：

经典 → 概念
人物 → 经典 / 流派
流派 → 方法
方法 → 阶段
概念 / 方法 → 研究与争议

### 3. 对话规划与仓库状态校准

原则：

后续不再把对话中的规划、草稿或拟编写内容标记为 Git 已完成。只有实际提交到仓库的内容才进入“已完成”。

## 执行原则

每轮迭代必须进行：

1. 读取仓库实际状态
2. 确定本轮阶段目标
3. 内容或结构修改
4. 来源与关系检查
5. Git 提交
6. 状态文件同步（仅阶段变化时）
7. 记录发现的问题和下一批任务
