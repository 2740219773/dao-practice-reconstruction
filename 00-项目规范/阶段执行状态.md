## 五、V2.5 日常使用减负

### 今日修持

实践页把工作台前置到完整路线之前。

今日入口规则：

- 无历史记录：从“准备与安全检查”开始；
- 正常历史记录：只显示“继续上次”；
- 不会自动从第 N 张卡推进到第 N+1 张；
- 黄色信号：回到安全检查；
- 红色信号：停止新的练习推荐，只提供安全边界；
- 显示当前阶段方向和今天已有记录数；
- 始终允许“今天决定不练”。

### 每张卡只显示必要字段

当前最小观察字段：

```text
准备与安全检查：无额外练习观察
调身与舒适姿势：姿势 + 练后状态
身体接触觉察：姿势 + 练后状态
自然察息：呼吸 + 练后状态
注意返回：注意 + 练后状态
短时基础安坐：姿势 + 呼吸 + 注意 + 练后状态
轻柔动静转换：姿势 + 练后状态
日用觉察：注意 + 练后状态
```

通用的情绪、安全分流、问题项仍保留。

数据模型会在保存前再次清理当前卡不使用的字段，因此“界面隐藏”不会留下旧值污染记录。

### 补充记录默认折叠

调整和长备注继续可用，但默认收进“补充记录（可选）”，降低每次填写的视觉和认知负担。

### 实践卡快捷链接

当前工作台能直接跳到当前实践卡查看：

- 具体步骤；
- 停止条件；
- 建议时长；
- 传统来源与“不等同”边界。
