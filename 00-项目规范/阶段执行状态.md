## 五、V2.4 真实交互改进

### “今天决定不练”

用户选择后：

- 时长自动为0；
- 不再填写姿势、呼吸、注意和练后状态；
- 可继续记录情绪、安全分流和事实；
- 不计为失败，也不产生补练要求。

### 本地数据操作

真实 Chromium 已验证：

- JSON 导出内容与文件名；
- JSON 通过真实文件输入重新导入；
- 单条删除取消/确认；
- 全部清空取消/确认；
- 导入仍经过 schema 迁移和记录规范化。

### 浏览器权限降级

剪贴板写入被拒绝时：

- 页面不崩溃；
- 不发送网络请求；
- 提示手动复制。

### 键盘导航

实践标签使用规范 `tablist/tab` 语义，支持：

```text
ArrowLeft / ArrowRight
Home / End
aria-selected
aria-live 状态提示
```
