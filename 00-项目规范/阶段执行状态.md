## 六、30天与阶段复盘

30天分布区分：

```text

主动决定不练
无记录
黄色事件
红色事件
```

“无记录”只代表本机没有日志。

### 四类基础能力

- 身体适应；
- 呼吸自然度；
- 注意发现与返回；
- 日用迁移。

机器状态：

```text
记录支持稳定
记录支持部分稳定
尚未稳定
记录不足
因安全原因暂停
```

不是客观能力认证、医学评估或修炼境界。

### 阶段方向

只允许：

- 继续当前基础阶段并观察；
- 继续当前阶段，先补足记录；
- 优先回退、缩短或暂停相关单元；
- 回到已审查负荷后再评估；
- 因安全原因暂停并处理异常；
- 可以讨论下一阶段或分流。

最后一项必须同时显示：

> **这不是自动晋级。**

## 九、schema迁移保护

当前仍是 schema v1。

规则：

- 当前 v1 原样读取；
- 非法 JSON 明确报错；
- 未来版本拒绝自动降级；
- 缺少 `vN → vN+1` 明确迁移函数时停止；
- 逐版本迁移；
- 失败不覆盖原 localStorage；
- 迁移后再进入 `normalizeRecord`。

真正发布 v2 前必须先提供：

```text

```

及对应测试和字段变更说明。

## 十二、Cloudflare Pages线上验证

main 更新后，Cloudflare Pages 自动部署到：

```text
https://wendaozhi.pages.dev/
```

GitHub Actions 现在会：

```text
等待线上 /build-info.json 的 commit 追上 github.sha
↓
检查线上主要页面
↓
检查实践工作台 V2.3 入口
↓
检查自然察息实践卡规范 URL
↓
检查旧路径与 .html 规范化重定向
```

默认最多等待 36 次，每次 10 秒，避免 Pages 仍在构建时立即误报。

第一次生产校验发现：

```text
/practice/card/natural-breath.html → 308
```

这是 Cloudflare 规范化行为，不是页面故障。当前测试已经改为：

- `/practice/card/natural-breath` 必须 200；
- `.html` 入口必须重定向到规范路径。
