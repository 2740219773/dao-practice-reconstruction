## 五、V2.1 新增：最近 7 天复盘

自动统计：

- 记录次数；
- 实际总时长；
- 使用最多的基础实践；
- 重复问题；
- 黄色事件；
- 红色事件。

规则型提示：

- 红色事件存在 → 停止相关实践并按安全边界处理；
- 黄色事件重复 → 优先暂停/回退/缩短；
- 主动控制呼吸重复 → 暂时跳过察息，改用身体接触或环境声音；
- 姿势问题重复 → 优先支撑、微调和缩短；
- 无明显异常 → 维持当前负荷，不自动加时。

不计算修为分、境界分、气感指数。

## 六、V2.1 新增：AI 复盘材料

页面只生成本地摘要和可复制提示词，不自动发送网络请求。

AI 规则：

- 只总结用户提供记录；
- 事实/解释/传统理论分开；
- 不诊断；
- 不判断经络、丹田、气或境界；
- 不生成 S2—S4 教程；
- 红色信号优先；
- 无异常也不自动加时。

## 九、第一轮产品审查

发现并修正：

1. 实际练超时仍必须允许如实记录，不能因卡片上限阻止日志保存；
2. `emotionState` 必须真实输入，不能让缺失 UI 自动制造“稳定”数据；
3. JSON schema v1 导入限制为已知实践 ID；
4. 实践质量门直接验证源数据，不依赖其他构建副产物。

结论：

**当前可以进入真实使用试跑，但八张实践卡继续保持 `review`，不升级为 `published`。**
