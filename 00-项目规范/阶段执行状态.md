## 五、V2.2 记录规则模块化

原先集中于 `PracticeJournal.vue` 的核心规则已经拆成四个独立模块：

```text
practice-model.mjs
practice-stats.mjs
practice-safety.mjs
practice-ai.mjs
```

### 数据模型

负责：

- 空白记录；
- 草稿校验；
- 已知实践 ID；
- 记录规范化；
- JSON 导入/导出；
- 同 ID 合并；
- 问题字段过滤。

### 统计

最近7天现在分开统计：

- 记录次数；
- 实际练习次数；
- 主动决定不练次数；
- 实际总分钟；
- 黄色/红色事件；
- 重复问题；
- 超过卡片审查上限次数。

“今天不练”不等于失败；“实际超时”必须如实记录，但多次超限会进入安全提示。

### 安全规则

现在可独立测试：

- 红色事件最高优先级；
- 现实功能受影响；
- 重复黄色事件；
- 重复主动控制呼吸；
- 重复姿势问题；
- 重复超审查时长；
- 填写期异常与分流不一致提醒。

系统不自动替用户作医学严重程度判断。

### AI摘要

AI摘要继续：

- 只使用结构化统计；
- 不自动带入个人长备注；
- 不诊断；
- 不判气/经络/丹田/境界；
- 不生成 S2—S4 教程；
- 不把“不练”写成失败；
- 不把超时写成进步。

## 七、V2.2 实践详情知识回链

`33-实践体系/实践关系-v1.json` 继续只属于实践层。

网站构建器现在自动将关系写入每张实践详情：

- 前序基础；
- 下一基础；
- 传统与知识背景；
- 明确不等同；
- 安全约束。

示例：

```text
自然察息
├─ contextualized_by → 息
├─ not_equivalent_to → 吐纳
├─ not_equivalent_to → 服气
└─ safety_constrained_by → 安全边界 V0.2
```

```text
轻柔动静转换
├─ contextualized_by → 导引
└─ not_equivalent_to → 导引
```

这些是实践层机器关系，不转换为历史影响/师承。

CI 已直接检查最终 HTML 中对应关系文本实际存在，而不是只检查 JSON 文件。
