## 七、产品观察与修持记录严格隔离

产品观察使用独立本地存储：

```text
wendaozhi.practice.trial.v1
schemaVersion: 1
```

只记录：

- 总体操作耗时；
- 主要入口；
- 难选字段；
- 低价值字段；
- 是否产生“系统在催升级/打卡”的感觉；
- 一句话产品备注。

产品观察明确不做：

- 不进入修持 schema；
- 不包含 `practiceId / severity / durationMinutes` 等修持核心字段；
- 不进入最近7天/30天阶段计算；
- 不进入 AI 修持摘要；
- 不产生连续打卡、完成率、总分或阶段结论；
- 不自动上传网络。

清空产品观察不会删除修持记录。

## 八、V2.5 减负基线继续有效

### 今日修持

- 无历史记录：从“准备与安全检查”开始；
- 正常历史记录：只提供“继续上次”；
- 不会自动从第 N 张卡推进到第 N+1 张；
- 黄色信号：回到安全检查；
- 红色信号：停止新的练习入口，优先安全边界；
- 始终允许“今天决定不练”。

### 每张卡只记录必要字段

```text
准备与安全检查：无额外练习观察
调身与舒适姿势：姿势 + 练后状态
身体接触觉察：姿势 + 练后状态
自然察息：呼吸 + 练后状态
注意返回：注意 + 练后状态
短时基础安坐：姿势 + 呼吸 + 注意 + 练后状态
轻柔动静转换：姿势 + 练后状态
日用觉察：注意 + 练后状态
```

保存前数据模型会再次清理当前卡不使用的字段。
