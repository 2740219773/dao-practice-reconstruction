# 知识关联规范

## 一、目的

建立不同类型知识内容之间的关联规则，使项目从目录结构逐步发展为可检索、可扩展的知识网络。

## 二、关联层级

### 1. 经典 → 概念

说明某一概念的文献来源。

示例：

《道德经》 → 静

### 2. 概念 → 体系

说明概念属于哪个理论体系。

示例：

精气神 → 内丹体系

### 3. 体系 → 方法

说明理论如何进入实践层面。

示例：

导引体系 → 八段锦

### 4. 方法 → 观察

记录实践经验与现代观察之间的关系。

示例：

八段锦 → MEDOBS观察记录

### 5. 体系 → 研究

连接现代研究、争议和不同解释。

## 三、关联原则

- 不强行建立因果关系；
- 区分历史来源和现代解释；
- 区分传统理论、个人经验和科学研究；
- 关联用于导航，不代表观点认同。

## 四、关联字段建议

知识卡中可增加：

- 上级体系
- 来源经典
- 关联概念
- 关联方法
- 关联专题
- 现代研究
- 争议问题
