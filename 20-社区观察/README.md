# 20-社区观察

本目录存放"社区观察卡"（编号前缀"观察记录-"，观察记录-0001 起）：登记 Reddit、知乎、贴吧、哔哩哔哩、公众号、短视频平台上的高频问题、常见误解、热门争议与修炼体验样本。

## 规则

- **社区观察层与正式知识区严格隔离**：本目录内容只用于发现问题、收集需求、建立风险提醒与设计调查，**不直接充当权威答案**；
- 社区内容最终转化为"问题"和"需求"，转化为结论时须走正式知识区流程（问题卡 → 概念卡/原文卡/争议卡核对）；
- 模板见 01-知识卡模板/社区观察卡模板.md；
- 每张卡记录：来源平台、出现频率、典型说法、背后真实需求、涉及知识节点、是否存在误解、处理状态；
- 高赞只说明表达被接受，不证明符合经典或传统；
- 个人体验、教师推荐、商业课程宣传只作观察记录，不进入正式修持库。
