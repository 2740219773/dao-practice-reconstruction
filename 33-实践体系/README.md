# 问道志实践体系

## 一、定位

本目录承接问道志从“可靠知识研究”向“低风险、可记录、可复盘、可长期纠偏的基础实践”扩展后的实践层。

实践层不是把古籍改写成教程，也不是把知识图谱中的 `method.*` 节点直接变成操作步骤。它是一套**现代教学、记录与复盘系统**：传统材料提供历史与思想背景，现代安全资料提供边界，项目再据此设计可停止、可观察、可回退的基础单元。

核心原则：

> 有传统依据，不等于古法复原；能形成现代练习，不等于传统原文就是练习说明。

## 二、四层必须分开

实践体系中的任何内容都必须区分：

1. **历史传统层**：经典原文、历史方法、后世传统解释；
2. **现代教学层**：问道志为现代低风险场景设计的教学单元；
3. **个人观察层**：个人当次体验、异常与变化；
4. **现代证据层**：医学、心理学、运动科学等现代研究。

禁止：

```text
古籍一句话 → 直接改写成现代功法步骤
个人一次体验 → 传统理论被证明
现代生理指标 → “气”等传统概念被科学证实
```

## 三、实践开放级别

机器字段使用 `access_level`，正文保持中文说明。

| access_level | 中文定位 | 处理方式 |
| --- | --- | --- |
| `knowledge_only` | 知识了解 | 只学习，不给操作步骤 |
| `basic_low_risk` | 低风险基础实践 | 可提供短时、自然、可停止的基础教学单元 |
| `guided` | 建议指导 | 需要可靠指导者或专业意见后再进行 |
| `teacher_required` | 需可靠教师/传承 | 不自动生成自学教程 |
| `research_only` | 仅研究记录 | 只做历史、理论、风险研究 |
| `prohibited` | 禁止执行 | 只记录存在和风险，不展开操作 |

开放级别与 `S0—S4` 风险等级是两套不同字段：前者回答“如何开放”，后者回答“潜在风险如何管理”。

## 四、当前基础路线

当前仍只开放八张 `S1` 低风险现代教学单元：

1. 准备与安全检查；
2. 调身与舒适姿势；
3. 身体接触觉察；
4. 自然察息；
5. 注意返回与收心基础；
6. 短时基础安坐；
7. 轻柔动静转换；
8. 日用觉察。

它们不是“道家统一八步功法”，只是问道志的**基础能力训练顺序**。时间只作负荷参考，是否继续以安全状态、能力记录和复盘结果决定。

## 五、明确不进入基础公开实践的内容

当前不自动转为练习卡：

- 固定节拍呼吸、深呼吸强化、延长呼吸、闭气、胎息、逆腹式呼吸；
- 长时间意守丹田或其他敏感部位；
- 长时间禁动、忍痛静坐、闭关；
- 追求麻、热、震动、幻觉、离体感等异常体验；
- 服气、吐纳、内丹、辟谷、丹药等历史体系中的中高风险操作；
- 把心斋、坐忘直接重构为标准化现代教程。

这些内容仍可在知识层、方法节点和专题研究中研究。

## 七、知识层与实践层的关系

实践卡可以链接：

- `concept.*`：传统概念；
- `method.*`：历史方法研究节点；
- `classic.*`：经典；
- `policy.*`：安全规则。

机器关系当前只在实践层使用：

- `prerequisite_for`；
- `contextualized_by`；
- `not_equivalent_to`；
- `safety_constrained_by`。

实践关系暂不进入 V3 历史知识图谱，避免现代教学顺序被误读为历史传承或宗派次第。

典型边界：

```text
自然察息 ≠ 吐纳 / 服气
注意返回基础 ≠ 《坐忘论》完整收心体系
短时基础安坐 ≠ 坐忘 / 内丹筑基
轻柔动静转换 ≠ 古代导引套路复原
```

## 八、记录与复盘

网站 `/practice/` 当前提供：

```text
每日记录
最近7天
30天与阶段
数据管理
```

### 最近7天

用于发现近期重复问题和安全信号。

### 30天与阶段

用于观察：

- 实际练习 / 主动不练 / 无记录分布；
- 身体适应；
- 呼吸自然度；
- 注意发现与返回；
- 日用迁移；
- 黄色/红色事件；
- 超审查负荷；
- 当前更适合继续、回退、暂停还是讨论分流。

系统只输出“记录支持状态”，不输出修为总分或境界认证。

即使结果是：

> 可以讨论下一阶段或分流

也明确：

> **这不是自动晋级。**

## 九、本地数据与迁移

当前存储：

```text
wendaozhi.practice.records.v1
schemaVersion: 1
```

当前没有发布 schema v2。

但已建立显式迁移底座：

- 本地读取和 JSON 导入统一经过版本识别；
- 非法 JSON 不伪装成空数据；
- 未来版本拒绝自动降级；
- 缺少明确迁移函数时停止；
- 迁移失败不自动覆盖原始 localStorage；
- 真正升级 v2 前必须先有 `migrateV1ToV2` 和测试。
