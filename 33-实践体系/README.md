# 问道志实践体系

## 一、定位

本目录承接问道志从“可靠知识研究”向“低风险、可记录、可复盘、可长期纠偏的基础实践”扩展后的实践层。

实践层不是把古籍改写成教程，也不是把知识图谱中的 `method.*` 节点直接变成操作步骤。它是一套现代教学、记录与复盘系统：传统材料提供历史与思想背景，现代安全资料提供边界，项目据此设计可停止、可观察、可回退的基础单元。

核心原则：

> 有传统依据，不等于古法复原；能形成现代练习，不等于传统原文就是练习说明。

## 二、四层必须分开

实践体系中的任何内容都必须区分：

1. 历史传统层：经典原文、历史方法、后世传统解释；
2. 现代教学层：问道志为现代低风险场景设计的教学单元；
3. 个人观察层：个人当次体验、异常与变化；
4. 现代证据层：医学、心理学、运动科学等现代研究。

禁止：

```text
古籍一句话 → 直接改写成现代功法步骤
个人一次体验 → 传统理论被证明
现代生理指标 → “气”等传统概念被科学证实
```

## 三、实践开放级别

| access_level | 中文定位 | 处理方式 |
| --- | --- | --- |
| `knowledge_only` | 知识了解 | 只学习，不给操作步骤 |
| `basic_low_risk` | 低风险基础实践 | 可提供短时、自然、可停止的基础教学单元 |
| `guided` | 建议指导 | 需要可靠指导者或专业意见后再进行 |
| `teacher_required` | 需可靠教师/传承 | 不自动生成自学教程 |
| `research_only` | 仅研究记录 | 只做历史、理论、风险研究 |
| `prohibited` | 禁止执行 | 只记录存在和风险，不展开操作 |

开放级别与 `S0—S4` 风险等级是两套不同字段。

## 四、当前基础路线

当前仍只开放八张 `S1` 低风险现代教学单元：

1. 准备与安全检查；
2. 调身与舒适姿势；
3. 身体接触觉察；
4. 自然察息；
5. 注意返回与收心基础；
6. 短时基础安坐；
7. 轻柔动静转换；
8. 日用觉察。

它们不是“道家统一八步功法”，只是问道志的基础能力训练顺序。教学顺序不进入 V3 历史图谱。

## 七、修持记录与产品观察分离

### 修持记录

本地存储：

```text
wendaozhi.practice.records.v1
schemaVersion: 1
```

用于：

- 每日事实记录；
- 最近7天规则复盘；
- 最近30天与阶段；
- 黄色/红色安全判断；
- AI 统计摘要。

### 产品观察

V2.7 新增独立本地存储：

```text
wendaozhi.practice.trial.v1
schemaVersion: 1
```

网站 `/practice/` 已挂载 `<PracticeTrial />`，只记录：

- 总体操作耗时；
- 主要入口；
- 难选字段；
- 低价值字段；
- “系统在催升级/打卡”的感觉；
- 一句话产品备注。

产品观察明确：

- 不进入修持 schema；
- 不参与最近7天/30天阶段判断；
- 不生成修为分或完成率；
- 不改变实践记录数量；
- 清空产品观察不删除修持记录；
- 不自动上传网络。

## 八、知识层与实践层的关系

实践卡可以链接：

- `concept.*`：传统概念；
- `method.*`：历史方法研究节点；
- `classic.*`：经典；
- `policy.*`：安全规则。

实践关系当前只在实践层使用：

- `prerequisite_for`；
- `contextualized_by`；
- `not_equivalent_to`；
- `safety_constrained_by`；
- `reviewed_by`。

典型边界：

```text
自然察息 ≠ 吐纳 / 服气
注意返回基础 ≠ 《坐忘论》完整收心体系
短时基础安坐 ≠ 坐忘 / 内丹筑基
轻柔动静转换 ≠ 古代导引套路复原
```


其中 `test:e2e:trial` 会真实验证：

- 刷新后保留；
- 不修改修持记录；
- 清空确认；
- 清空产品观察后修持记录仍在。

GitHub Actions 还会等待 Cloudflare Pages 的 `/build-info.json` 追上当前提交，再做线上冒烟。
