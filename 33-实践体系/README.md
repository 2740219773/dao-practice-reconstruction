# 问道志实践体系

## 一、定位

本目录用于承接问道志从“可靠知识研究”向“低风险、可记录、可复盘的基础实践”扩展后的实践层。

实践层不是把古籍改写成教程，也不是把知识图谱中的 `method.*` 节点直接变成操作步骤。它是一套**现代教学与记录系统**：传统材料提供历史与思想背景，现代安全资料提供边界，项目再据此设计可停止、可观察、可复盘的基础单元。

核心原则：

> 有传统依据，不等于古法复原；能形成现代练习，不等于传统原文就是练习说明。

## 二、四层必须分开

实践体系中的任何内容都必须区分以下四层：

1. **历史传统层**：经典原文、历史方法、后世传统解释，回答“历史上怎么说、怎么做”。
2. **现代教学层**：问道志为现代使用场景设计的教学单元，回答“今天如何以低风险方式练习某项基础能力”。
3. **个人观察层**：个人当次体验、异常与变化，只作为个人记录，不自动推广为规律。
4. **现代证据层**：现代医学、心理学、运动科学等研究，只说明其实际研究对象，不反向证明传统概念。

禁止：

```text
古籍一句话 → 直接改写成现代功法步骤
个人一次体验 → 传统理论被证明
现代生理指标 → “气”等传统概念被科学证实
```

## 三、实践内容开放级别

机器字段使用 `access_level`，正文以中文说明。

| access_level | 中文定位 | 处理方式 |
| --- | --- | --- |
| `knowledge_only` | 知识了解 | 只学习，不给操作步骤 |
| `basic_low_risk` | 低风险基础实践 | 可提供短时、自然、可停止的基础教学单元 |
| `guided` | 建议指导 | 需要可靠指导者或专业意见后再进行 |
| `teacher_required` | 需可靠教师/传承 | 不自动生成自学教程 |
| `research_only` | 仅研究记录 | 只做历史、理论、风险研究 |
| `prohibited` | 禁止执行 | 只记录其存在和风险，不展开操作 |

开放级别与 `S0—S4` 风险等级是两套不同字段：前者回答“如何开放”，后者回答“潜在风险如何管理”。

## 四、当前基础路线

第一版只开放八张 `S1` 低风险现代教学单元：

1. 准备与安全检查；
2. 调身与舒适姿势；
3. 身体接触觉察；
4. 自然察息；
5. 注意返回与收心基础；
6. 短时基础安坐；
7. 轻柔动静转换；
8. 日用觉察。

它们不是“道家统一八步功法”，只是问道志的**基础能力训练顺序**。时间只作参考，是否进入下一项以能力门槛、安全状态和复盘结果决定。

## 五、明确不进入基础公开实践的内容

当前不把以下内容自动转为练习卡：

- 固定节拍呼吸、深呼吸强化、延长呼吸、闭气、胎息、逆腹式呼吸；
- 长时间意守丹田或其他敏感部位；
- 长时间禁动、忍痛静坐、闭关；
- 追求麻、热、震动、幻觉、离体感等异常体验；
- 服气、吐纳、内丹、辟谷、丹药等历史体系中的中高风险操作；
- 把心斋、坐忘直接重构为标准化现代教程。

这些内容仍可在知识层、方法节点和专题研究中研究。

## 七、与现有知识层的关系

实践卡可以链接：

- `concept.*`：传统概念；
- `method.*`：历史方法研究节点；
- `classic.*`：经典；
- `source.*`：来源；

但实践卡本身暂不进入 V3 历史知识图谱，避免“现代教学顺序”被图谱误读为“历史传承或传统阶段”。后续若进入图谱，应增加独立 `practice_unit` 类型和明确的 `designed_from / contextualized_by / not_equivalent_to` 等关系。
