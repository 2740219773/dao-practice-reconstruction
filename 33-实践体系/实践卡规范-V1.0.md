# 问道志实践卡规范 V1.0

## 一、适用范围

本规范只用于 `33-实践体系/实践卡/` 中可执行的现代教学单元。

历史方法继续使用 `method.*` 节点；传统概念继续使用 `concept.*` 节点。实践卡不得替代二者。

## 二、机器字段

字段名保留英文仅用于程序解析，说明与正文保持中文。

```yaml
---
id: practice.basic.example
slug: example
type: practice
name: 示例实践
summary: 一句话说明练什么基础能力
version: "1.0"
status: review
track: basic_foundation
sequence: 1
practice_kind: modern_teaching_unit
historical_equivalence: false
risk_level: S1
activity_class: B
access_level: basic_low_risk
duration_minutes:
  min: 1
  typical: 3
  max: 5
frequency: 每日0—1次，按状态调整
prerequisites: []
goal: []
observations: []
common_errors: []
stop_conditions: []
completion_criteria: []
next_practice: null
related_entities: []
traditional_refs: []
modern_evidence_refs: []
---
```

## 三、必填字段说明

### `id`

全库唯一。基础实践统一：

```text
practice.basic.<短名>
```

### `slug`

用于网站地址：

```text
/practice/card/<slug>
```

### `practice_kind`

当前公开基础卡必须是：

```text
modern_teaching_unit
```

禁止把历史方法的名称直接当作现代练习类型。

### `historical_equivalence`

第一阶段必须统一为：

```text
false
```

这表示“本练习可以借鉴或关联传统材料，但不宣称复原某一古法”。

### `risk_level`

沿用项目安全等级：

- S0：纯知识或无人体干预；
- S1：低风险基础实践；
- S2：中风险，通常不公开自动教程；
- S3：高风险，只研究；
- S4：极高风险，只记录存在和风险。

### `activity_class`

与《安全边界 V0.2》兼容：

- A：纯知识研究；
- B：自然状态观察/普通低风险活动；
- C：主动身心干预；
- D：高风险或禁止性活动。

第一批基础卡统一限制为 B 类。

### `access_level`

允许值：

- `knowledge_only`：知识了解；
- `basic_low_risk`：低风险基础实践；
- `guided`：建议指导；
- `teacher_required`：需可靠教师/传承；
- `research_only`：仅研究记录；
- `prohibited`：禁止执行。

### `duration_minutes`

时间是负荷边界和参考值，不是升级条件。

必须提供 `min / typical / max`。超过 `max` 不属于本卡已审查范围。

### `prerequisites`

写实际前置能力或安全条件，不写玄学门槛。

### `goal`

写可观察能力，例如“能在不改动呼吸的情况下短时观察呼吸”，不写“打通经脉”。

### `observations`

只记录可描述现象，不要求获得特定体验。

### `common_errors`

必须包含“越练越用力”“追求特殊感受”等适用风险。

### `stop_conditions`

所有卡必须明确何时终止；不得写“出现不适坚持一下”。

### `completion_criteria`

使用能力标准，不使用天数、积分、气感或境界。

### `related_entities`

只表示知识关联，不自动形成实践步骤链。

### `traditional_refs`

传统来源说明历史/思想背景，不能作为“现代方案已验证安全”的证据。

### `modern_evidence_refs`

用于现代安全、行为、运动或心理研究。必须注明其研究对象与本卡是否完全一致。

## 四、正文固定结构

每张卡至少包含：

1. 本卡定位；
2. 练习目标；
3. 开始前检查；
4. 具体步骤；
5. 建议时长与频率；
6. 观察什么；
7. 不要做什么；
8. 常见问题与调整；
9. 停止条件；
10. 完成标准；
11. 传统依据与“不等同”说明；
12. 现代证据与边界；
13. 下一步。

## 五、步骤编写要求

步骤应：

- 一步只做一件事；
- 使用普通语言；
- 允许随时停止；
- 允许改变姿势；
- 不强迫闭眼；
- 不要求获得特殊体验；
- 不把不适解释成进展。

步骤不得包含：

- 固定屏息；
- 强力吸吐；
- 延长呼吸；
- 过度换气；
- 逆腹式等主动特殊呼吸；
- 长时间锁定某器官或敏感部位；
- 追求麻、热、震动、漂浮、幻觉；
- 忍痛禁动；
- 睡眠剥夺、禁食、脱水；
- 未经审查的内丹、服气等操作。

## 六、传统依据写法

推荐：

> 本卡与《坐忘论》“收心”材料存在思想背景关联，但本卡是问道志为现代低风险场景设计的注意返回练习，不等于《坐忘论》的历史修炼体系。

禁止：

> 《坐忘论》证明正确练法就是以下五步。

## 七、现代研究写法

推荐：

> 现代冥想研究提示，注意训练并非对所有人均无不良体验，因此本卡采用短时、可停止和异常监测设计。相关研究并未直接研究本卡，也不能验证古代“收心”概念。

现代研究引用必须保留：

- 研究类型；
- 样本/场景边界；
- 能支持什么；
- 不能支持什么。

## 八、体验记录写法

允许：

- “今天坐3分钟后肩颈明显紧，改用椅背支撑后缓解。”
- “一注意呼吸就开始主动深吸，因此改观察脚底接触。”

不允许直接升级为：

- “肩颈紧说明气堵。”
- “呼吸变深说明气脉打开。”

## 九、发布质量门

实践卡进入网站前必须全部通过：

- [ ] ID唯一；
- [ ] `type: practice`；
- [ ] `practice_kind: modern_teaching_unit`；
- [ ] `historical_equivalence: false`；
- [ ] 风险等级存在；
- [ ] 活动类别存在；
- [ ] 开放级别存在；
- [ ] 时长上限明确；
- [ ] 至少1项停止条件；
- [ ] 至少1项能力完成标准；
- [ ] 传统来源与现代证据分开；
- [ ] 没有高风险自动教程；
- [ ] 没有境界/修为伪量化；
- [ ] 没有把个人体验当客观机制；
- [ ] 与项目安全边界无冲突。

## 十、实践卡状态

- `draft`：结构未完成；
- `review`：内容完整，处于试运行/审核期；
- `published`：完成内部审核并可公开；
- `paused`：因安全、证据或产品原因暂停；
- `archived`：不再使用。

第一批八张卡统一从 `review` 开始，不因为页面可访问就宣称已经完成实践有效性验证。
