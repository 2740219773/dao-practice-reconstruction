# 问道志实践记录数据模型 V1.0

## 一、目的

本规范定义 PRACTICE-002 的个人记录数据结构。目标不是量化“修为”，而是让每日记录、周复盘、异常分流和后续 AI 辅助使用同一份可迁移数据。

第一阶段采用**浏览器本地优先**：

- 默认只写入当前浏览器 `localStorage`；
- 不要求账号；
- 不默认上传服务器；
- 可以导出 JSON；
- 可以清空；
- 用户以后主动启用同步时，再单独设计权限和隐私协议。

## 二、存储键

```text
wendaozhi.practice.records.v1
```

数据结构版本：

```text
schema_version: 1
```

版本号必须保留。以后字段变化通过迁移处理，禁止静默改写旧记录含义。

## 三、单条记录结构

```json
{
  "id": "record-uuid",
  "schemaVersion": 1,
  "createdAt": "2026-08-12T11:00:00.000Z",
  "date": "2026-08-12",
  "practiceId": "practice.basic.natural_breath",
  "durationMinutes": 3,
  "startState": "acceptable",
  "postureState": "adjusted",
  "breathState": "mostly_natural",
  "attentionState": "returned",
  "emotionState": "stable",
  "afterState": "normal",
  "issues": ["breath_control"],
  "severity": "none",
  "adjustment": "改回脚底接触",
  "note": "一注意呼吸就想主动加深，因此没有继续察息。",
  "nextStep": "shorten"
}
```

## 四、枚举值

### `startState`

- `good`：顺畅；
- `acceptable`：可接受；
- `interfered`：有明显干扰；
- `skipped`：决定不练。

### `postureState`

- `comfortable`：舒适；
- `acceptable`：可接受；
- `adjusted`：中途做了调整；
- `stopped`：因姿势问题停止；
- `not_observed`：本次未观察。

### `breathState`

- `mostly_natural`：自然为主；
- `sometimes_controlled`：偶尔主动控制；
- `clearly_controlled`：明显主动控制；
- `not_observed`：未观察呼吸。

### `attentionState`

- `returned`：能发现并返回；
- `sometimes_returned`：偶尔能；
- `difficult`：今天较困难；
- `not_practiced`：未练此项。

### `emotionState`

- `stable`：稳定；
- `fluctuating`：有波动但可接受；
- `interfered`：明显干扰；
- `stopped`：因此停止。

### `afterState`

- `normal`：正常回到日常；
- `need_rest`：需要缓一缓；
- `affected`：日常功能明显受影响。

### `issues`

第一批允许：

- `posture_pain`：姿势疼痛；
- `numbness`：麻木；
- `shoulder_neck_tension`：肩颈紧张；
- `breath_control`：主动控制呼吸；
- `dizziness_chest`：头晕、胸闷或明显心慌；
- `restlessness`：明显烦躁；
- `sleepiness`：困倦；
- `special_sensation_chasing`：追求特殊感觉；
- `perceptual_reality_change`：异常感知或现实感变化；
- `function_impact`：练后影响睡眠、工作、学习或现实功能；
- `other`：其他。

`issues` 只记录用户描述的现象，不自动生成传统或医学机制解释。

### `severity`

- `none`：无需要升级处理的异常；
- `yellow`：建议暂停、回退或继续观察；
- `red`：立即停止并按安全边界处理。

`severity` 不是疾病严重程度，也不是 AI 诊断结果；第一阶段由用户根据项目安全页自行选择。

### `nextStep`

- `continue`：保持当前负荷；
- `shorten`：缩短；
- `lower_frequency`：降低频率；
- `step_back`：回退基础单元；
- `pause_unit`：暂停本单元；
- `daily_only`：只保留日用觉察；
- `pause_all`：暂停全部实践；
- `professional_opinion`：考虑专业意见。

## 五、周复盘派生数据

周复盘只由原始记录计算以下事实性指标：

- 最近 7 天记录次数；
- 实际总时长；
- 使用最多的基础实践卡；
- 反复问题的出现次数；
- 黄色事件数；
- 红色事件数；
- “呼吸明显被控制”出现次数；
- “练后功能受影响”出现次数。

不生成：

```text
修为分
静心指数
气感指数
综合境界分
连续打卡等级
```

## 六、自动提示规则

自动提示只做规则型安全提醒，不冒充 AI 诊断。

### 红色事件 > 0

只提示：停止相关实践并按安全边界处理。不推荐“换一种高级练法”。

### 黄色事件 >= 2

提示优先暂停触发问题的单元、缩短或回退。

### `breath_control` >= 2

提示暂时跳过察息，以身体接触或环境声音为锚点；不建议主动调息。

### `posture_pain` / `numbness` / `shoulder_neck_tension` 反复出现

提示检查姿势、缩短时长、使用普通支撑；不建议忍痛。

### 无明显异常

只提示维持当前负荷，不自动增加时长。

## 七、导出格式

导出文件：

```text
wendaozhi-practice-records-YYYY-MM-DD.json
```

建议结构：

```json
{
  "app": "问道志",
  "schemaVersion": 1,
  "exportedAt": "...",
  "records": []
}
```

导入时必须检查：

- `schemaVersion` 是否支持；
- `records` 是否为数组；
- 每条记录是否包含 `id/date/practiceId`；
- 数值时长是否在合理范围；
- 不认识的字段可以保留或忽略，但不能当作可执行指令。

## 八、隐私边界

实践记录可能包含身体、情绪和生活状态，属于敏感个人数据。

第一阶段原则：

- 浏览器本地保存；
- 不自动同步；
- 不默认公开；
- 不写入 GitHub；
- 导出文件由用户自行管理；
- AI 复盘只使用用户主动复制/提交的内容。

未来若引入账号、云同步或研究用途，必须另行建立：权限、加密、删除、数据保留、知情同意和研究伦理规则。
