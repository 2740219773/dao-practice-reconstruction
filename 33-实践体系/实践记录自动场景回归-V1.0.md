## 四、V2.2模块化结构

Vue 组件不再直接拥有所有规则。

```text
PracticeJournal.vue
├─ practice-model.mjs   数据模型 / 导入导出 / 草稿校验
├─ practice-stats.mjs   7天窗口 / 聚合统计
├─ practice-safety.mjs  安全规则 / 填写期提醒
└─ practice-ai.mjs      AI摘要 / 提示词约束
```

这样可以在没有浏览器界面的情况下直接测试核心规则。

## 五、新增统计解释

### 主动决定不练

记录系统将“今天决定不练”单独统计，不与“失败”“中断”或“意志不足”绑定。

其意义是：

- 可能来自正常时间安排；
- 可能来自开始前安全判断；
- 可能是合理回退；
- 不能仅凭不练次数评价实践质量。

### 超过卡片审查上限

实际超时必须保留为事实。

系统处理：

```text
允许保存真实时长
→ 统计 overLimitCount
→ 多次出现时提醒回到已审查负荷
```

不会处理为：

```text
超时 = 进步
超时 = 功力增加
超时 = 自动升级
```

## 六、填写期安全核对

V2.2 增加保存前的规则提醒，但不自动替用户做医学分诊。

例如：

- 记录了现实功能受影响但仍选择“无升级事件”；
- 记录了异常感知/现实感变化但仍选择“无升级事件”；
- 自然察息中记录“明显主动控制呼吸”。

系统会提示重新核对分流或回退，但仍允许事实记录进入日志。

## 八、自动测试尚不能证明的内容

以下仍需真实浏览器人工试跑：

1. 页面刷新后 `localStorage` 是否按预期保留；
2. 浏览器隐私/无痕模式下的行为；
3. JSON文件真实下载与重新选择上传；
4. 剪贴板权限拒绝时的实际交互；
5. 删除、清空确认框的真实操作体验；
6. 手机窄屏布局；
7. 深色/浅色主题可读性；
8. Safari、Chrome、Edge 等浏览器差异；
9. 真实连续使用7天后的复盘可读性；
10. 用户是否会误解“黄色/红色”含义。

这些项目不得因为 CI 通过就标记为“已完成真实使用验证”。
