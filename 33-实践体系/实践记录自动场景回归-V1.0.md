## 七、30天阶段复盘自动约束

机器状态只允许：

```text
记录支持稳定
记录支持部分稳定
尚未稳定
记录不足
因安全原因暂停
```

阶段判断固定优先级：

```text
红色事件
↓
现实功能影响 / 重复黄色 / 多项尚未稳定
↓
记录是否充分
↓
反复超出审查负荷
↓
才允许“讨论下一阶段或分流”
```

自动测试明确保证：

```text
讨论分流 ≠ 自动晋级
讨论分流 ≠ 解锁S2—S4
讨论分流 ≠ 境界认证
```

## 八、schema迁移保护

本地读取和 JSON 导入现在都必须经过 `practice-migrations.mjs`。

保证：

- 非法数据不自动覆盖；
- 未来版本不降级；
- 缺迁移函数不硬转；
- 迁移必须逐版本；
- 迁移失败不等于“无记录”；
- 真正升级 v2 前必须先建立 `migrateV1ToV2` 和测试。

## 十、自动测试尚不能证明

仍需真实浏览器人工试跑：

1. 页面刷新后的 localStorage 保留；
2. 浏览器隐私/无痕模式行为；
3. JSON 文件真实下载和上传；
4. 剪贴板权限拒绝；
5. 删除、清空确认框；
6. 30天标签页真实可读性；
7. 手机窄屏；
8. 深色/浅色主题；
9. Safari / Chrome / Edge 差异；
10. 连续真实使用7天和30天后的信息密度；
11. 用户是否误解黄色/红色或“记录支持稳定”；
12. 未来真正 schema v2 的真实数据迁移。

这些项目不得因为 CI 全绿就标记为真实使用验证完成。
