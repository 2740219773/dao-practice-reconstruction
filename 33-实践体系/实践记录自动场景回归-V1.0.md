## 三、GitHub Actions 当前顺序

1. `npm run graph:check`；
2. `npm run practice:check`；
3. `npm test`；
4. `npm run build`；
5. `npm run test:e2e:practice`；
6. 构建产物检查；
7. 等待 Cloudflare Pages `build-info.json` 追上当前 `github.sha`；
8. 线上冒烟；
9. 上传网站与图谱构建产物。

连续 push 使用 `concurrency` 取消旧工作流，避免旧提交继续等待已经被新提交替代的线上部署。

## 六、30天阶段复盘自动约束

机器状态只允许：

```text
记录支持稳定
记录支持部分稳定
尚未稳定
记录不足
因安全原因暂停
```

固定优先级：

```text
红色事件
↓
现实功能影响 / 重复黄色 / 多项尚未稳定
↓
记录是否充分
↓
反复超出审查负荷
↓
才允许“讨论下一阶段或分流”
```

自动测试保证：

```text
讨论分流 ≠ 自动晋级
讨论分流 ≠ 解锁S2—S4
讨论分流 ≠ 境界认证
```

## 七、schema迁移保护

本地读取和 JSON 导入都经过 `practice-migrations.mjs`。

保证：

- 非法数据不自动覆盖；
- 未来版本不降级；
- 缺迁移函数不硬转；
- 迁移逐版本；
- 迁移失败不等于“无记录”；
- 真正升级 v2 前必须先建立 `migrateV1ToV2` 和测试。

- 专题入口；
- 静专题；
- 知识索引；
- 问题地图；
- 安全边界；
- 实践工作台；

- 构建信息；
- 首页构建 SHA；
- `PRACTICE-003`；
- “30天与阶段”；
- `/library/` 旧路径重定向；
- 实践卡 `.html` → 无扩展名规范路径。

第一次正式生产冒烟曾发现：

```text
/practice/card/natural-breath.html → 308
```

实际规范 URL：

```text
/practice/card/natural-breath
```

因此当前断言是：

- 规范 URL 返回 200；
- `.html` URL 必须正确重定向。

这不是放宽检查，而是把检查改为符合真实生产路由。
