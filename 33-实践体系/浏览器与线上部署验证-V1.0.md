## 十、自动化曾暴露的问题

当前浏览器/生产链已经真实发现并修正过：

1. Cloudflare `.html` URL 会 308 规范化，不能按本地文件名验证；
2. 页面版本变化后，旧 smoke 文案锚点会误报；
3. Chromium DevTools 偶发启动超过原等待窗口，需要更稳的启动诊断；
4. 同一个 URL 再次赋给 `location.href` 不等同于重新挂载页面，安全覆盖测试必须用真实刷新；
5. URL 入口安全决策不能依赖响应式计算属性刷新时机，应直接根据刚载入记录计算；
6. 产品观察清空后，Vue 提示文本需要一轮 DOM 更新，E2E 不能把“立即读 DOM”当成产品失败。

这些问题都通过修正测试或产品实现解决，没有通过删除检查来换取绿灯。
