## 十、自动化曾真实暴露的问题

当前浏览器/生产链已经发现并修正过：

1. Cloudflare `.html` URL 会 308 规范化，不能按本地文件名验证；
2. 页面版本变化后，旧 smoke 文案锚点会误报；
3. Chromium DevTools 偶发启动超过旧等待窗口；
4. 同 URL 再赋给 `location.href` 不等于重新挂载，安全覆盖测试需要真实刷新；
5. URL 入口安全决策不能依赖响应式计算属性刷新时机；
6. 产品观察清空后，Vue 提示文本需要等待 DOM 更新；
7. 安全渐进层若反复写相同文本可能形成 MutationObserver 自触发循环，因此同步改为幂等；
8. 7天复盘 E2E 曾依赖标签页切换后立即读取日期，已改为浏览器本地日期；
9. 单次黄色事件曾被稳定文案覆盖，已新增 `yellow_event`；
10. 第五轮新增30天黄色测试时，测试曾把“**不应被当作状态稳定**”这一正确否定句误判为包含稳定结论，现改为检查规则代码与完整否定语义；
11. 30天入口更名后，旧通用 E2E 仍写死“30天与阶段”并要求能力状态默认铺开。测试已更新为验证“30天复盘 + 当前建议 + 记录依据折叠”，没有把产品改回旧设计。

这些问题都通过修正产品或测试语义解决，没有通过删除检查换取绿灯。
