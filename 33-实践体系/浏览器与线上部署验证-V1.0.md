### 3.1 今日入口与双向导航

脚本：`website/scripts/e2e-practice-daily.mjs`

验证：

- 第一次从“准备与安全检查”开始；
- “阶段方向”不占据今日卡，只保留在30天复盘；
- 自然察息只显示呼吸 + 练后状态；
- 短时基础安坐显示姿势、呼吸、注意、练后四类观察；
- 保存“调身”后只显示“继续上次：调身与舒适姿势”；
- 不自动推进到下一实践卡；
- “今天决定不练”进入最简表单；
- 实践卡 → 工作台真实反向跳转；
- 反向预选不增加记录；
- 黄色/红色安全状态覆盖 `?practice=<slug>`。

安全便利顺序保持：

```text
本地记录
↓
安全状态
↓
URL实践卡预选
```

### 3.2 今日首屏低价值字段减法

脚本：`website/scripts/e2e-practice-reduction.mjs`

验证：

- 今日卡不显示“阶段方向”；
- “情绪状态”退出日常表单；
- “下次决定”退出日常表单；
- 保存后的真实本地 JSON 仍为：
  - `emotionState = not_observed`；
  - `nextStep = not_decided`。

这证明不是只用 CSS 隐藏控件，而是数据本身不虚构结论。

### 3.3 异常与安全渐进展开

脚本：`website/scripts/e2e-practice-safety-reduction.mjs`

验证：

```text
正常记录
→ 异常区默认折叠
→ 手动展开可查看完整异常与安全分流
→ 自然察息记录明显主动控制呼吸
→ 草稿安全提醒出现并自动展开
→ 系统不自动选择 yellow / red
→ 改成“今天决定不练”
→ 异常区退出
→ 保存后 issues=[] / severity=none / nextStep=not_decided
```

渐进展示只决定“何时把安全信息拿出来”，不替用户或专业人员做医学判断。

### 3.4 7天复盘信息层级减法

脚本：`website/scripts/e2e-practice-review-reduction.mjs`

第四轮新增。

验证空记录状态：

- 规则型复盘始终直接可见；
- “重复问题”无内容时压缩成轻提示；
- 六项数字统计默认折叠在“查看7天数据细节”；
- AI 材料默认折叠在“AI复盘材料（可选）”；
- 展开以后，原有六项数字和17行 AI 材料必须完整存在。

验证存在安全记录状态：

- 规则型复盘仍保持第一层；
- 真实重复问题仍直接可见；
- 数字与 AI 不因为存在安全问题而自动抢占首屏；
- 单次明确黄色事件必须显示准确黄色提醒。

第四轮 E2E 实际发现过一个产品规则缺口：

```text
只有 1 次黄色事件
↓
旧规则因为“尚未重复”
↓
错误显示“没有触发重复安全规则，保持当前低负荷即可”
```

现已修正为独立 `yellow_event`：

```text
单次黄色事件
↓
明确提示本周期存在黄色事件
↓
按当次记录暂停 / 回退 / 观察
↓
不自动医学诊断
```

因此浏览器减负测试不仅验证布局，也用于防止“为了页面更轻而把安全语义变弱”。

## 十、自动化曾真实暴露的问题

当前浏览器/生产链已经发现并修正过：

1. Cloudflare `.html` URL 会 308 规范化，不能按本地文件名验证；
2. 页面版本变化后，旧 smoke 文案锚点会误报；
3. Chromium DevTools 偶发启动超过旧等待窗口；
4. 同 URL 再赋给 `location.href` 不等于重新挂载，安全覆盖测试需要真实刷新；
5. URL 入口安全决策不能依赖响应式计算属性刷新时机；
6. 产品观察清空后，Vue 提示文本需要等待 DOM 更新；
7. 安全渐进层的 `MutationObserver` 若反复写相同文本可能形成自触发循环，因此同步改为幂等；
8. 7天复盘首次 E2E 依赖标签页切换后立即读取日期，测试时序不稳定，改为与产品同源的浏览器本地日期格式；
9. **单次黄色事件曾被“没有触发重复安全规则”的稳定文案覆盖**，已新增 `yellow_event` 和自动测试修正。

这些问题都通过修正测试或产品实现解决，没有通过删除检查来换取绿灯。
