# 问道志浏览器与线上部署验证 V1.2

更新时间：2026-08-13

## 一、验证分层

问道志网站由 GitHub main 更新后自动部署到：

`https://wendaozhi.pages.dev/`

当前质量链分为五层：

```text
纯规则 / 数据测试
↓
实践工作台真实 Chromium E2E
↓
今日修持减负 Chromium E2E
↓
日读 / 夜读 Chromium E2E
↓
Cloudflare Pages 当前提交线上验证
```

不同层解决不同问题：规则是否正确、日常交互是否真实可用、主题是否真的变化，以及生产站点是否确实部署了当前提交。

## 二、实践工作台 Chromium E2E

脚本：`website/scripts/e2e-practice-browser.mjs`

命令：

```text
npm run test:e2e:practice
```

当前覆盖：

1. `/practice/` 实际加载；
2. 四个标签页具备 `tablist/tab` 语义；
3. ArrowRight 键盘切换并同步 `aria-selected`；
4. 调身按最小字段真实保存；
5. 隐藏的呼吸/注意字段不会写入旧值；
6. `localStorage` 写入与刷新保留；
7. “今天决定不练”最终为0分钟且不计失败；
8. JSON 导出实际生成 schema v1 数据；
9. JSON 导入通过真实 `File + DataTransfer + change`；
10. 单条删除取消/确认；
11. 清空全部取消/确认；
12. 剪贴板权限拒绝后的手动复制降级；
13. 记录不足时30天页不自动推进；
14. 红色事件保存后阶段判断优先暂停；
15. 390px 窄屏无明显横向溢出。

## 三、今日修持减负 Chromium E2E

脚本：`website/scripts/e2e-practice-daily.mjs`

命令：

```text
npm run test:e2e:daily
```

这是 V2.5 新增的独立日常使用回归，当前验证：

- 第一次使用显示“从准备与安全检查开始”；
- 首次实践卡快捷链接指向 `/practice/card/precheck`；
- 今日入口显示阶段方向；
- 安全检查不要求姿势、呼吸、注意、练后状态；
- 自然察息只显示呼吸 + 练后状态，不显示姿势/注意；
- 短时基础安坐显示姿势、呼吸、注意、练后四类观察；
- 保存一次“调身与舒适姿势”后，今日入口变成“继续上次：调身与舒适姿势”；
- **不会**自动推进到“身体接触觉察”；
- 当前实践卡链接同步指向上次使用卡；
- “今天决定不练”进入最简表单；
- 不练时隐藏时长与全部练习观察字段。

因此“继续上次”是便利入口，不是机器晋级系统。

## 五、31个规则与数据场景

`npm run test:practice` 当前自动运行 31 个实践/schema 场景。

其中 V2.5 新增 5 个模型级约束：

- 每张实践卡声明自己的最小观察字段；
- 自然察息清理姿势/注意旧值；
- 短时基础安坐保留四类必要观察；
- “今天决定不练”清理全部练习观察；
- 实践卡 URL 由统一模型生成。

这样即使以后界面重构，数据层仍能阻止无关隐藏字段进入记录。

## 六、Cloudflare Pages 当前提交验证

脚本：`website/scripts/smoke-production.mjs`

main push 后：

```text
读取 github.sha
↓
轮询线上 /build-info.json
↓
等待 Pages commit 追上当前提交
↓
检查线上关键页面与版本锚点
```

默认：

```text
站点：https://wendaozhi.pages.dev
最多检查：36次
间隔：10秒
```

V2.5 的实践工作台生产锚点为：

```text
PRACTICE-004
今日修持
30天与阶段
今天决定不练
```

不再使用已经过时的 `PRACTICE-003` 文案作为生产判断条件。
