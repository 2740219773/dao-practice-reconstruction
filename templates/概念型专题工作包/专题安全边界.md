## 四、异常体验的记录与处理（专题口径）

**原则（安全边界 V0.2 §2.2）：异常体验首先作为安全事件记录，不解释为突破、排病或境界。**

| 等级 | 表现示例 | 处理 |
| ---- | ---- | ---- |
| L1 轻度 | 【短暂焦虑、注意难集中等】 | 停止当前练习、回正常活动、当天不再重复；持续或加重则升级 |
| L2 中度 | 【持续失眠、明显恐慌等】 | 停止相关实践、暂停项目活动、建议专业心理评估、不恢复练习 |
| L3 严重/紧急 | 【晕厥、抽搐、意识不清等】 | 立即停止、联系紧急医疗服务、不独自处理、启动重大事件审查 |

**专题边界：** 本专题只做**文献性风险提示**，**不远程评估任何人的练习反应**（安全边界 §14.3 禁止远程诊断）。
