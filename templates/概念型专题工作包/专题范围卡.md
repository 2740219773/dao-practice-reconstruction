## 8. 验收标准

| 阶段 | 验收点 | 产出物 |
| ---- | ---- | ---- |
| 0 范围冻结 | 核心问题≤4；核心文献/时期/排除范围冻结；manifest就位 | manifest + 范围卡 |
| 1 来源核对 | 关键文本来源、版本、网络/底本状态与异文可追溯 | 来源清单 + 核对记录 |
| 2 证据总账 | 每个核心问题有支持/反对/限定；结论编号唯一维护 | 证据总账 |
| 3 概念与解释竞争 | 核心概念修订；主张/争议按材料建立；原文/注家/项目判断分层 | 核心卡片 |
| 4 文献解释与现代研究核对 | 不同材料类型逐项写能/不能支持和实际用途；无过度使用 | 研究引用核对表 |
| 5 风险边界 | A—D分类明确；只写真实相关风险；不提供越界操作 | 专题安全边界 |
| 6 结论摘要与入口 | 摘要引用正式结论；入口卡覆盖真实问题/混淆点，不新增研究 | 摘要 + 按需入口卡 |
| 7 反向审查 | 来源、层次、研究使用、风险、结论编号与状态完整检查 | 反向审查记录 |
| 8 验收与冻结 | 项目负责人最终验收；研究侧状态明确；平台侧可延期 | 发布/验收记录 |

**停止条件：** 研究侧阶段0—8完成并通过项目负责人验收；所有未解决项已显式登记。平台侧延期不自动阻塞研究侧冻结。
