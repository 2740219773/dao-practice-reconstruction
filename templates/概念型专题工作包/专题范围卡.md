## 8. 验收标准（九项验收点，每项有依据与产出物）

| 阶段 | 验收点 | 产出物 |
| ---- | ---- | ---- |
| 0 范围冻结 | 核心问题固定（≤4）、核心原文/现代研究清单固定、排除范围明确、manifest 就位 | manifest.yml |
| 1 来源核对 | 核心原文网络文本/指定底本核对状态逐张明确，异文与页码留痕 | 来源清单 + 来源核对记录 |
| 2 证据总账 | 核心问题所有判断有完整证据清单（支持/反对/限定），结论有编号 | 证据总账 |
| 3 概念与主张争议 | 概念/主张/争议修订完成，引用结论编号，项目判断与原文判断分开 | 核心卡片 |
| 4 现代研究核对 | 固定现代研究逐一标注能/不能支持，未被过度使用 | 研究引用核对表 |
| 5 风险边界 | 专题安全边界建立，A—D 类映射 + 专项风险覆盖 | 安全边界页 |
| 6 结论摘要 | 结论摘要建立，八节齐备，全部引用结论编号，不新增证据 | 专题结论摘要 |
| 7 反向审查 | 11 项检查全部过一遍并留记录（含"是否把现代研究强行对应古籍"） | 反审记录 |
