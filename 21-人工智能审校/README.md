# 21-人工智能审校

本目录存放"AI 审校记录卡"（编号前缀"审校记录-"，审校记录-0001 起）：登记 AI 辅助内容进入正式知识库前的审校记录。

## 规则

- **AI 是研究助手，不是最终裁判**：AI 生成内容一律视为"待审核材料"，未经人工核对不得进入正式知识库；
- 审校记录卡登记：审校对象、引用检查、术语检查、历史时期检查、传统与现代解释检查、安全检查、人工复核人、发现问题与处理结果；
- 模板见 01-知识卡模板/AI审校记录卡模板.md；
- 审校检查并入现有反方审查流程（11 项检查），本目录为审校留痕位置；
- 发现问题未解决前，对应内容保持"待复核/需要修订"状态，不公开。
