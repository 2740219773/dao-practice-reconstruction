# 17-医学观察资料卡

本目录存放"医学观察资料卡"（编号前缀"医学观察-"，医学观察-0001 起），登记内证记录、身体经验与医家个人观察等资料。

## 规则

- 编号前缀"医学观察-"（医学观察-0001 起），按《基础规范》第 2.1 节；
- 模板见 01-知识卡模板/医学观察资料卡模板.md；
- 医学观察模块（MEDOBS-001 内证观察笔记等）是独立研究主线，与概念专题（TOPIC-001 静）平级；
- 证据分层执行《医学观察资料分层规范》：传统医学原文 → 历代和当代医学解释 → 个人内证与身体观察 → 现代医学研究，四层不得混用；
- 最重要规则：**观察到了什么** 与 **作者认为这意味着什么** 必须分开记录；
- 个人内证与身体观察只用于描述经验、提出假说、提供待验证线索，不能用于证明解剖结构、确诊疾病或证明治疗有效；
- 不建立练功教程，不诊断疾病，不把个人观察直接推广为普遍规律。
