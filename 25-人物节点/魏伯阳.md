# 魏伯阳

## 一、人物定位

魏伯阳在后世炼丹传统中具有非常重要的地位，因为《周易参同契》长期被归于其名下。但对于问道志来说，最重要的不是把传统说法直接转成“历史事实”，而是把三个层次分开：

1. 传统如何描述魏伯阳；
2. 早期文献如何处理《参同契》的作者与传承；
3. 现代文本史研究能够确认到什么程度。

因此本节点的 `historicity` 标记为 `uncertain_traditional_figure`。

## 二、与《周易参同契》的关系

传统上，《周易参同契》长期被视为魏伯阳所作，并常把他放在东汉中期。

但现存早期资料并不提供一个简单、稳定、始终一致的“魏伯阳单独撰成今本《参同契》”故事。不同传统曾涉及徐从事、淳于叔通等人物，后来的注释家和炼丹家又逐渐强化魏伯阳的单一作者地位。

因此机器关系使用：

```text
魏伯阳 traditional_attribution 《周易参同契》
```

而不是：

```text
魏伯阳 authored 《周易参同契》
```

## 三、传统传记与历史事实

后世关于魏伯阳的传记包含隐居、炼丹、试丹和成仙等叙事。这些材料对于研究炼丹传统如何塑造祖师形象非常重要，但不能直接承担现代人物传记意义上的史实证明。

问道志保留这些内容时，应归入：

- 传统传记；
- 祖师形象；
- 炼丹文化记忆；

而不是“已确认生平”。

## 四、不建立的关系

当前明确不建立：

```text
魏伯阳 → 葛洪 → 张伯端 → 王重阳
```

这种关系最多可以作为阅读导航，不能自动解释为师承、直接影响或连续宗派传承。

同样，不建立：

```text
魏伯阳 founded 丹鼎派
```

因为“丹鼎派/丹道传统”是跨时代的实践和研究分类，并不是可以证明由魏伯阳创建的单一组织。

## 五、研究边界

- 《参同契》的传统年代、作者和今本文本形成必须分别记录；
- 传统传记中的成仙叙事属于宗教史资料，不作为现代事实判断；
- 不能因为后世内丹高度重视《参同契》，就把魏伯阳直接定义为宋元内丹某一宗派的历史祖师；
- 涉及炼丹内容时只做历史研究，不输出危险的矿物炼制与服食操作。
