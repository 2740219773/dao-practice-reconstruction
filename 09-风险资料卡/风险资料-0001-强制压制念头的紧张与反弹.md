# 强制压制念头的紧张与反弹

## 1. 风险类型

- 注意和意守相关；
- 心理影响。

## 2. 可能诱因

- 把静坐理解为「消灭念头」「脑子里不能有杂念」并持续执行压制操作（对应主张-0005 描述的常见表述，见 05-主张卡）；
- 追求「无念」状态，把念头的出现视为失败；
- 压念失败后的自我批评与继续加力；
- 环境或指导语强化「必须静下来」的要求。

## 3. 表现

记录时严格区分来源：

- 文献中常见表现（非项目参与者原话）：压抑期间念头频次不减反增、头紧绷感、紧张、「越压越多」的循环感（思维抑制研究，见资料来源）；
- 观察者现象：坐立不安、皱眉、呼吸急促、难以放松、频繁叹气；
- 机制候选：与思维抑制的反弹效应方向一致（Wegner 1987；思维抑制反弹荟萃）；
- 文献资料中的一般说明：思维抑制可导致压抑期念头频繁与压抑解除后的反弹，并伴随紧张、焦虑（Wegner 1987；思维抑制反弹荟萃）；
- 项目最终处理决定：暂无（本项目尚未开展实践）。

## 4. 严重程度

- 多数情况为 L1 轻度异常：短暂紧张、头胀、烦躁，停止后缓解；
- 若持续加重为持续焦虑、入睡困难等，升级为 L2；
- 若出现持续现实感减弱、无法自主停止等，按 L2/L3 处理。

本卡卡片发布风险 S0（纯知识整理）；所含实践最高风险 S2（需要专业审核的实践——持续压制念头属于注意操作类内容）。

## 5. 停止条件

出现以下任一表现即停止压制操作：

- 明显焦虑、头胀、紧张感加重；
- 「越压越多」循环持续超过数分钟且不缓解；
- 无法放松、呼吸急促；
- 因压不住念头而产生强烈挫败或自我批评。

停止后改为：不追求无念，只觉察念头并自然放下；或暂停练习回到日常活动。

## 6. 处理原则

### L1 处理原则

1. 立即停止当前练习；
2. 回到正常呼吸和日常活动；
3. 不继续追求或重复「无念」体验；
4. 记录发生时间、练习内容与持续时间；
5. 当天不再继续相同练习；
6. 若症状持续、加重或反复出现，升级为 L2。

### L2 处理原则

1. 停止相关实践；
2. 暂停参加项目实践活动；
3. 不再接受人工智能生成的练习建议；
4. 建议寻求合格的医疗或心理专业评估；
5. 记录事件，不在公开社区讨论当事人身份；
6. 专业人员确认前不得恢复相关练习。

### L3 处理原则

按安全边界 V0.2 的 L3 流程处理（立即停止一切练习、联系紧急医疗服务、不独处）。
