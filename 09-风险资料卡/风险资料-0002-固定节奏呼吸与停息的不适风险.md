# 固定节奏呼吸与停息的不适风险

## 1. 风险类型

- 呼吸相关。

## 2. 可能诱因

- 按固定节拍或时长呼吸（如吸-停-呼按固定秒数执行、数息时强行拉长呼吸周期）；
- 呼气后停息数秒至数十秒（憋气）；
- 呼吸频率过快或过慢，超出个体自然节律；
- 叠加因素：空腹、疲劳、炎热环境、焦虑状态；
- 有呼吸系统、心血管或神经系统基础疾病者进行同类练习。

## 3. 表现

记录时严格区分来源：

- 文献中常见表现（非项目参与者原话）：头晕、口周及指尖麻木、胸闷、心悸、站立不稳等；
- 文献及一般现场观察中可能出现的外在表现：面色改变、出汗、呼吸紊乱、站立不稳等；
- 机制候选：头晕发麻与过度通气导致的二氧化碳下降（呼吸性碱中毒）方向一致；停息过长与血氧下降、二氧化碳升高相关（Fitz-Clarke 2018；Gilbert 1999）；
- 医学资料中的一般说明：快速或过深呼吸可致碱中毒症状（头晕、口周及指尖麻木）；长时间停息超过个体极限（terminal breakpoint）可致缺氧相关反应，极端情况有晕厥风险（Fitz-Clarke 2018；Gilbert 1999）；
- 项目最终处理决定：暂无（本项目尚未开展实践）。

## 4. 严重程度

- 短暂头晕、发麻、胸闷等可按 L1 事件处理（恢复自然呼吸后缓解）；晕厥、意识不清等应按 L3 事件处理；
- 有基础疾病者任何类似表现都应提高警惕。

本卡卡片发布风险 S0（纯知识整理）；所含实践最高风险 S3（长时间停息或强力呼吸，见安全边界 V0.2 的 S3 定义）。

## 5. 停止条件

出现以下任一表现立即停止并恢复自然呼吸：

- 头晕、眼前发黑、口周或指尖发麻；
- 胸闷、心悸、呼吸困难感；
- 憋气感强烈时仍被要求「再坚持几秒」——本项目禁止此类要求；
- 任何症状持续不缓解。

同时：不与他人比较停息时长或呼吸频率；不追求「越慢越好」「停得越久越好」。

## 6. 处理原则

### L1 处理原则

1. 立即停止当前练习，回到自然呼吸；
2. 保持坐位或平躺，避免立即站立活动；
3. 不继续追求或重复该呼吸模式；
4. 记录发生时间、练习内容与持续时间；
5. 当天不再继续相同练习；
6. 若症状持续、加重或反复出现，升级为 L2。

### L2 处理原则

1. 停止相关实践，暂停参加项目实践活动；
2. 不再接受人工智能生成的练习建议；
3. 建议寻求医疗专业评估；
4. 记录事件，不在公开社区讨论当事人身份；
5. 专业人员确认前不得恢复相关练习。

### L3 处理原则

1. 立即停止一切练习；
2. 联系当地紧急医疗服务或立即前往医疗机构（晕厥、严重胸痛、明显呼吸困难）；
3. 不让当事人独处；
4. 保存必要事件记录；
5. 启动重大安全事件审查。
