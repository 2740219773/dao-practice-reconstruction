# 持续关注身体内部感觉的风险

## 1. 风险类型

- 注意和意守相关；
- 身体不适；
- 心理影响。

## 2. 可能诱因

- 长时间专注某一身体部位（意守丹田、内视、观想某处发热/气行、专注呼吸时的体内感受）；
- 把注意力当作「找气感」的工具，反复搜寻热、麻、胀、跳动等感觉；
- 对已出现感觉的过度关注与反复确认；
- 个体因素：焦虑倾向、躯体症状敏感、惊恐发作史、创伤史。

## 3. 表现

记录时严格区分来源：

- 文献中常见表现（非项目参与者原话）：注意力放大正常生理信号、对躯体感觉的警觉增强、「越注意越明显」的循环感；
- 观察者现象：反复触碰或查看身体部位、频繁量血压/测心率、回避活动；
- 机制候选：与注意放大正常生理信号的方向一致——注意聚焦可使原本存在的心跳、呼吸、肠鸣等信号被更清晰感知，也可能增强对躯体感觉的警觉（现代研究-0003）；
- 文献资料中的一般说明：对躯体感觉的灾难化解读与惊恐样发作有关（内感受恐惧模型）；对高焦虑个体，内感受训练可能加剧而非缓解躯体警觉（Clark 1986；现代研究-0003）；
- 项目最终处理决定：暂无（本项目尚未开展实践）。

## 4. 严重程度

- 多数情况为 L1：部位紧张、对感觉的过度在意、短暂不安；
- 若诱发明显焦虑、惊恐样发作、持续担忧身体健康，升级为 L2；
- 创伤史个体出现闯入性体验时按 L2 处理。

本卡卡片发布风险 S0（纯知识整理）；所含实践最高风险 S2（持续集中注意身体部位）。

## 5. 停止条件

出现以下任一表现即停止意守/内视类操作：

- 焦虑明显加重或出现恐慌感；
- 注意力无法从身体部位转移，反复确认感觉；
- 因「找不到感觉」或「感觉消失」产生挫败或担忧；
- 原有躯体不适因注意而加重。

停止后：将注意力转向外部环境（视觉、听觉）或自然呼吸，不继续搜寻感觉。

## 6. 处理原则

### L1 处理原则

1. 立即停止当前练习；
2. 回到自然呼吸与日常活动，转移注意力至外部环境；
3. 不继续追求或重复该感觉；
4. 记录发生时间、练习内容与持续时间；
5. 当天不再继续相同练习；
6. 若症状持续、加重或反复出现，升级为 L2。

### L2 处理原则

1. 停止相关实践，暂停参加项目实践活动；
2. 不再接受人工智能生成的练习建议；
3. 建议寻求合格的心理或医疗专业评估（尤其有焦虑、惊恐、创伤史者）；
4. 记录事件，不在公开社区讨论当事人身份；
5. 专业人员确认前不得恢复相关练习。

### L3 处理原则

按安全边界 V0.2 的 L3 流程处理（立即停止一切练习、联系紧急医疗服务、不独处）。
