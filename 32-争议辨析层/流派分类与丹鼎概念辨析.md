# 流派分类与“丹鼎派”概念辨析

## 一、问题来源

问道志早期为了快速建立知识地图，把以下对象统一放进了“流派节点”：

- 先秦道家；
- 黄老思想；
- 丹鼎派；
- 全真道；
- 正一道。

这种做法在导航层面方便，但在历史研究层面会造成严重混淆，因为它们并不是同一种类型的历史实体。

## 二、新版分类原则

V3 暂时保留顶层 `school` 类型以兼容旧数据，同时使用 `school_kind` 细分：

| 对象 | 新版分类 | 核心理由 |
| --- | --- | --- |
| 先秦道家 | `intellectual_tradition` | “道家”作为统一思想史类别主要由汉代史家追认，不能假定战国人物已有统一宗派自称 |
| 黄老思想 | `intellectual_tradition` | 战国末至汉初的思想、政治和修养传统，边界本身存在研究争议 |
| 丹道传统 | `practice_tradition` | 横跨外丹、内丹、金丹文本与炼养传统，不作为单一组织处理 |
| 全真道 | `religious_order` | 十二世纪形成，有较明确创建人物、早期弟子群体及后续宗派组织 |
| 正一道 | `religious_tradition` | 与天师道、正一盟威和后世正一体系相关，跨越多个组织与历史阶段 |

## 三、“先秦道家”为什么不是宗派

“道家”这一思想史类别是在汉代整理先秦思想时逐渐形成的。

后世把老子、庄子置于道家核心位置具有很强的思想史意义，但这不能证明：

- 老子自称“道家”；
- 庄子加入了一个叫“道家”的组织；
- 老子是庄子的正式师父；
- 战国时代存在统一的“道家宗派总部”。

因此新版只建立后世分类意义上的 `related_to` 关系。

## 四、黄老为什么单独建节点

黄老在战国末和汉初具有更具体的历史语境，涉及：

- 黄帝与老子并举；
- 无为政治；
- 统治者自我修养；
- 社会秩序与宇宙时序。

它与后世“道家”分类相交，但不是“老庄思想”的另一个名称。

同时，哪些出土文献、传世文献应该归为黄老，现代研究仍有讨论，因此不能建立一个无争议的“黄老经典全集”。

## 五、“丹鼎派”到底是什么

早期项目把“丹鼎派”当成一个类似全真道的宗派节点，这会产生两个误导：

1. 仿佛存在从魏伯阳、葛洪到张伯端一直组织连续的“丹鼎派”；
2. 仿佛可以用一条“外丹 → 内丹”的路线解释整个中国炼丹史。

新版采用：

```yaml
id: school.danding
name: 丹道传统
school_kind: practice_tradition
aliases:
  - 丹鼎派
```

即：保留“丹鼎派”作为历史资料、近现代分类和旧项目路径中的兼容名称，但正式建模使用“丹道传统”。

## 六、为什么不用“魏伯阳创建丹鼎派”

魏伯阳本身就是一个历史性需要谨慎处理的人物。《周易参同契》虽长期传统归于魏伯阳，但作者和文本形成问题复杂。

即便接受传统归属，也只能建立：

```text
魏伯阳 traditional_attribution 《周易参同契》
```

不能进一步自动推出：

```text
魏伯阳 founded 丹鼎派
```

因为“丹道传统”本身就是跨时代研究分类，而不是一个具有明确创建时刻的教团。

## 七、全真为什么可以使用 founded

与“先秦道家”“丹道传统”不同，全真运动的十二世纪形成过程、王重阳及第一代弟子群体有较明确历史研究基础。

因此可以建立：

```text
王重阳 founded 全真道
```

但仍要区分：

- 王重阳时代的早期全真；
- 十三世纪逐渐制度化的祖师谱系；
- 后世具体支派。

`founded` 不等于“后世所有制度均由创建者一次设计完成”。

## 八、正一道为什么不直接等于东汉天师道

正一传统的历史根源与东汉天师道和“正一盟威”等传统密切相关，但从二世纪共同体到后世龙虎山正一体系经历了长期变化。

因此当前使用：

```yaml
school_kind: religious_tradition
```

并计划另建 `school.tianshi`，让早期天师共同体和后世正一传统既有关联又不被完全合并。

## 九、当前禁止的知识图谱边

以下关系不得在没有新增专门证据时建立：

```text
老子 founded 先秦道家
庄子 belongs_to 先秦道家（无时代限定）
魏伯阳 founded 丹鼎派
葛洪 belongs_to 丹鼎派（当作历史组织）
张伯端 → 王重阳
外丹 develops 内丹（作为唯一线性起源）
正一道 = 符箓
全真道 = 内丹
```

## 十、当前允许的关系

```text
老子 related_to 先秦道家
庄子 related_to 先秦道家
黄老 related_to 先秦道家
魏伯阳 traditional_attribution 《周易参同契》
葛洪 related_to 丹道传统
张伯端 related_to 丹道传统
王重阳 founded 全真道
全真道 related_to 内丹
正一道 related_to 符箓科仪
```

每条关系仍需要 `scope` 和 `source_refs` 限定。

## 十一、对网站和人工智能展示的影响

前端不应统一显示“流派”标签。

建议显示为：

- 先秦道家 → **思想传统**；
- 黄老思想 → **思想传统**；
- 丹道传统 → **修炼传统**；
- 全真道 → **宗教宗派**；
- 正一道 → **宗教传统**。

这样用户进入知识地图时，可以直接看到这些对象的性质差异。

人工智能回答“某人属于什么派”时，也必须先判断这是：

- 历史自我认同；
- 后世归类；
- 祖师谱系；
- 现代研究分类。

不能把四者混在一起。

## 十二、来源与后续核对

当前主要依据：

- Stanford Encyclopedia of Philosophy 关于道家、宗教道教与黄老的研究综述；
- Fabrizio Pregadio 关于《参同契》、金丹、外丹与内丹的文本及炼丹史研究；
- Louis Komjathy 关于早期全真和王重阳的研究；
- Jinping Wang 关于十三世纪全真谱系建构的研究；
- Terry F. Kleeman 关于早期天师道组织和仪式的研究。

后续仍需：

- 建立天师道独立节点；
- 对“丹鼎派”一词的近现代分类史做更专门的中文学术文献检索；
- 建立内丹南宗节点，避免张伯端长期直接挂在总“丹道传统”之下；
- 研究正一道在宋元明清的具体制度变化。
