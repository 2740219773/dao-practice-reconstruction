# 14-当代传播资料卡

本目录存放"当代传播资料卡"（决策-0003）：登记视频、网络文章、网络课程等当代网络修炼传播材料。

## 规则

- 编号前缀"传播资料-"（传播资料-0001 起），按《基础规范 V0.3》第 2.1 节；
- 原始材料先进入 12-待处理资料/当代传播资料/ 暂存区（含 00-资料说明、01-原视频索引、03-内容整理稿等），完成整理与拆解后建立本目录正式卡；
- 当代传播材料不能直接作为古籍依据，不能作为现代学术证据；
- 其中古籍引文必须回到原始来源核验（见各资料目录的 04-传统出处待查表.md）；
- 具体实践方法不得直接进入实践协议，必须逐段风险审查；
- 公开仓库不保存未经许可的完整视频、完整音频与完整逐字稿。
