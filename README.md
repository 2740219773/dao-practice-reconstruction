# 道修重构计划

> 道可道，非常道。

**全称：** 传统道家修炼知识重构与实践研究计划
**公开网站：** 问道志（研究工作台公开预览版；website/ 为 VitePress 源码，内容按决策-0004 公开原则分批上线）
**状态：** 阶段一（基础知识重构），2026 年 8 月启动

把传统道家修炼中高度抽象、依赖师承解释和个人悟性的内容，转化为具有来源、语境、结构、争议、证据和修订记录的现代知识体系。

项目不是宗教组织、医疗机构、修炼培训机构或商业课程；不预设任何传统说法必然正确，也不把个人体验直接视为客观规律。

## 三条独立主线（模块）

项目后续分为三条相互独立、完全平级的模块主线，架构上平行、执行上串行：

```
                    ┌─ TOPIC-001 静（概念与思想研究）
道修知识研究体系 ───┼─ DAOYIN-001 八段锦（导引术与身体训练）
                    │   └─ DAOYIN-002 五禽戏
                    └─ MEDOBS-001 内证观察笔记（医学观察与身体经验）
```

| 模块 | 前缀 | 首批样板 | 研究什么 | 不研究什么 |
| ---- | ---- | -------- | -------- | ---------- |
| 概念与思想研究 | TOPIC- | TOPIC-001 静 | "静"在传统文献中的含义、过程/状态、是否等于无念、不同文献异同、现代有限对应、传播说法证据问题 | 导引术动作、内证体验、中医诊断、具体身体练习方案 |
| 导引术与身体训练 | DAOYIN- | DAOYIN-001 八段锦 | 完整身体训练系统：历史来源、版本演变、动作结构、呼吸/意念要求、传统功效主张、现代研究、适用人群、禁忌风险 | 定义"静""气""心"的完整理论（只建立关联） |
| 医学观察与身体经验 | MEDOBS- | MEDOBS-001 内证观察笔记 | 观察者记录了什么、作者如何解释、与传统/现代医学关系、独立验证、替代解释、可作假说的内容 | 练功教程、疾病诊断、经络解剖证明、据主观感觉判脏腑 |

模块边界：三者平级，互不包含。概念专题不研究导引术动作与内证体验；导引术模块不重新完成概念史（"松静""调息"等只建立关联）；医学观察模块不建立练功教程。模块间只通过「关联模块」导航与概念链接引用，不提前写结论。

**执行顺序（严格串行）：** 第一阶段 TOPIC-001 静（概念型生产线）→ 第二阶段 DAOYIN-001 八段锦（导引术型生产线）→ 第三阶段 DAOYIN-002 五禽戏（验证模板可复制）→ 第四阶段 MEDOBS-001 内证观察笔记（医学观察型生产线）→ 第五阶段汇总三类模板形成统一生产规范。禁止交叉开工。

## 核心规则（摘要）

- 知识七层分离，不混合：L1 原始文献、L2 历代注释、L3 近现代传承与实践解释、L4 现代学术研究、L5 项目解释、L6 项目假说、L7 个人实践记录；
- 所有内容多维证据标注：T（文献）/ I（解释，分最低层级与最高推论层级）/ E（现代）/ M（对应）/ R（重复）/ C（反证）/ S（风险）；
- 来源可信等级（甲乙丙丁/待考/禁用）：面向公众与检索的直观分级，全部卡片通用；T/I/E 证据等级按决策-0006 逐步退役（新卡停填、存量卡回填甲乙丙丁、证据等级规范转为历史参考）；
- 社区观察层（20-社区观察/）与正式知识区严格隔离：社区用来发现问题，不直接充当权威答案；
- 知识卡字段键统一使用中文，程序读取需求由《字段映射表》单独维护；
- 每个争议至少保留两种解释，不提前合并；
- AI 是研究助手，不是最终裁判；AI 输出一律待人工核对（审校留痕见 21-人工智能审校/）；
- 所有判断可追溯、可修订，重要变化记决策记录卡。

## 安全边界（摘要）

第一阶段以知识整理为主，只开放 S0 和少量不干预人体的 S1 内容。强制呼吸、闭气、胎息、辟谷、丹药、意守敏感部位等中高风险内容只建立研究索引，不转化为公众操作教程。出现异常首先作为安全事件记录，不解释为“突破”“排病”。

详细规则见 `00-项目规范/安全边界 V0.2.md`。
