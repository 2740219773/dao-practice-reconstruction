# 问道志 · 道修重构计划

> 道可道，非常道。

**全称：** 传统道家修炼知识重构与实践研究计划

**项目定位：** 以可靠研究支撑学习、实践、记录、复盘与持续纠偏的开放道修知识工程。

**当前状态：** 2026 年 8 月，V3.8 知识图谱稳定基线已建立；实践与产品主线已推进到 V2.7，形成“今日修持—实践卡—本地记录—7天/30天复盘—安全回退”的可用闭环，并进入首轮真实7天试运行与产品减法阶段。当前已有 36 个实践/schema/产品观察测试、4 条真实 Chromium 回归与 Cloudflare Pages 当前提交验证。

## 一、问道志现在要解决什么

问道志最初从“把道家、道教相关知识整理清楚”开始，但长期目标并不只是做一套资料库。

项目现在同时回答两类问题：

### 我要学习

- 一句话最早出自哪里？
- 同一个“静、虚、心、气、息、身”，在不同文本里是不是同一含义？
- 心斋、坐忘、静坐、导引、吐纳、服气、内丹之间到底是什么关系？
- 哪些是经典原文，哪些是后世解释，哪些只是现代传播说法？
- 一个传统主张有没有史料、学术研究或现代证据支持？

### 我要实践

- 一个现代人应该从哪些低风险基础能力开始？
- 怎样调身而不是硬摆“练功姿势”？
- 怎样观察自然呼吸而不把察息变成主动调息？
- 杂念多时如何处理，而不是强迫自己“无念”？
- 练习出现腿麻、肩颈紧、烦躁、异常体验时该怎么回退或停止？
- 怎样记录和复盘，而不是制造“修为值”“境界积分”？
- 传统方法可以给现代实践什么背景，又有哪些内容不能直接照搬？

这两条路径共享同一套证据与安全底座，但**知识页不自动变教程，实践页也不冒充古法复原**。

## 二、核心原则

### 1. 原文为根

重要判断尽量回到具体文献、章节、版本和语境，不只引用二手转述。

### 2. 不同证据分层

必须区分：

- 原始文献；
- 现代历史与学术研究；
- 后世传统解释；
- 个人经验；
- 现代医学、心理学、运动科学等实证研究；
- 项目自身的教学设计与推论。

A—E 字母在项目中是**来源类别**，不是从强到弱的简单排名。

### 3. 相关不等同

例如：

```text
自然察息 ≠ 吐纳
自然察息 ≠ 服气
注意返回基础 ≠ 《坐忘论》完整收心体系
短时基础安坐 ≠ 《庄子》坐忘
短时基础安坐 ≠ 内丹筑基
轻柔动静转换 ≠ 古代导引套路复原
传统“气” ≠ 某一个现代生理实体
```

### 4. 实践必须可停止、可回退

练习不是线性升级游戏。状态不好可以不练；一个阶段不稳定可以退回更简单的单元；出现异常时安全优先于进度。

### 5. 个人体验不是客观机制

“今天手心发热”可以记录为体验，但不能自动升级成“经脉已通”“气到了某处”的事实判断。

### 6. 社区材料只发现问题

Reddit、论坛、短视频评论等当代社区材料可以帮助发现：

- 人们真正困惑什么；
- 哪些误解反复出现；
- 哪些实践问题值得研究。

但社区观点与正式知识区严格隔离，不直接充当权威答案。

### 7. AI 是辅助者，不是裁判

AI 可以检索、比较、总结、做反方审查和复盘辅助，但不得替代来源核对，也不得根据主观体验诊断疾病、判定境界或自动生成中高风险练法。

### A. 研究证据系统

现有研究层包括：

- 文献卡、原文卡、概念卡；
- 主张、假说、争议；
- 现代研究与风险资料；
- 问题地图、概念辨析；
- 社区观察与 AI 审校；
- TOPIC 专题研究与来源核对/证据总账。

“静、虚、心、气、息”等核心专题已经形成连续研究基础；TOPIC-003/004/005 已整合入主分支。

### B. V3.8 知识图谱

V3 图谱是统一实体与关系导航层，当前基线包括：

- 38 个正式节点；
- 79 条规范关系；
- 经典、人物、传统/流派、概念、方法、阶段等实体；

图谱关系表示有来源限定的历史、文本或概念关联，**不把现代教学顺序伪装成历史传承**。

- URL 参数不绕过黄色/红色安全状态；
- 日读 / 夜读；
- 独立的7天产品观察面板。

### D. 修持记录、复盘与产品观察

修持闭环为：

```text
今日修持
↓
本地修持记录
↓
最近7天规则复盘
↓
最近30天阶段复盘
↓
继续 / 回退 / 暂停 / 讨论分流
```

修持记录存储：

```text
wendaozhi.practice.records.v1
schemaVersion: 1
```

观察重点包括：身体适应、呼吸自然度、注意发现与返回、情绪与功能影响、日用迁移、异常、超时和调整。

当前数据只保存在浏览器本地，支持 JSON 导入/导出与 schema v1 迁移保护；AI 复盘只生成可自行复制的统计摘要，不自动发送原始日志。

V2.7 另设独立产品观察：

```text
wendaozhi.practice.trial.v1
schemaVersion: 1
```

只记录操作耗时、入口、难选字段、低价值字段、被催打卡/升级感和一句话备注。它不进入修持 schema，不参与7天/30天阶段判断，也不形成总分、完成率或修炼结论。

## 四、基础修持路线

当前现代教学路线：

```text
准备与安全检查
  ↓
调身与舒适姿势
  ↓
身体接触觉察
  ↓
自然察息
  ↓
注意返回与收心基础
  ↓
短时基础安坐
  ↓
轻柔动静转换
  ↓
日用觉察
  ↓
阶段复盘与分流
```

箭头只表示问道志的现代教学依赖，不表示古代宗派次第；系统也不会根据一次记录自动从第 N 张卡推进到第 N+1 张。

### 分流方向

完成基础能力后，再根据兴趣、安全状态和证据准备度分流：

- **静修深化**：继续研究和设计更深入的坐式静修；
- **导引深化**：进入来源明确、动作版本清楚、风险可说明的身体练习；
- **生活养修**：把低风险觉察和生活调摄继续融入日常；
- **丹道研究**：默认 `research_only`，先研究历史、经典、术语与体系，不自动开放火候、周天、闭气、采炼等操作。

## 五、安全边界

第一批实践只开放 S1 低风险内容。

当前不自动开放：

- 固定节拍呼吸；
- 主动延长呼吸；
- 屏息、闭气、胎息；
- 强力深呼吸、快速呼吸；
- 逆腹式等特殊呼吸；
- 长时间意守敏感部位；
- 长时间禁动、忍痛静坐、闭关；
- 服气具体操作；
- 内丹火候、周天、采炼；
- 辟谷、丹药；
- 追求晕眩、麻木、幻觉、离体感等异常体验。

出现异常首先作为安全事件处理，不默认解释成“突破”“排病”“气冲病灶”。

完整规则：`00-项目规范/安全边界 V0.2.md` 与 `33-实践体系/实践问题与安全分流-V1.0.md`。

## 九、项目不是

问道志不是：

- 宗派宣传平台；
- 修炼效果承诺；
- 医疗或心理治疗服务；
- “古籍一句话自动生成练法”的内容工厂；
- 用现代科学术语包装传统说法的证明工程；
- 用 AI 判断个人境界的系统。

它更希望成为一套可以持续修订的研究与实践工作台：

**来源可查，关系可辨，边界可见，实践可停，体验可记，问题可复盘。**
