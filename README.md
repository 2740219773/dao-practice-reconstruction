# 道修重构计划

> 道可道，非常道。

**全称：** 传统道家修炼知识重构与实践研究计划（Daoist Practice Reconstruction Project，DPRP）
**公开网站：** 问道志（研究工作台公开预览版；website/ 为 VitePress 源码，内容按决策-0004 公开原则分批上线）
**状态：** 阶段一（基础知识重构），2026 年 8 月启动

## 项目简介

道修重构计划是一个面向道家文化、思想与修习体系的长期知识工程项目。

项目以道家经典、历代文献、现代研究资料和现实讨论为基础，通过资料整理、概念拆解、来源考证、主题关联与知识重构，逐步建立一个能够持续积累、相互验证和不断完善的道学知识体系。

项目并不只是收集文章、书籍或修炼方法，也不试图简单地把传统内容转化为零散的"知识点"。项目更关注以下问题：

* 一个概念最早来自哪里，后来经历了怎样的演变；
* 不同经典、流派和历史时期对同一问题有何异同；
* 理论、方法、经验和民间说法应当如何区分；
* 修习内容中的前提、步骤、风险和适用范围是什么；
* 如何利用现代知识管理与人工智能工具，提高整理、检索、比较和研究效率。

## 项目目标

项目希望逐步完成四个层面的建设。

### 一、资料整理

系统收集和整理道家经典、注疏、研究资料、修习文献、历史人物、流派传承及现代讨论，为后续研究建立稳定的资料基础。

### 二、知识重构

将分散在不同文献和语境中的内容，整理为概念卡、人物卡、经典卡、方法卡、流派卡、问题卡和专题研究等结构化内容。

### 三、关系建立

梳理概念之间、经典之间、人物与流派之间，以及理论与实践之间的关联，逐步形成可以交叉检索和相互印证的知识网络。

### 四、智能辅助

探索人工智能在资料分类、内容提取、观点比较、来源追踪、知识关联和专题研究中的应用，并尝试构建面向道学研究的多智能体协作体系。

## 基本原则

### 尊重原始资料

尽可能保留原文出处、时代背景和完整语境，避免脱离原文进行过度概括。

### 区分不同层次

明确区分经典原文、历代注解、现代研究、个人经验、民间说法和项目推论，避免将不同性质的内容混为一谈。

### 保持来源可追溯

重要观点应尽量标明出处、版本和资料来源，使内容能够被重新查找、核对和修正。

### 不急于得出结论

面对流派差异、历史争议和修习经验，优先呈现证据、背景和不同观点，而不是追求简单统一的答案。

### 持续修订

项目中的内容不是固定结论。随着新资料、新研究和新认识的加入，已有内容会不断补充、修正和重构。

## 内容范围

目前计划整理的主要内容包括：

* 道家经典与重要注疏；
* 道家思想、概念与术语；
* 历史人物、流派与传承；
* 修习理论、方法与注意事项；
* 内丹、养生、静坐及相关历史资料；
* 道家思想与现代生活的关系；
* 传统知识的现代化整理方法；
* 人工智能辅助道学研究的方法与工具；
* 面向具体问题的专题研究与资料索引。

## 项目定位

道修重构计划首先是一个开放的学习与研究项目，而不是宗派宣传、修炼承诺或权威结论的发布平台。

项目希望在传统文献与现代工具之间建立一座桥梁：既尊重传统内容本身，也使用现代知识工程的方法，使复杂、分散且容易混淆的道学资料变得更加清晰、可靠和便于研究。

项目不是宗教组织、医疗机构、修炼培训机构或商业课程；不预设任何传统说法必然正确，也不把个人体验直接视为客观规律。

## 项目愿景

长期来看，项目希望形成一套具备以下特征的道学知识体系：

* 内容有来源；
* 观点有层次；
* 概念有联系；
* 争议有记录；
* 方法有边界；
* 资料可检索；
* 研究可延续；
* 系统可持续演化。

这不是一项追求快速完成的工作，而是一份持续整理、持续求证、持续反思的长期记录。

## 三条独立主线（模块）

项目分为三条相互独立、完全平级的模块主线，架构上平行、执行上串行：

```
                    ┌─ TOPIC-001 静（概念与思想研究）
道修知识研究体系 ───┼─ DAOYIN-001 八段锦（导引术与身体训练）
                    │   └─ DAOYIN-002 五禽戏
                    └─ MEDOBS-001 内证观察笔记（医学观察与身体经验）
```

| 模块 | 前缀 | 首批样板 | 研究什么 | 不研究什么 |
| ---- | ---- | -------- | -------- | ---------- |
| 概念与思想研究 | TOPIC- | TOPIC-001 静 | "静"在传统文献中的含义、过程/状态、是否等于无念、不同文献异同、现代有限对应、传播说法证据问题 | 导引术动作、内证体验、中医诊断、具体身体练习方案 |
| 导引术与身体训练 | DAOYIN- | DAOYIN-001 八段锦 | 完整身体训练系统：历史来源、版本演变、动作结构、呼吸/意念要求、传统功效主张、现代研究、适用人群、禁忌风险 | 定义"静""气""心"的完整理论（只建立关联） |
| 医学观察与身体经验 | MEDOBS- | MEDOBS-001 内证观察笔记 | 观察者记录了什么、作者如何解释、与传统/现代医学关系、独立验证、替代解释、可作假说的内容 | 练功教程、疾病诊断、经络解剖证明、据主观感觉判脏腑 |

模块边界：三者平级，互不包含。模块间只通过「关联模块」导航与概念链接引用，不提前写结论。

**执行顺序（严格串行）：** 第一阶段 TOPIC-001 静 → 第二阶段 DAOYIN-001 八段锦 → 第三阶段 DAOYIN-002 五禽戏 → 第四阶段 MEDOBS-001 内证观察笔记 → 第五阶段汇总三类模板形成统一生产规范。禁止交叉开工。

## 核心规则（摘要）

- 知识七层分离，不混合：L1 原始文献、L2 历代注释、L3 近现代传承与实践解释、L4 现代学术研究、L5 项目解释、L6 项目假说、L7 个人实践记录；
- 所有内容多维证据标注：T（文献）/ I（解释）/ E（现代）/ M（对应）/ R（重复）/ C（反证）/ S（风险），来源可信等级（甲/乙/丙/丁 + 核对状态 + 采用状态）面向公开展示（决策-0006）；
- 六层结构（《项目结构总图》）：正式知识 / 专题综合 / 用户入口 / 采集观察 / 治理审校 / 展示；
- 社区观察层与正式知识区严格隔离：社区用来发现问题，不直接充当权威答案；
- 每个争议至少保留两种解释，不提前合并；
- AI 是研究助手，不是最终裁判；AI 输出一律待人工核对（审校留痕见 21-人工智能审校/）；
- 所有判断可追溯、可修订，重要变化记决策记录卡。
