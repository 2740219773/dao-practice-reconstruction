# 外丹

## 一、方法定位

外丹是中国古代道教炼丹传统的重要组成部分。现代研究通常以“外丹”指通过外在物质、炉鼎和加热等过程制成丹药的炼丹实践，并把它与内丹区分。

外丹不仅是“古代化学实验”。许多传统中的炼制过程同时包含仪式、禁忌、传授、宇宙论和宗教目标，因此必须放在道教史、技术史和宗教实践史的综合语境中研究。

## 二、历史来源

中国炼丹相关材料很早出现，至中古时期形成更明确的外丹传统和文本体系。不同传统之间的配方、仪式和理论并不统一。

问道志现阶段不试图建立一个从早到晚无断裂的“外丹标准工艺”，而是把它作为一个历史类别，逐步连接：

- 早期神仙与方术材料；
- 中古道教炼丹传统；
- 《参同契》及其复杂接受史；
- 葛洪、《抱朴子内篇》等相关人物与文本；
- 后世外丹与内丹的关系。

## 三、理论与实践背景

外丹文本常见：

- 丹、药；
- 炉鼎；
- 火候；
- 矿物与金属材料；
- 阴阳、五行或其他宇宙论解释；
- 仪式、斋戒、传授和禁忌。

这些元素在不同时代和传统中组合不同，不能把后世某一套解释投射到全部外丹史。

## 四、与《参同契》的关系

《参同契》长期在炼丹和内丹史中具有特殊地位，但其文本性质和历史形成复杂。

因此问道志不再写：

```text
《参同契》 = 外丹经典
```

也不写：

```text
外丹 → 《参同契》 → 内丹
```

当前只保留“重要关联”，再由《参同契》经典卡和接受史研究说明它如何被不同传统解释。

## 五、与内丹的关系

外丹与内丹共享大量炼丹术语和象征语言，但二者的主要实践场域不同。

研究上可作对照：

```text
外丹：外在物质、炉鼎与炼制过程
内丹：修炼者自身的生命与身心炼养过程
```

这只是第一层分类。历史上二者有复杂交流，不能用“外丹失败后改成内丹”之类单因果故事概括。

## 六、葛洪与中古炼丹

葛洪和《抱朴子内篇》是研究中古早期神仙术、药物与炼丹的重要入口。

但本卡暂不建立：

```text
葛洪 authored 外丹
```

或：

```text
葛洪 → 外丹 → 内丹
```

这类错误关系。待葛洪人物节点迁移和《抱朴子》经典节点建立后，再加入具体有来源的关系。

## 七、风险与边界

外丹是本项目中必须设置明确安全边界的方法节点。

历史炼丹常涉及具有显著毒性的矿物和金属材料。问道志只整理：

- 历史文本；
- 技术史；
- 宗教史；
- 思想和象征体系；
- 中毒、医疗与社会史研究。

不提供：

- 炼丹配方；
- 具体原料比例；
- 炉温和时序；
- 丹药服食剂量；
- 任何复现古代炼制过程的操作指导。

## 八、现代研究

现代研究可以分析外丹的：

- 化学史；
- 冶金与材料史；
- 毒理史；
- 医药史；
- 宗教仪式史；
- 道教思想史。

但不能因为某些炼制过程存在化学反应，就把传统外丹的宗教目标全部改写成现代化学目标。
