# 静坐

## 一、方法定位

“静坐”在今天常被当作一个很自然、很古老、定义统一的词，但从历史研究角度看，它更适合作为一个**坐式修养总类**。

不同历史传统可能使用：

- 安坐；
- 守一；
- 坐忘；
- 存想；
- 内观；
- 打坐；
- 内丹坐式修炼；

等不同术语和方法。

因此问道志保留“静坐”作为导航节点，但不把所有方法压成一套统一步骤。

## 二、与先秦修养的关系

现代研究认为，先秦和汉初道家相关材料中已经存在与身体安定、呼吸、注意、虚静有关的修养传统。

但从这些研究不能直接推出：

```text
《道德经》已经明确教授今天所谓“静坐法”
```

或：

```text
先秦所有静修 = 后世盘坐冥想
```

文本中的姿势、注意和呼吸必须按具体出处分析。

## 三、静坐与“静”

`concept.jing` 是一个多义概念，可以指安定状态、修养原则及后世体系化过程。

静坐则是坐式实践类别。

因此：

```text
静坐 related_to 静
```

而不是：

```text
静 = 静坐
```

## 四、静坐与坐忘

《庄子·大宗师》的“坐忘”是具体文本中的修养表达，后世又有《坐忘论》等体系化发展。

静坐比坐忘范围更宽：

```text
静坐：坐式修养总类
坐忘：特定经典与后世传统中的修养概念/方法
```

因此二者只能建立一般关联，不能写成同义词。

## 五、静坐与心斋

心斋出自《庄子·人间世》，重点在“虚”“心”“听之以气”等语境。经典本身并没有把它明确命名为今天意义上的“静坐教程”。

所以项目不建立：

```text
静坐 contains 心斋
```

也不把心斋自动设为静坐第一阶段。

## 六、静坐与内丹

宋元以后部分内丹传统大量采用坐式修养，但内丹体系还包括更复杂的术语、理论、身体观和阶段解释。

因此：

```text
静坐 related_to 内丹
```

不等于：

```text
静坐 = 内丹
```

## 七、现代研究边界

现代冥想研究可以研究：

- 注意；
- 情绪；
- 呼吸；
- 心率；
- 脑电；
- 主观体验；

等具体变量。

这些现代研究不能直接证明古代“虚、静、坐忘、守一”之间已经存在同一个心理或神经机制。

## 八、安全边界

问道志不把历史文本直接转写成极端坐姿、长时间禁动、强制压念或异常呼吸训练。

实践性内容若未来单独建立，应遵循：

- 以舒适、自然、可停止为前提；
- 不以疼痛、麻木、晕厥或意识异常为追求目标；
- 身体疾病或心理症状不由静坐替代专业诊疗；
- 历史研究页与现代练习指南分开。
