# 13-参考资料

本目录集中登记支撑项目判断的现代学术专著、论文、工具书等参考资料（《基础规范 V0.3》第 2.1 节）。

## 规则

- 参考资料编号从"参考资料-0001"开始，按类别独立计数，不作废、不复用；
- 参考资料不是卡片，不占用知识卡编号体系；卡片正文引用格式：`（参考资料-0001）`；
- 条目字段见《字段映射表 V0.3》第 8 节（参考资料编号、作者、题名、出版信息、具体页码、资料类型、所支持的判断、关联卡片、登记日期）；
- 所有条目登记于《参考资料总索引.md》。

## 登记条件

- 只登记确实支撑过项目某项判断的资料（"所支持的判断"必须填写）；
- 出版信息尽量完整（出版机构、年份）；具体页码必须填写，否则不登记；
- 未经核实的书目信息可作为线索暂记，但必须标注"待复核"，不写入正式判断的依据。
