# 性命双修

## 一、概念定位

“性命双修”在现代道教和内丹叙述中非常常见，但它并不是一个可以脱离时代和文本、直接当作“道家修炼最后阶段”的万能标签。

旧版把它放在 `28-修行阶段/`。V3 现改为：

```text
concept.xingming_shuangxiu
```

也就是：**内丹理论中的性命关系概念**。

## 二、性与命

在内丹史中，“性”和“命”并不是简单对应：

```text
性 = 心理
命 = 身体
```

这样的现代二分。

相关文本往往把“性”与人的本性、心性、先天根源等问题联系起来，把“命”与个体生命禀赋、生命存在及炼养问题联系起来，但具体定义需要按作者和传统分别研究。

## 三、为什么不是统一阶段

不同内丹传统可能：

- 更强调性；
- 更强调命；
- 讨论先后次第；
- 主张二者不可分；
- 使用不同术语表达类似问题。

因此不能建立：

```text
筑基 → 精气神 → 性命双修
```

作为统一修炼路线。

更合适的是把“性命双修”作为连接文本、人物、内丹传统和相关概念的研究节点。

## 四、与《悟真篇》的关系

张伯端和《悟真篇》是宋代内丹史的重要节点，也成为后世南宗性命理论讨论的重要文本基础。

但本项目不把《悟真篇》压缩成一本只讲“性命双修”的书。具体判断仍需回到诗篇、序跋和后世注释层次。

## 五、与全真传统的关系

全真道在内丹史上与性命问题密切相关，但全真本身还包含宗教组织、戒律、伦理、仪式、诗文和教团生活。

后续若建立全真—性命关系，应使用具体早期全真文献，而不是因为现代常说“全真性命双修”就直接建立强关系。

## 六、研究边界

- 不把“性”直接等同现代心理学概念；
- 不把“命”直接等同现代生理系统；
- 不把南宗、北宗/全真的差异压成一条绝对公式；
- 不把性命理论自动转化为现实练习处方。
