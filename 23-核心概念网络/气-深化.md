# 气

## 一、概念定位

“气”是问道志中连接度最高的核心概念之一。它同时出现在先秦哲学、传统医学、养生实践和道教修炼体系中，但这些语境中的“气”不能直接合并成一个固定定义。

本节点的首要任务不是给“气”下一个统一结论，而是建立分层语义：

1. 天地与变化语境中的气；
2. 生命聚散语境中的气；
3. 传统医学理论中的气；
4. 导引、吐纳、服气等实践中的气；
5. 内丹体系中的气；
6. 现代研究对这些传统概念的解释边界。

## 二、历史与经典来源

### 1. 《道德经》

《道德经》第四十二章把“气”放在阴阳、和合与万物生成的语境中。这一层主要用于说明“气”与天地变化、生成秩序有关，不能直接用后世医学或内丹术语反向解释。

### 2. 《庄子》

《庄子·知北游》将“气”与人的生死、聚散联系起来，为后世生命论意义上的“气”提供了重要先秦文献背景。

### 3. 《黄帝内经》

《黄帝内经》进一步把“气”纳入人体、天地和生命运行的医学理论体系。这里的“气”具有更明确的身体和医学语境，必须和先秦哲学概念分层记录。

### 4. 《参同契》《悟真篇》

后世丹道与内丹传统使用“气”解释炼养过程，但具体概念需要结合精、神、阴阳、火候等术语共同分析。本节点暂时建立关联，不代替内丹专题中的细致考证。

## 三、不同语境中的含义

### 1. 宇宙与变化层

“气”可以用于描述天地之间的变化、生成与和合关系。这一层与阴阳等概念紧密相连。

### 2. 生命层

“气”也被用来解释生命的聚散、活动和状态变化。在这一层，“气”逐渐成为连接宇宙观与生命观的重要桥梁。

### 3. 医学层

传统医学进一步形成更加细分的气论。医学中的“气”应放在《黄帝内经》等医学文献体系中理解，而不能直接当作哲学概念的简单延伸。

### 4. 养生实践层

导引、吐纳、服气等传统会使用“行气”“调气”“养气”等表达。这些词属于实践传统内部的术语，需要结合具体方法、时期和文献分别解释。

### 5. 内丹层

内丹体系中的“气”通常与精、神以及性命、火候等概念共同出现。这里的“气”已经处于高度体系化的修炼语言中，不应与现代生理学中的气体或能量概念直接对应。

## 六、争议与辨析

### 1. “气”是不是空气

不能等同。呼吸和空气可以与部分吐纳、调息实践相关，但传统“气”的语义范围远大于空气。

### 2. “气”是不是现代物理学意义上的能量

本项目不采用这种直接等同。传统“气”首先属于古代哲学、医学和修炼语言。现代研究若提出类比，必须明确标为现代解释，不能冒充传统原义或科学定论。

### 3. 哲学、医学、内丹中的“气”是不是同一个概念

存在历史联系，但不能视为完全相同。后续图谱应通过 `scope` 字段标明关系适用语境。

### 4. 实践体验能否证明“气”的客观实体性

不能。个人体验属于经验记录层，不能单独作为证明某种客观实体存在的证据。

## 七、现代研究边界

现代研究可以讨论呼吸训练、身体感觉、自主神经活动、注意状态、传统医学思想史和宗教史等可观察问题。现代实验结果若与传统“气”概念发生联系，应作为解释模型或比较研究记录，而不能直接证明传统理论整体成立。
