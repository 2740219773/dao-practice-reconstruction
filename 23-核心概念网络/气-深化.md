# 气

> 既有详细概念卡：`04-概念卡/概念-0004-气.md`。本页用于新版知识图谱和结构化检索；迁移期间，涉及先秦文献的详细解释仍应回查旧概念卡及对应原文卡。

## 一、概念定位

“气”是问道志中连接度最高的核心概念之一。它同时出现在先秦哲学、传统医学、养生实践和道教修炼体系中，但这些语境中的“气”不能直接合并成一个固定定义。

本项目首先按语境拆分“气”：

1. 《道德经》中的专气、心与气关系；
2. 《庄子》心斋语境中的“听之以气”；
3. 《管子·内业》中的精气、心静气理等系统表达；
4. 秦汉以后医学体系中的气；
5. 导引、吐纳、服气等养生实践中的气；
6. 宋元以后内丹体系中的气；
7. 现代研究对传统气论的解释与比较。

## 二、历史与经典来源

### 1. 《道德经》

既有概念卡已把第十章“专气”与第五十五章“心使气”列为核心原文。这些材料显示，“气”在先秦老子文本中已经进入修养和生命状态讨论，但文本本身并没有给出后世意义上的完整行气或采气技术。

### 2. 《庄子》

《人间世》心斋段落中的“听之以气”把“气”放入认识和心性调整语境。其具体含义存在解释空间，因此不能直接把它转译成现代生理过程。

### 3. 《管子·内业》

《内业》是现有项目资料中非常重要的一组“气”论材料。既有原文卡包含“精气”“心静气理”“精也者，气之精者也”等表达，使“气”与生命生成、心性状态、身体状态建立更系统的关系。

### 4. 《黄帝内经》及后世医学

秦汉以后，传统医学进一步发展出更复杂的气论。本项目把这部分视为新的医学语境，不直接等同于老庄或《内业》的“气”。当前只建立关系，具体篇章仍需进入后续医学专题核对。

### 5. 丹道与内丹文献

《参同契》《悟真篇》等后世文献使“气”进入更加体系化的炼养术语网络。该部分应和精、神、阴阳、火候、性命等概念共同研究，不应把后世内丹含义读回先秦文本。

## 三、不同语境中的含义

### 1. 修养与生命状态

《道德经》的“专气”“心使气”提示“气”与人的身心状态、柔强关系有关，但其操作层含义必须谨慎处理。

### 2. 感知与心斋

《庄子》的“听之以气”位于心斋语境中，体现“气”与心、虚、感知之间的特殊关系。

### 3. 精气论

《管子·内业》把“气”发展为更加系统的宇宙与生命理论，并明确讨论“精”与“气”的层次关系。

### 4. 医学气论

《黄帝内经》等医学文献中的“气”服务于身体、脏腑、营卫、生命状态等理论，其术语系统需要独立研究。

### 5. 实践传统

导引、吐纳、服气等传统会使用“行气”“调气”“养气”等表达。只有在具体文献和方法节点中核对后，才能确定其准确含义。

### 6. 内丹气论

宋元以后内丹中的“气”常与精、神共同构成炼养体系。这里的“气”已经是高度体系化的修炼术语。

## 六、争议与辨析

### 1. 气是不是空气

不能等同。呼吸和空气只覆盖“气”语义的一小部分，先秦精气论、医学气论和内丹气论都远超“空气”这一现代日常含义。

### 2. 气是不是现代物理能量

本项目不采用直接等同。把“气”解释成能量、生物电、神经冲动或所谓能量场，都属于现代解释尝试，不是传统文本原义，也不能在缺乏证据时写成科学事实。

### 3. 不同传统的气能否合并

不能直接合并。老庄、《内业》、医家、服气、内丹之间既有历史联系，也有明显的理论与术语差异。新版图谱必须通过 `scope` 标记语境。

### 4. 主观“气感”能否证明传统气论

不能。主观体验属于经验观察层，只能记录体验本身，不能独立证明某种客观实体或完整传统理论。

## 七、现代研究边界

现代研究可以讨论呼吸、身体感觉、注意、自主神经活动、传统医学思想史、宗教史和身体文化等问题。若某项现代研究与传统“气”发生类比，只能在现代研究层明确标注对应强度，不能反向证明传统概念已经被现代科学完整验证。
