# 精气神

## 一、概念定位

“精、气、神”在后世内丹及相关生命论述中经常组合出现，是理解内丹身体观和炼化语言的重要入口。

旧版把“精气神”放在 `28-修行阶段/`，并排列成：

```text
筑基 → 精气神 → 性命双修
```

这种写法把“概念组合”误当成“阶段”。V3 现正式纠正为：

```text
concept.jingqishen
```

## 二、为什么不是阶段

“精、气、神”是三个概念及其关系的组合。内丹文献常讨论它们的炼化、归复和相互关系，但“精气神”三个字本身不是一个有明确开始和结束边界的单独步骤。

后世常见的：

```text
炼精化气
炼气化神
炼神还虚
```

属于内丹阶段化表达的一种重要典型，但不同传统的理论、术语、先后重点和解释方式仍有差异。

## 三、与“气”节点的关系

`concept.qi` 研究“气”在不同早期经典、医学、养生和内丹语境中的多义性。

`concept.jingqishen` 则研究：

- 精、气、神为何被组合；
- 三者在内丹中如何相互解释；
- 不同时期如何形成不同炼化模型。

因此二者相关，但不能合并。

## 四、与内丹的关系

精、气、神是内丹史中的高连接概念，但不能因此把所有出现“精”“气”“神”的早期材料都自动归为内丹。

需要区分：

- 早期生命论或医学语境中的精、气、神；
- 中古道教身体与神灵体系；
- 宋元以后成熟内丹中的三者炼化模式。

## 五、现代研究边界

本项目不把“精、气、神”直接一一翻译成现代生殖物质、氧气、神经活动等生理变量。

现代研究若比较具体身体指标，必须保持概念层级差异，不能用单个生理指标证明整个传统三元模型。
