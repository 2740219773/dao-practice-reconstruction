# 道（深化）

## 一、节点定位

“道”是中国传统思想体系中的核心概念之一，也是道家哲学和后世道教思想的重要基础节点。

在问道志知识体系中，道作为核心概念节点，连接：

- 经典体系
- 哲学思想
- 修行体系
- 后世宗教实践

## 二、经典关联

主要关联：

- 《道德经》
- 《庄子》

## 三、核心关系

道 → 无为

道 → 自然

道 → 虚静思想

道 → 修性体系

## 四、历史演变

先秦时期，道主要作为解释世界运行规律的重要哲学概念。

后世道教发展过程中，道进一步与修炼、宗教实践和生命观结合。

## 五、关联体系

- 修性体系
- 清静思想
- 内丹思想
- 身心实践

## 六、研究边界

本节点区分：

- 经典中的“道”
- 历史流派中的解释
- 现代研究中的哲学分析

不将不同语境简单等同。
