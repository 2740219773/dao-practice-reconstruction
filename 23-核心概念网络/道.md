# 道

## 一、节点定位

类型：概念节点

所属领域：道家思想体系

## 二、核心含义

“道”是道家思想中的核心概念，不同历史时期和文本中具有不同解释。

常见理解包括：

- 宇宙运行规律
- 万物生成依据
- 超越具体事物的根本原则
- 人与自然关系的基础

## 三、经典关联

主要关联：

- 《道德经》
- 《庄子》

## 四、体系关系

道连接：

道 → 无为 → 自然 → 清静

同时影响：

道 → 修行体系 → 性命实践

## 五、问道志关联

关联节点：

- 静
- 虚
- 气
- 无为
- 自然

## 六、研究边界

“道”属于哲学和思想体系概念，不对应单一现代科学对象，需要区分不同语境下的解释。
