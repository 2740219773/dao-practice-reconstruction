# 争议与开放问题

> 本栏目是知识库的正式组成部分：**每个争议至少保留两种解释，不提前合并**。以下为第一批开放问题的示例主题，正式争议卡按批次上线。

1. **"静"是否等于"无念"？**——《庄子·大宗师》"坐忘"涉及"离形去知"的解释历来有分歧：是忘的递进层次、深度安定状态，还是某种哲学境界？三种解释在原文卡中并列呈现，不强行归一。

2. **"气"是什么？**——字面义（呼吸、气息）、哲学义（万物本原）、身体经验义（练习中的感受）之间是什么关系？不同时代的文本是否在说同一个东西？

3. **"心斋"与"坐忘"是同一功夫的两面，还是两种不同的功夫？**——两者在《庄子》中分属《人间世》与《大宗师》，后世传承常将其合并讲解，合并的根据是什么？

4. **古籍中的呼吸与身体描述，能否直接理解为操作指导？**——如"绵绵若存"是描述状态还是给出方法？把描述读成指令，是常见的反向解释错误。

5. **当代传播材料对古籍的引用是否可靠？**——已入库的玄丹道阁系列声称引用《云笈七签》《性命圭旨》等 17 处古籍，出处与准确性正在逐条待查（见[当代传播观察](/contemporary/)）。

> 说明：以上为主题预告，正式争议卡将注明各方依据、证据等级与当前处理。
