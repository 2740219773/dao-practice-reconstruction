# 关于问道志

## 问道志是什么

问道志是一套**研究支撑学习与实践**的开放工作台。

它先把传统道家、道教相关材料做成有来源、有语境、有争议、可追溯、可修订的知识体系，再在这套证据和安全底座上，设计少量现代低风险基础实践、记录与复盘工具。

因此现在有两条入口：

- [我要学习](/question-map/)：从真实问题进入经典、概念、人物、传统、方法、争议与专题；
- [我要实践](/practice/)：从安全检查、调身、身体觉察、自然察息、注意返回等基础能力开始。

## 它不是什么

问道志不是：

- 宗派宣传站；
- 修炼效果承诺；
- 医疗或心理治疗服务；
- “古籍一句话直接改成练法”的教程站；
- 用现代科学术语包装传统说法的证明平台；
- AI 自动判断境界或经脉状态的系统。

## 核心立场

> **不急于相信，也不急于否定。**

- 不预设传统说法必然正确；
- 不把个人体验直接视为客观规律；
- 不因为“传统”而回避现代研究，也不因为“现代”而贬低传统；
- 不把现代相关研究反向写成“古代理论已被科学证实”；
- 所有结论保留回到原文、来源和继续修订的道路。

## 为什么知识层和实践层必须分开

知识层中的 `method.*` 节点研究静坐、导引、吐纳、服气、心斋、坐忘、内丹等历史方法。

实践层中的 `practice.*` 是问道志为现代场景设计的教学单元。

二者可以关联，但不等同。例如：

```text
自然察息 ≠ 吐纳 / 服气
注意返回基础 ≠ 《坐忘论》完整收心体系
短时基础安坐 ≠ 坐忘 / 内丹筑基
轻柔动静转换 ≠ 古代导引套路复原
```

第一批实践卡都强制标记 `historical_equivalence: false`。

## 内容从哪来

项目内容由多层材料共同组成：

- 原始经典与历史文献；
- 现代历史学、思想史、宗教史、文献学研究；
- 后世传统解释；
- 现代医学、心理、生理、运动等研究；
- 项目专题证据总账与争议审查；
- 个人实践记录；
- 问道志自己的现代教学设计。

这些层次不会混成一个“最终真理”。

## 当前工程结构

- `02-*` 至 `21-*`：研究证据、专题、问题、社区与审校；
- `23-*` 至 `32-*`：V3 结构化知识图谱；
- `33-实践体系/`：基础实践、记录复盘与安全分流；
- `website/`：公开网站；
- `data/`：V3 自动构建数据。

网站中的知识节点和实践详情都尽量由仓库源文件自动生成，避免长期维护两份正文。

## 安全原则

第一批只开放 S1 低风险现代教学单元。主动调息、闭气、胎息、强意守、长时间静坐、服气、内丹火候/周天、辟谷、丹药等中高风险内容不自动生成公开教程。

出现异常首先作为安全事件处理，不默认解释为“突破、排病、气冲”。完整说明见 [安全边界](/safety/)。

## AI在项目里的角色

AI可以：

- 辅助资料整理与检索；
- 比较不同来源；
- 做反方审查；
- 帮助总结实践记录与重复问题；
- 回链到证据与安全规则。

AI不能替代来源核对、专业诊断、安全评估或传统师承，也不能根据主观“气感”判断身体机制和修炼境界。

## 参与方式

- 阅读与查证：浏览本站；
- 提出修订：在 GitHub 仓库提交 issue 或 PR；
- 引用：尽量连同来源、限定范围和风险边界一起引用，而不是只截取结论。

## 一句话总结

问道志希望做的不是“告诉你玄学答案”，而是把一条复杂的求索过程做得更可靠：

**来源可查，关系可辨，边界可见，实践可停，体验可记，问题可复盘。**
