## 问道志是什么

问道志是一个开放的知识研究站，把高度抽象、依赖师承解释和个人悟性的传统道家修炼知识，转化为**有来源、有语境、有争议、可追溯、可修订**的现代知识体系。

**它不是：** 修炼教程、宗教站、百科全书、现代科学包装平台，也不提供占卜或即时答案。

**它是：** 一套将传统知识与证据结构结合的研究界面——从原文、解释、证据、争议与风险出发，记录一条可以追溯和修订的求索路径。

## 核心立场

> **不急于相信，也不急于否定。**

- 不预设任何传统说法必然正确；
- 不把个人体验直接视为客观规律；
- 不因为"传统"而回避现代研究，也不因为"现代"而贬低传统；
- 所有结论保留回到原文和继续修订的道路。

## 内容从哪来

本站内容源于项目仓库（Obsidian 知识库）中的知识卡：文献卡、原文卡、概念卡、主张卡、争议卡、现代研究卡、风险资料卡等。每张卡都经过**公开字段校验**，只展示"可公开草稿"与"正式公开"的内容；原件与修订历史完整保留在 GitHub。

- 知识卡原件：仓库根目录 `02-文献卡` 至 `17-医学观察资料卡`
- 网站源码与生成逻辑：仓库 `website/` 目录
- 修订记录：GitHub 提交历史

## 项目治理

- 内部治理记录（项目决策、AI 审校）不进入公开页面，只保留在仓库；
- 每次内容整理都经过发布状态与风险字段校验；
- 异常体验首先作为安全事件记录，不解释为"突破、排病、境界"。

## 参与方式

- 阅读与查证：直接浏览本站各页；
- 提出修订：在 GitHub 仓库提交 issue 或 PR；
- 引用本站内容：请注明出处与修订时间，并保留风险与边界提示。

## 版权与引用

本站内容以项目仓库为源，引用请遵循仓库开源协议；涉及传统文献的原文引用均注明版本与核对状态。引用本站结论时，请同时引用其证据来源与结论编号（如 TOPIC-001-C02），不要只引结论不引边界。
