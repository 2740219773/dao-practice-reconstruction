# 项目说明

> 本站处于第一版骨架阶段：多数页面为入口与说明，具体卡片内容按批次上线。

## 这是什么

**项目名称：** 传统道家修炼知识重构与实践研究计划（简称"道修重构计划"，Daoist Practice Reconstruction Project，DPRP）。**本站（问道志）** 是该项目的研究工作台公开预览版。

把传统道家修炼中高度抽象、依赖师承解释和个人悟性的内容，转化为具有**来源、语境、结构、争议、证据和修订记录**的现代知识体系。项目以道家经典、历代文献、现代研究资料和现实讨论为基础，通过资料整理、概念拆解、来源考证、主题关联与知识重构，逐步建立一个能够持续积累、相互验证和不断完善的道学知识体系。

项目并不只是收集文章、书籍或修炼方法，也不试图简单地把传统内容转化为零散的"知识点"。项目更关注以下问题：

- 一个概念最早来自哪里，后来经历了怎样的演变；
- 不同经典、流派和历史时期对同一问题有何异同；
- 理论、方法、经验和民间说法应当如何区分；
- 修习内容中的前提、步骤、风险和适用范围是什么；
- 如何利用现代知识管理与人工智能工具，提高整理、检索、比较和研究效率。

本项目不是宗教组织、医疗机构、修炼培训机构或商业课程；不预设任何传统说法必然正确，也不把个人体验直接视为客观规律。

## 项目目标

项目希望逐步完成四个层面的建设：

1. **资料整理**：系统收集和整理道家经典、注疏、研究资料、修习文献、历史人物、流派传承及现代讨论，为后续研究建立稳定的资料基础；
2. **知识重构**：将分散在不同文献和语境中的内容，整理为概念卡、人物卡、经典卡、方法卡、流派卡、问题卡和专题研究等结构化内容；
3. **关系建立**：梳理概念之间、经典之间、人物与流派之间，以及理论与实践之间的关联，逐步形成可以交叉检索和相互印证的知识网络；
4. **智能辅助**：探索人工智能在资料分类、内容提取、观点比较、来源追踪、知识关联和专题研究中的应用，并尝试构建面向道学研究的多智能体协作体系。

## 基本原则

- **尊重原始资料**：尽可能保留原文出处、时代背景和完整语境，避免脱离原文进行过度概括；
- **区分不同层次**：明确区分经典原文、历代注解、现代研究、个人经验、民间说法和项目推论，避免将不同性质的内容混为一谈；
- **保持来源可追溯**：重要观点应尽量标明出处、版本和资料来源，使内容能够被重新查找、核对和修正；
- **不急于得出结论**：面对流派差异、历史争议和修习经验，优先呈现证据、背景和不同观点，而不是追求简单统一的答案；
- **持续修订**：项目中的内容不是固定结论。随着新资料、新研究和新认识的加入，已有内容会不断补充、修正和重构。

## 项目定位

本项目首先是一个开放的学习与研究项目，而不是宗派宣传、修炼承诺或权威结论的发布平台。

项目希望在传统文献与现代工具之间建立一座桥梁：既尊重传统内容本身，也使用现代知识工程的方法，使复杂、分散且容易混淆的道学资料变得更加清晰、可靠和便于研究。

## 项目愿景

长期来看，项目希望形成一套具备以下特征的道学知识体系：

> 内容有来源；观点有层次；概念有联系；争议有记录；方法有边界；资料可检索；研究可延续；系统可持续演化。

这不是一项追求快速完成的工作，而是一份持续整理、持续求证、持续反思的长期记录。**问道无终，所志者，非一时之得，而是求索之迹。**

## 第一阶段做什么

第一阶段主线是一个问题：

> 静、虚、心、气、息、身之间是什么关系？

围绕六部核心文献展开：**《道德经》《庄子》《管子·内业》《黄帝内经·素问》《坐忘论》《太上老君内观经》**。

工作方式：文献 → 原文 → 概念 → 不同解释 → 主张与争议 → 现代研究 → 风险判断 → 专题结论 → 反方审查。每张知识卡记录来源、核对状态、解释层级与修改记录，所有判断可追溯、可修订。

## 第一版不做什么

第一版是研究工作台的公开预览版，以下功能与内容**明确不做**：注册登录、评论区、修炼打卡、练习计时器、境界测试、AI 问答、个性化练习推荐、体感上传、排行榜、今日功法、宣传筑基入门、未核对卡片的自动批量公开。

一句话：网站服务于研究，不反过来拖着项目追求页面数量和视觉效果。

## 公开原则

仓库是源头，网站是展示层。每张卡片带"网站发布状态"字段（不公开／内部预览／可公开草稿／正式公开／已撤回），网站只展示"可公开草稿"与"正式公开"的内容；存量内容在未完成选择与核对前，一律以"整理中"呈现，不批量公开。

## 安全边界（摘要）

第一阶段以知识整理为主，只开放 S0 和少量不干预人体的 S1 内容。强制呼吸、闭气、胎息、辟谷、丹药、意守敏感部位等中高风险内容只建立研究索引，不转化为公众操作教程。出现异常首先作为安全事件记录，不解释为"突破""排病"。

详见[安全边界](/safety/)。
