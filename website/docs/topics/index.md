# "静"专题

> 第一阶段主线围绕一个问题展开：**静、虚、心、气、息、身之间是什么关系？**"静"是第一个展开的专题。

本文以现有已核对材料为限，回答五个问题："静"有哪些不同用法、哪些有原文直接支持、哪些属于项目归纳、哪些是现代解释候选、哪些常见说法没有充分依据。本专题内容均不构成练习指导；涉及身体的内容按[安全边界](/safety/)处理。

## 一、"静"在现有文献中有哪些不同用法？

"静"不是单一含义的词。在已建立原文卡的文献中，它至少承担以下几类用法：

- **状态义**：《道德经》第十六章"归根曰静，是谓复命"——静是万物回归本根的状态（[原文-0001](/originals/原文-0001-道德经第十六章)）；
- **过程义**：同章"致虚极，守静笃"——"致""守"是主动保持的动作（[原文-0001](/originals/原文-0001-道德经第十六章)）；
- **与"躁"对举**："静为躁君""静胜躁"——以静制动的原则（对应原文卡待建立）；
- **心静气理**：《管子·内业》"心静气理，道乃可止"——心与气的关联；
- **以"忘"承担**：《庄子》以"心斋""坐忘"作整体性表述，不把"静"当作核心术语（[原文-0005](/originals/)）；
- **体系化环节**：《坐忘论》把静坐实践体系化，"泰定"等承担安定阶段（[原文-0018](/originals/)）。

一句话概括：传统文献中的"静"更接近"少扰动"，既是要做的事（守静），也是达到的状态（归根曰静）。

## 二、哪些是原文直接支持？

- "静"兼有过程义与结果义——第十六章"守静笃"与"归根曰静"并见；
- "静"与"虚"并提——"致虚极，守静笃"；
- "静"与"复命""常""明"相连——"归根曰静，是谓复命。复命曰常，知常曰明"；
- 心静与气理相连——《管子·内业》"心静气理"；
- 对"灭念式收心"的明确批评——《坐忘论》"心起皆灭，永断知觉，入于盲定"为四种偏差之一，主张"息乱而不灭照"。

以上均为原文直接文字，可追溯至对应原文卡。

## 三、哪些属于项目归纳？

以下内容是项目的整理工具，不代表古人使用过同样的分类：

- **八义拆分**：外部安静、情绪不扰、欲望减少、注意稳定、思维减弱、身体安定、修炼过程、修炼结果——其中过程义与结果义有直接原文支持，其余为语境候选；
- **"虚—静"各有侧重**：虚侧重清除（不执），静侧重安定（不躁）——项目暂取之说，待"虚"概念卡核对；
- **"注意稳定"对应**：把"守静笃"之"守"理解为注意的保持，属现代术语的对应候选，暂不建立正式对应（M0）；
- **第十章两读法的影响**：若"能无知乎"读法成立，可与"涤除玄览"呼应，强化"虚—静"关联——此读法来自另一王弼本传本与帛书系统，与通行本"能无为乎"并列，不判定优劣。

## 四、哪些是现代解释候选？

- **注意方向**：短时正念训练研究显示觉察类训练与注意表现相关（现代研究-0001，编号见[概念卡"静"](/concepts/)关联现代研究），但荟萃分析显示效应量小、不优于主动对照，注意域不显著（现代研究-0006/0007）——因此"守"与"注意稳定"的对应暂不建立；
- **身体感觉方向**：以内感受任务分数推论身体觉察变化需谨慎——心跳计数任务与客观辨别仅弱相关、可被时间估计等非内感受过程驱动（现代研究-0008/0009）；
- **风险面**：冥想相关不良体验确实存在，但发生率高度依赖定义与研究设计（同一批样本因定义不同可从 6% 到 83%；实验研究 3.7% vs 观察研究 33.2%）——任何单一发生率数字都不可脱离定义引用（现代研究-0004/0005/0014/0015）。

## 五、哪些常见说法目前没有充分依据？

- **"静＝脑子里没有念头"**：已建文献（道德经、庄子、内业、坐忘论）没有任何一处以消灭念头定义"静"；《坐忘论》明确批评"永断知觉，入于盲定"；
- **"静坐是静的必然形式"**：原文未规定任何姿势，坐卧站皆可；
- **"静＝α 脑波/副交感神经兴奋"**：未经确认的现代对应，不作结论；
- **"归根＝具体身体操作"**：第十六章语境以万物为对象（"万物并作，吾以观复"），不解释为具体身体回归；
- **"静坐能提升认知（已被科学证明）"**：现有荟萃显示认知效应量小且不优于主动对照；
- **"静坐必然带来异常体验"**：发生率随定义与研究设计变化约 9 倍，不能一概而论。
