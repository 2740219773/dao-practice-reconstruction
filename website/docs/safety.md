# 安全边界

> 阅读本站任何内容前，请先阅读本页。本站是研究工作台预览，**不提供任何练习指导**。

## 基本立场

第一阶段以知识整理为主，不面向公众提供修炼操作教程。项目不预设任何传统说法必然正确；涉及身体的内容一律按风险等级管理。

## 风险等级

| 等级 | 含义 | 第一阶段处理 |
| ---- | ---- | ---- |
| S0 | 无已知风险 | 可整理、可展示 |
| S1 | 低风险（少量不干预人体的内容） | 少量开放，注明注意事项 |
| S2 | 中风险（如主动呼吸控制） | 只建立研究索引，不转化为公众操作教程 |
| S3 | 高风险（如强制闭气、胎息、辟谷、丹药、意守敏感部位） | 只建立研究索引，不转化为公众操作教程 |
| S4 | 极高风险 | 只记录存在与来源，不展开 |

## 实践内容处理原则

- 中高风险内容**只建立研究索引**，不转化为公众操作教程；
- 当代传播材料（视频、网文、网课）中的具体练习方法**不得直接采用**，必须单独进行风险审查；
- 古籍中的呼吸、意守、身体动作描述，先作为文本整理，不视为操作指导；
- 效果承诺（如"七天丹田温热"）必须建立主张卡记录，不作为事实传播。

## 异常处理

任何人在练习相关传统内容时出现异常，首先作为**安全事件**记录和处理，不解释为"突破""排病""气冲病灶"等说法；本项目不提供替代医疗建议，身体问题请咨询专业医务人员。
