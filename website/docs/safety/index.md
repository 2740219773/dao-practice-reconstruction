# 安全边界页（方案 8.7）：四级边界，不隐藏在页尾
---

> 阅读本站任何内容前，请先了解本页。本站提供清晰的**四级边界**，并链接到相关风险资料。

## 第一级：知识研究

本站绝大部分内容属于**纯知识研究**：典籍原文整理、概念辨析、文献对照、现代研究综述。

- 这一级内容可放心阅读，但仍请注意：文本结论不等于操作建议；
- 示例：`「静」专题`的六张核心原文与概念整理，均属于本级别；
- 本级别内容不组织、不推荐任何身体实践。

## 第二级：一般练习信息

少数内容包含**一般练习信息**（如动作概述、传统功法说明），仅作文献研究，不视为操作指导。

- 阅读时请确认：该内容标注为「文献研究」而非「教程」；
- 中高风险内容（如主动呼吸控制、意守、静坐姿势）只建立研究索引，不转化为公众操作教程；
- 效果承诺（如"七天丹田温热"）一律建立主张卡记录，不作为事实传播。

## 第三级：需要专业意见

涉及身体、心理或健康的内容，**需要专业意见**时请务必咨询医生或合格专业人员。

- 本站不提供替代医疗建议、心理治疗建议或修炼操作指导；
- 出现持续失眠、明显恐慌、现实感减弱等异常时，请停止相关实践并寻求专业评估；
- 相关风险资料见知识索引中「风险」类型条目。

## 第四级：应立即停止并求助

以下情况**立即停止**并寻求紧急帮助，不要独自处理：

| 表现 | 处理 |
| ---- | ---- |
| 晕厥、抽搐、严重胸痛、意识不清 | 立即停止，联系紧急医疗服务 |
| 自伤或伤人想法 | 立即停止，联系紧急医疗服务，不独自处理 |
| 持续恶化且无法自行停止的异常体验 | 停止相关实践，暂停项目活动，建议专业评估 |

## 风险等级表

| 等级 | 含义 | 本站处理 |
| ---- | ---- | ---- |
| S0 | 无已知风险 | 可整理、可展示 |
| S1 | 低风险（少量不干预人体的内容） | 少量开放，注明注意事项 |
| S2 | 中风险（如主动呼吸控制） | 只建立研究索引，不转化为公众操作教程 |
| S3 | 高风险（如强制闭气、胎息、辟谷、丹药、意守敏感部位） | 只建立研究索引，不转化为公众操作教程 |
| S4 | 极高风险 | 只记录存在与来源，不展开 |

## 异常体验的处理原则

任何人在练习相关传统内容时出现异常，首先作为**安全事件**记录和处理，不解释为"突破""排病""气冲病灶"等说法；本项目不提供远程诊断，身体问题请咨询专业医务人员。

## 免责声明
