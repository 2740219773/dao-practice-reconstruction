# 研究方法页（方案 8.6）：解释项目如何形成判断
---

> 本站的研究方法有两个关键词：**分层**与**标注**。任何一句话，都标明它属于哪一层知识、依据什么证据、可能推出多远。

## 为什么区分原文与解释

项目把知识分为七层，**不混合、不越层解释**：

| 层级 | 内容 | 说明 |
| ---- | ---- | ---- |
| L1 | 原始文献 | 先秦至唐宋典籍原文，如《道德经》《庄子》《坐忘论》 |
| L2 | 历代注释 | 文字训诂、文献解释、义理注疏（按资料性质归层，不以作者年代划分） |
| L3 | 近现代传承与实践解释 | 师承讲解、实践经验、修炼方法、当代重构 |
| L4 | 现代学术研究 | 学术论文、专著中的研究结论 |
| L5 | 项目解释 | 本项目对前述材料的整理与说明 |
| L6 | 项目假说 | 未经证实的研究设想，明确标注为假说 |
| L7 | 个人实践记录 | 只作记录，不视为客观规律 |

**为什么必须区分：** 同一句话可能是原文直接支持、后世注释、现代研究或项目自己的归纳。读者需要知道"这句话的底气来自哪里"，才能判断该信多少。原文页、概念页都会明确标注每一层。

## 证据等级如何判定

每条内容按七个维度标注：

| 标注 | 维度 | 说明 |
| ---- | ---- | ---- |
| T1—T5 | 文献可靠 | 底本可靠程度（T1 最可靠） |
| I1—I5 | 解释层级 | 从最接近字面的直译（I1）到最远的推论（I5），记录**最低**与**最高**两个值，不用单一等级掩盖跨度 |
| E1—E5 | 现代证据 | 现代研究的证据强度 |
| M0—M4 | 对应强度 | 传统说法与现代研究结论的对应程度 |
| R0—R5 | 实践重复 | 实践记录中的重复程度 |
| C0—C4 | 反证状态 | 是否存在反证 |
| S0—S4 | 风险等级 | 内容的风险程度（S0 最低） |

**判定原则：** 能回到原文的归原文，能查证的归文献，其余一律降级为"项目归纳"或"假说"。证据等级不因表述自信而提高。

## 现代研究如何使用

- 现代研究是**对照物**，不是传统说法的证明，也不是否定证据；
- 传统概念与现代概念（正念、冥想、脑波、放松训练）的对应，一律标注对应强度（M0—M4），不默认等同；
- 现代研究卡的结论表达等级与全文核对状态必须公开，避免"某研究证明……"式的过度转述；
- 本项目不把任何健康或修炼效果承诺当作事实传播。

## 反方材料如何处理

- 每个争议至少保留两种解释，不提前合并；
- 争议卡是知识库的正式组成部分，开放问题与已解决判断并列呈现；
- 已被证据否定的说法（如"静＝无念"）仍保留主张卡，标注"当前不支持"，供读者对照；
- 不因立场而隐藏不利材料。

## 何时不能形成结论

以下情况，项目明确标注"暂时不能确认"，不强行下结论：

- 原文未给步骤、版本未实物复核、页码未核对；
- 现代研究证据不足、样本局限或结论表达等级低；
- 传统说法与现代概念仅存在"语境类似"而无直接对应；
- 跨流派（佛教、内丹等）术语未独立研究。

## 发布前如何审查风险

- 每个公开页必须显示：风险等级（S0—S4）、内容类型、是否包含操作、是否经安全审核；
- 中高风险内容只建立研究索引，不转化为公众操作教程；
- 发布状态分五档（不公开 / 内部预览 / 可公开草稿 / 正式公开 / 已撤回），本站只展示后两档，可公开草稿带标识；
- 异常体验首先作为安全事件记录，不解释为"突破、排病、境界"。

## 审核状态与发布状态

每张卡片有两个互相独立的"状态"：

**审核状态**（表达内容质量）：草稿 → 待核对 → 来源已核对 → 待解释审核 → 待综合审核 → 已审核 → 需要修订／不予采用／已归档。"已审核"只表示符合当前版本标准，不代表永久正确。

**网站发布状态**（表达是否对外展示）：不公开、内部预览、可公开草稿、正式公开、已撤回。

## AI 与研究者的关系

AI 是研究助手，不是最终裁判。AI 输出一律待人工核对；所有判断以人工核对后的卡片为准。
