## 目前能确认与不能确认

以「静」为例，展示本项目的结论边界——区分有原文直接支持的内容与整理归纳的内容：

<div class="wd-twocol">

<div class="wd-card">

**能确认（有原文直接支持）**

- 《道德经》中「静」与「虚」「归根」「复命」直接相连（第十六章）；
- 「守静」是《道德经》明确使用的表达（第十六章「守静笃」）；
- 先秦道家文本中「静」同时承担状态描述与方法描述两类含义。

</div>

<div class="wd-card">

**不能确认（不当作结论）**

- 不能把「致虚极，守静笃」直接翻译成现代冥想达到某个境界；
- 不能把「静」定义为「脑子里没有念头」；
- 不能把后世内丹术语读回《道德经》原文。

</div>

## 关于本计划

本项目不是宗教组织、医疗机构、修炼培训机构或商业课程；不预设任何传统说法必然正确，也不把个人体验直接视为客观规律。所有内容多维证据标注（文献来源 / 解释层级 / 现代研究 / 反证 / 风险），AI 只担任研究助手，最终判断由人工核对完成。
