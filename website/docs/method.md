# 研究方法

> 本站的研究方法有两个关键词：**分层**与**标注**。任何一句话，都标明它属于哪一层知识、依据什么证据、可能推出多远。

## 知识七层分层

项目把知识分为七层，**不混合、不越层解释**：

| 层级 | 内容 | 说明 |
| ---- | ---- | ---- |
| L1 | 原始文献 | 先秦至唐宋典籍原文，如《道德经》《庄子》《坐忘论》 |
| L2 | 历代注释 | 文字训诂、文献解释、义理注疏（按资料性质归层，不以作者年代划分） |
| L3 | 近现代传承与实践解释 | 师承讲解、实践经验、修炼方法、当代重构 |
| L4 | 现代学术研究 | 学术论文、专著中的研究结论 |
| L5 | 项目解释 | 本项目对前述材料的整理与说明 |
| L6 | 项目假说 | 未经证实的研究设想，明确标注为假说 |
| L7 | 个人实践记录 | 只作记录，不视为客观规律 |

L2 与 L3 的边界以**资料性质**划分：文字训诂、注疏类内容归 L2，师承讲解、实践方法类内容归 L3——当代人写的纯训诂作品仍属 L2，古人留下的传承讲解仍属 L3；同一部文献可能两类内容都有，按段落分别归层。

## 多维证据标注

每条内容按七个维度标注：

| 标注 | 维度 | 说明 |
| ---- | ---- | ---- |
| T1—T5 | 文献可靠 | 底本可靠程度（T1 最可靠） |
| I1—I5 | 解释层级 | 从最接近字面的直译（I1）到最远的推论（I5），每张卡记录**最低**与**最高**两个值，不用单一等级掩盖跨度 |
| E1—E5 | 现代证据 | 现代研究的证据强度 |
| M0—M4 | 对应强度 | 传统说法与现代研究结论的对应程度 |
| R0—R5 | 实践重复 | 实践记录中的重复程度 |
| C0—C4 | 反证状态 | 是否存在反证 |
| S0—S4 | 风险等级 | 内容的风险程度（S0 最低） |

## 卡片状态与公开状态

每张卡片有两个互相独立的"状态"：

**审核状态**（9 个，表达内容质量）：草稿 → 待核对 → 来源已核对 → 待解释审核 → 待综合审核 → 已审核 → 需要修订／不予采用／已归档。"已审核"只表示符合当前版本标准，不代表永久正确。

**网站发布状态**（5 个，表达是否对外展示）：不公开、内部预览、可公开草稿、正式公开、已撤回。本站只展示"可公开草稿"与"正式公开"的内容；"可公开草稿"页面带草稿标识。

## 争议处理

每个争议至少保留两种解释，不提前合并；争议卡是知识库的正式组成部分，开放问题与已解决判断并列呈现。

## AI 与研究者的关系

AI 是研究助手，不是最终裁判。AI 输出一律待人工核对；所有判断以人工核对后的卡片为准。
