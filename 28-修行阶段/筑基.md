# 筑基

## 一、阶段定位

“筑基”可以进入 V3 的 `stage` 类型，但必须带着明确范围：

**它是部分后世内丹体系中的阶段化概念，不是所有道家修炼共同的第一步。**

旧节点只有一句：

```text
内丹 → 筑基 → 精气神调整 → 后续阶段
```

这会制造两个错误：

1. 把“精气神”误当成独立阶段；
2. 把某些内丹体系的次第扩大成普遍道家路线。

新版撤销这种无范围的线性链。

## 二、可确认的内丹语境

王沐对内丹的系统整理把相关实践划分为四个阶段，其中第一项为“筑基”，随后才是炼精化气、炼气化神、炼神还虚。

这一模型主要依据《悟真篇》体系并综合其他内丹材料，因此它适合作为理解一类后世内丹次第的研究入口。

但这里必须区分：

```text
后世学者/修炼者对内丹的阶段化整理
```

与：

```text
所有历史内丹文本都逐字采用同一套四阶段目录
```

后者并不成立。

## 三、与《悟真篇》的关系

本节点与《悟真篇》只建立 `related_to`，并在关系范围中明确：

- 王沐的整理以《悟真篇》体系为重要基础；
- 这是后世解释和体系化模型；
- 不把现代整理出的阶段标题无条件反投射为张伯端原文的固定目录。

因此不建立：

```text
《悟真篇》 source_of 筑基
```

这样的强来源边，除非后续找到并核对具体原文。

## 四、与精气神的关系

“精气神”已经迁移为 `concept.jingqishen`，不再处于筑基之后作为一个阶段。

在某些内丹模型中，筑基会涉及精、气、神的基础状态和准备，但这只是：

```text
阶段中的相关概念
```

不是：

```text
筑基完成 → 进入“精气神阶段”
```

## 五、与性命双修的关系

“性命双修”已经迁移为理论概念 `concept.xingming_shuangxiu`，同样不再作为筑基之后的固定阶段。

不同内丹传统对性、命和修炼次第的组织并不完全相同，因此本节点暂不建立“筑基→性命双修”的步骤关系。

## 六、安全边界

本节点用于历史与理论研究，不把后世“筑基”说明直接转写为现实操作处方。

尤其不据此提供：

- 极端闭气或强制呼吸；
- 长时间禁食、辟谷；
- 以异常感觉作为阶段完成标准；
- 以修炼替代医学诊疗的建议。

具体实践材料若未来进入项目，必须单独经过来源、风险和适用范围审查。

- `concept.xingming_shuangxiu`：性命双修（理论原则，不是下一阶段）
