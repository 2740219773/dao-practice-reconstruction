# 18-问题地图

本目录存放"问题卡"（编号前缀"问题-"，问题-0001 起）：面向初学者的入口节点，记录真实用户从具体问题出发的疑问。

## 规则

- 每个问题不写成孤立文章，而是作为**入口节点**，连接到相关概念卡、原文卡、争议卡、辨析卡与修持相关内容；
- **卡片平铺存放**：所有问题卡直接放在 18-问题地图/ 下（与读取程序 `dir/*.md` 一致），用 YAML「问题分类」字段分类：
  - 入门认知／经典阅读／概念理解／修持实践／历史宗派／现实应用／资料辨伪
- 模板见 01-知识卡模板/问题卡模板.md；
- **问题卡不填写「来源可信等级」**：问题本身无"可信不可信"，有可信度的是答案与关联证据——改填「文本判断依据等级／风险判断依据等级／综合答案依据等级」三字段与「答案依据」（见问题卡模板；体系变更见决策-0007）；
- 问题卡是用户入口层（《项目结构总图》），不作为原始证据，不计入正式知识卡统计；
- 问题来自社区观察时，只转化"问题与需求"，不转化社区结论为权威答案。
