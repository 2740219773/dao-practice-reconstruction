# 18-问题地图

本目录存放"问题卡"（编号前缀"问题-"，问题-0001 起）：面向初学者的入口节点，记录真实用户从具体问题出发的疑问。

## 规则

- 每个问题不写成孤立文章，而是作为**入口节点**，连接到相关概念卡、原文卡、争议卡、辨析卡与修持相关内容；
- 问题按类别分子目录：01-入门认知、02-经典阅读、03-概念理解、04-修持实践、05-历史宗派、06-现实应用、07-资料辨伪；
- 模板见 01-知识卡模板/问题卡模板.md；
- 每条问题卡必须标注「来源可信等级」（甲乙丙丁/待考/禁用，见 00-项目规范/来源可信等级规范.md）；
- 问题来自社区观察时，只转化"问题与需求"，不转化社区结论为权威答案。
