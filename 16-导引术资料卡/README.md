# 16-导引术资料卡

本目录存放"导引术资料卡"（编号前缀"导引术-"，导引术-0001 起），登记完整的身体训练系统（如八段锦、五禽戏等）。

## 规则

- 编号前缀"导引术-"（导引术-0001 起），按《基础规范》第 2.1 节；
- 模板见 01-知识卡模板/导引术资料卡模板.md；
- 导引术模块（DAOYIN-001 八段锦、DAOYIN-002 五禽戏等）是独立研究主线，与概念专题（TOPIC-001 静）平级；
- 导引术资料卡不负责定义"静""气""心"等概念的完整理论；涉及概念处只建立关联（如"八段锦使用了'松静'要求 → 关联概念：静"）；
- 历史功法 ≠ 现代标准化功法 ≠ 临床研究中的干预方案，三者必须持续区分核对；
- 具体动作与呼吸意念要求属中低风险内容，仍按安全边界逐段审查；不转化为无监督操作指导。
