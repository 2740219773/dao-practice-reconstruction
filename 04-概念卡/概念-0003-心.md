# 心

## 1. 概念说明

“心”是第一阶段“静、虚、心、气、息、身”主线中的第三个核心概念，但它比“静”“虚”更容易失控扩张。医学、儒家、佛教、理学、内丹和现代心理学都大量使用“心”或近似概念，如果不先冻结范围，很容易把一个专题变成“中国思想中的心”总论。

因此本卡只服从 `TOPIC-003` 的冻结范围：

- 《道德经》；
- 《庄子》；
- 《管子·内业》；
- 《坐忘论》。

专题结论的唯一权威来源是：

`11-专题研究/TOPIC-003-心/证据总账.md`

本卡只引用 `TOPIC-003-C01～C05`，不自行维护另一套完整结论。

当前最重要的原则不是先回答“古代的心究竟是什么”，而是先观察：**不同文本让“心”处在什么结构里、承担什么角色。**

---

## 2. 本专题不采用的总定义

旧稿曾把“心”概括为“思维、情绪、意志活动的承担者”，并进一步把“心性、心法、虚心”等并列为名称。这种写法范围过大，容易把后起概念和现代分类反向套回冻结文本。

本专题暂不采用以下覆盖性等式：

- 心＝心脏；
- 心＝大脑；
- 心＝意识；
- 心＝注意力；
- 心＝执行功能；
- 心＝灵魂；
- 心＝后世“心性”；
- 心＝后世“心法”。

这不是说上述概念之间绝无历史或解释关系，而是说**当前冻结材料不足以把其中任何一个当作统一翻译**（TOPIC-003-C05）。

## 3. 项目多角色分析框架

> 本节是 `TOPIC-003-C01` 的项目分析框架，不代表古人已经使用同样分类。

在当前7张核心原文中，“心”至少可以按以下角色整理：

| 角色 | 典型文本 | 当前可说到的程度 |
| ---- | ---- | ---- |
| 可被“虚”的对象 | 原文-0019“虚其心” | 可确认使动结构；首先受“圣人之治”语境限制 |
| 可呈“静/定/安”等状态 | 原文-0009、0010、0016 | 可确认不同文本分别出现“心静”“定心”“安心”；不预设同一技术 |
| 与情欲扰动相关的中心 | 原文-0008 | 忧乐喜怒欲利与“失心/安宁”关系明显；具体“刑/形”训释待核 |
| 与气发生关系的节点 | 原文-0004、0009、0005 | 有“使气”“气理”“听之以气”等不同关系，不能压成单向控制 |
| 心斋中的感知/止息环节 | 原文-0005 | “听之以心”“心止于符”属于心斋语境，不能直接翻成现代注意训练 |
| 后世明确的主位与修养对象 | 原文-0016 | 《坐忘论》明确称“一身之主”并谈“收心/虚心/安心”；只能代表唐代文本层 |

这些角色之间可以比较，但当前不合并成一个“心本质论”。

## 4. 《道德经》中的“心”

### 4.1 “虚其心”——原文-0019

“虚其心，实其腹”位于第三章“圣人之治”的排比结构中。

本专题可确认：

- “心”可以进入“虚其心”的使动结构；
- 它与TOPIC-002“虚”直接相连。

本专题不直接推出：

- 这是个人静坐操作；
- “虚其心”就是清空思维；
- “虚其心”与唐代《坐忘论》“虚心”完全同义。

因此“虚其心”和“虚心”必须历史分层处理（TOPIC-003-C02/C04）。

### 4.2 “心使气曰强”——原文-0004

第五十五章将“心使气”置于“强”的表述中，后续又接“物壮则老，谓之不道”。

王弼注释层进一步说“心宜无有，使气则强”。

因此当前最重要的用途不是把本句解释成“心能够控制气”的技术说明，而是反过来限制这种现代化读法：**文本至少没有把“使气”作为一个可以直接正面技术化的统一机制来讲**（TOPIC-003-C03）。

## 5. 《庄子·人间世》心斋中的“心”

原文-0005出现：

- “若一志”；
- “无听之以耳而听之以心”；
- “无听之以心而听之以气”；
- “心止于符”；
- “唯道集虚。虚者，心斋也”。

这里的“心”处在一组连续的感知、志向、虚与道的关系中。

当前可以说：

- “心”是心斋论述不可缺少的环节；
- 心斋不是单纯“心越用力越好”的结构，因为文本进一步从“听之以心”转向“听之以气”；
- “虚”与心斋直接相关。

当前不能直接说：

- “若一志”就是现代注意力集中；
- “听之以气”就是呼吸法；
- “心止于符”就是压制念头；
- 心斋与《内业》定心、《坐忘论》收心是同一方法。

这部分主要服务 `TOPIC-003-C03/C04`。

## 6. 《管子·内业》中的“心”

当前冻结三组核心材料：原文-0008、0009、0010。

### 6.1 “凡心之刑，自充自盈”——原文-0008

当前网络传本作“凡心之刑”。

本专题阶段1确认：

- 中国哲学书电子化计划与维基文库可见本均作“刑”；
- 明代刘绩《管子补注》明确注“刑，法也”，将其解释为“安心之法”；
- 现代研究中也存在将“刑”校读/解释为“形”，进而讨论“心之形”的路径。

因此本专题**不提前把“刑/形”拍板成唯一答案**。

当前最稳妥的做法是：

> 原文按当前核对传本保留“刑”；“刑=法”与“刑/形”两类解释进入阶段4研究核对；在底本、校注与研究材料未进一步收口前，不用此句证明“心有实体形状”或“古人已有固定心理结构学”。

### 6.2 “心静气理，道乃可止”——原文-0009

这一句直接连接心、静、气、道。

它可以支持：

- “心静”是明确文本结构；
- “心”与“气”存在关系；
- “静”专题与“心”专题需要互相引用。

但仅凭语序不能把它机械改写成：

> 心主动控制气 → 气按意念运行。

这条限制属于 `TOPIC-003-C03`。

### 6.3 “心以藏心，心之中又有心焉”——原文-0010

这是本专题最需要保留解释开放性的句子之一。

文本还出现：

- “定心在中”；
- “我心治，官乃治；我心安，官乃安”；
- “心以藏心，心之中又有心焉”；
- “心全于中，形全于外”。

现代研究对“心中之心”存在不同解释，例如：

- 区分官能层面的心与更根源的“本心”；
- 区分一般心与得道/精气作用后的更高层次之心；
- 从“心—官”“心—精气”关系理解，而不是建立两个解剖实体。

这些都属于**解释候选**，不是原文直接定义。

本卡暂不采用“《内业》明确提出两个心实体”的说法。

## 7. 《坐忘论》中的“心”

原文-0016属于唐代体系化文本，与先秦材料必须分层。

文本明确出现：

- “夫心者，一身之主，百神之师”；
- “收心离境”；
- “心不受外，名曰虚心”；
- “心不逐外，名曰安心”；
- “心安而虚，则道自来居”。

因此可以确认：

1. 《坐忘论》明确赋予“心”较强的主位表述；
2. “心”成为系统化修养论中的直接对象；
3. “收心、虚心、安心”在同一唐代文本中具有连续关系。

但不能反向推出：

- 《道德经》“虚其心”已经等同唐代“虚心”；
- 《庄子》心斋就是《坐忘论》收心的早期版本；
- 《内业》定心与《坐忘论》收心是一套固定传承程序。

这正是 `TOPIC-003-C04` 的历史分层要求。

## 8. 心与静、虚的关系

`TOPIC-003-C02` 当前只支持“逐文本关系”，不支持统一三段式模型。

| 关系 | 文本依据 | 当前处理 |
| ---- | ---- | ---- |
| 心—静 | 原文-0009“心静气理”；原文-0016静定语境 | 心可以呈“静”或进入静定关系，但“静”不是“心”的同义词 |
| 心—虚 | 原文-0019“虚其心”；原文-0005“唯道集虚”；原文-0016“虚心” | 关系密切但文本结构不同，不写成统一操作 |
| 静—虚—心 | 前三专题综合 | 只建立知识网络，不写“先虚后静/先静后虚”的固定流程 |

TOPIC-001与TOPIC-002已经冻结。本专题若发现新的关系限定，只建立关联或提出未来修订建议，不静默重开前两个专题。

## 9. 心与气的关系

> 对应 `TOPIC-003-C03`。

当前三组直接材料：

1. 《道德经》：“心使气曰强”；
2. 《内业》：“心静气理，道乃可止”；
3. 《庄子·心斋》：“无听之以心而听之以气”。

它们并不支持一个单一方向的“心控制气”模型。

因此本专题只采用：

> 在冻结文本中，“心”与“气”存在多种不同关系；其具体含义必须逐文本解释。

不采用：

- “以意领气”作为Q3答案；
- “气=呼吸”；
- “气=现代物理能量”；
- “意念可以操控某种能量流”的现代技术化解释。

“气”本身的概念定义移交TOPIC-004。

## 10. 心斋、定心、收心是不是同一方法

> 对应 `TOPIC-003-C04`。

当前不合并。

| 表述 | 文本 | 第一轮定位 |
| ---- | ---- | ---- |
| 虚其心 | 《道德经》3章 | 治民语境中的使动表达 |
| 若一志/心斋 | 《庄子·人间世》 | 心斋具体语境 |
| 定心/心以藏心 | 《管子·内业》 | 内业心—道—气结构 |
| 收心/虚心/安心 | 《坐忘论》 | 唐代系统化收心体系 |

可以研究相似性，但不得因为现代汉语都带“心”字，就默认它们是同一条操作链或同一传承步骤。

## 11. 现代对应边界

> 对应 `TOPIC-003-C05`。

传统“心”可以与现代认知科学、心理学或身体观念做比较，但比较必须在后续专门问题里明确对应维度。

本卡不直接写：

- “心就是大脑”；
- “心就是意识”；
- “心就是注意”；
- “心就是情绪系统”；
- “心就是执行控制”；
- “心就是心脏的神经网络”。

同样，也不把“古人说心”解释成“古人早已发现现代神经科学”。

## 12. 当前真实争议

阶段3以后优先保留三个解释问题：

1. **心—气关系：** 是否可以概括成控制关系？当前C03为“不支持简化模型”；
2. **不同“心”术语：** 心斋、定心、收心等是否可以合并？当前C04要求历史分层；
3. **《内业》“刑/形”及“心中之心”：** 属校勘与解释竞争，阶段4核对，不先做本体论结论。

是否建立独立争议卡由真实材料密度决定，不为模板凑数。

本专题属于A类纯知识研究。

最需要防止的是“解释 → 操作教程”的滑移，例如：

- 《黄帝内经》医学心脏/脏象体系；

- 佛教心识、心性、无心体系；
