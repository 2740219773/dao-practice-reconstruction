# “玄丹道阁筑基打坐系列”纳入项目实施方案 V0.1

## 一、资料的正式定位

建议将这套内容定义为：

> **当代网络修炼传播资料**

它不是以下任何一种资料：

* 不是古代原典；
* 不是历代权威注释；
* 不是经过同行评议的现代学术研究；
* 不是项目已经认可的实践协议；
* 不是可以直接验证传统理论的证据。

它在项目中的主要身份是：

1. 当代传统修炼传播样本；
2. 古籍引用追溯样本；
3. 实践方法风险分析样本；
4. 现代人如何重组传统修炼体系的案例；
5. 未来实践协议的候选素材来源。

项目当前章程已经要求区分原始文献、历代注释、现代研究、项目解释、项目假说和个人实践记录，因此这类视频不能直接混入现有原文卡或现代研究卡。

### `00-资料说明.md`

记录：

* 抖音账号名称；
* 账号主页；
* 系列名称；
* 发布者身份是否核实；
* 是否说明师承；
* 视频数量；
* 发布时间；
* 资料获取日期；
* 整理人员；
* 当前处理状态；
* 是否包含具体实践方法；
* 是否允许进入实践区。

当前建议状态：

```text
资料状态：已收录，待核对
实践状态：禁止直接采用
研究用途：传播研究、出处追溯、风险分析
```

### `01-原视频索引.md`

每条视频单独记录：

| 视频编号   | 标题 | 发布时间 | 原链接 | 时长 | 主要内容 | 当前状态 |
| ------ | -- | ---- | --- | -- | ---- | ---- |
| 视频-001 |    |      |     |    | 坐前准备 | 待核对  |
| 视频-002 |    |      |     |    | 坐前热身 | 待核对  |

视频后续被删除时，仍然能够知道资料原来来自哪里。

### `02-原始内容摘录.md`

这里只保存研究所必需的短句、关键时间点和必要上下文。

由于仓库是公开的，不建议直接上传：

* 完整视频文件；
* 完整音频；
* 大量视频截图；
* 未经许可的完整逐字稿。

完整逐字稿可以保存在本地私有目录，公开仓库只保留摘要、短引文、时间点和分析结果。

### `03-内容整理稿.md`

放入你现在整理出的结构化版本，但要在开头明确区分：

```text
原视频直接表达：
整理者归纳：
整理者增加的安全说明：
项目后续判断：
```

例如：

> “方向要求属于传统修炼观念，并非必要条件。”

需要说明这是视频原话，还是整理者增加的判断。两者不能混在一起。

# 三、把整套内容拆成六类

不能把整个视频系列作为一个整体判断“正确”或“错误”。

需要按照内容性质拆分。

## 第一类：普通环境和生活建议

例如：

* 环境安静；
* 避免冷风直吹；
* 不在酒后练习；
* 饭后不立即静坐；
* 手机静音；
* 初次时间不宜过长。

处理方式：

> 作为普通生活建议保留，但不使用“气机”“阴阳”证明其正确。

后续可以寻找睡眠、环境舒适度和注意干扰方面的现代资料。

## 第二类：姿势和运动准备

例如：

* 开胯；
* 脊柱活动；
* 不强压膝盖；
* 椅坐替代盘坐；
* 起身前活动腿脚；
* 膝痛立即调整。

处理方式：

> 进入身体动作与关节安全研究，不直接归入道家修炼理论。

可以关联：

* 运动医学；
* 康复训练；
* 髋关节活动度；
* 膝关节受力；
* 久坐与体位变化。

## 第三类：主动呼吸方法

例如：

* 吸气四秒；
* 停留两秒；
* 呼气六秒；
* 深、细、匀、长；
* 吸气提肛；
* 腹部主动起伏。

处理方式：

> 标为需要专业审核的主动身心干预。

不得直接进入初级练习方案。

应拆成独立变量：

1. 延长呼气；
2. 呼吸停顿；
3. 腹式呼吸；
4. 提肛；
5. 与注意结合。

不能把五个变量一起测试。

## 第四类：意守与观想

例如：

* 意守下丹田；
* 呼气时守丹田；
* 吸气时放松；
* 气沿脊柱上行；
* 气从百会下行；
* 浊气排出；
* 封固元气。

处理方式：

> 作为传统实践解释研究，暂不进入人体实践。

主要研究问题：

* 最早出处在哪里；
* 不同文献是否采用同一种方法；
* 这是视频作者的组合，还是已有完整传承；
* “意守”与普通身体注意有什么区别；
* 是否可能引起注意紧张或过度追求体感。

## 第五类：仪式和象征内容

例如：

* 面向东方；
* 避免西北方向；
* 红布聚阳；
* 舌抵上腭搭鹊桥；
* 玉液还丹；
* 收功口诀；
* 气归元海。

处理方式：

> 作为传统象征、仪式和修辞材料记录。

项目不急着证明或否定它，而要先区分：

* 是否有古籍出处；
* 是否为某个流派特有；
* 是否为近现代增补；
* 它主要承担心理、仪式还是技术作用。

## 第六类：效果和时间承诺

例如：

* 七天丹田温热；
* 十四天气感充盈；
* 练透后久坐不麻；
* 某个方向可以补养气血；
* 某种动作能够通脉。

处理方式：

> 必须建立主张卡，不得作为课程事实直接传播。

# 四、需要生成哪些正式知识卡

## 1. 主张卡

建议第一批建立：

```text
主张-0006：面向东方静坐比其他方向更有利
主张-0007：横梁下静坐会阻碍气机
主张-0008：舌抵上腭具有所谓搭鹊桥作用
主张-0009：四二六呼吸适合普通初学者
主张-0010：吸气配合提肛能够聚气
主张-0011：新手七天左右可能出现丹田温热
主张-0012：守下丹田是初级静坐的通用方法
主张-0013：任何调息和守窍后都必须进行收功
```

每张主张卡分别寻找：

* 视频中的原话；
* 声称的古籍来源；
* 实际古籍原文；
* 历代解释；
* 现代支持材料；
* 反对材料；
* 风险；
* 当前结论。

## 2. 风险资料卡

建议建立：

```text
风险资料-0001：固定节奏呼吸和短暂停顿的不适风险
风险资料-0002：吸气配合提肛造成呼吸紧张的风险
风险资料-0003：强行盘坐与压膝的关节风险
风险资料-0004：持续意守下腹引起注意紧张的可能性
风险资料-0005：追求丹田发热和气感造成自我暗示的问题
风险资料-0006：静坐后腿麻和突然起身的安全风险
```

## 3. 争议卡

建议建立：

```text
争议-0001：初级静坐应自然呼吸还是固定节奏调息
争议-0002：初级练习是否适合直接意守下丹田
争议-0003：收功是生理恢复过程还是传统仪式
争议-0004：坐前方向禁忌是实践条件还是文化象征
```

## 4. 现代研究卡

后续查找以下主题：

* 延长呼气对身体状态的影响；
* 屏息和呼吸停顿风险；
* 腹式呼吸的适用条件；
* 髋关节柔韧性与盘坐膝痛；
* 冥想中的身体内部感觉；
* 注意身体部位对体感的影响；
* 静坐后体位性头晕；
* 冥想和呼吸练习的不良反应。

现代研究卡目前已有模板，但该模板明确要求现代研究只能帮助解释和检验假说，不能给传统说法提供“科学包装”。

## 5. 原文卡

对于视频声称引用的传统内容，应回到原始文献建立原文卡，例如：

* 《云笈七签》中的坐法和时辰；
* 《坐忘论》中的收心、静定；
* 《童蒙止观》中的调身、调息、调心；
* 《黄庭经》中的相关身体术语；
* 《性命圭旨》中的丹田、周天和收功；
* 《金丹四百字》相关段落；
* 《太乙金华宗旨》相关内容。

必须先确认原文确实存在，再判断视频有没有改变它的语境。

# 六、这部分内容在各阶段的作用

## 第一阶段：作为研究对象

当前阶段主要作用：

* 测试当代传播资料的处理流程；
* 训练古籍出处追溯；
* 测试主张卡和风险卡；
* 发现传统理论被现代重组的方式；
* 完善项目的资料分类。

当前不做实践验证。

## 第二阶段：作为历史传承比较材料

以后可以将它与以下材料比较：

* 《坐忘论》；
* 《童蒙止观》；
* 《性命圭旨》；
* 《太乙金华宗旨》；
* 《炁体源流》；
* 近现代静坐、气功和内丹著作。

研究它从哪些传统中取材，又加入了哪些现代内容。

## 第三阶段：作为实践协议候选素材

进入实践协议设计后，可以从中提取候选组件，例如：

* 环境减少干扰；
* 不强压膝盖；
* 椅坐替代盘坐；
* 练习后缓慢恢复活动。

但每个组件必须单独审查。

不能直接把整套流程整体采用。

## 第四阶段：只验证拆分后的单项

以后具备专业条件时，也只能分别研究：

* 热身是否减少不适；
* 椅坐与散盘的差异；
* 自然呼吸与固定节奏呼吸的差异；
* 是否意守下腹的差异；
* 是否进行恢复活动的差异。

不能一次把热身、呼吸、提肛、意守、口诀和收功全部加入，否则无法判断到底是什么产生了结果。

# 七、项目规范需要进行的修改

建议建立：

```text
决策-0002：
新增“当代传播资料”类别及处理流程
```

决定内容包括：

1. 新增当代传播资料卡；
2. 新增 `13-当代传播资料卡` 目录；
3. 视频、网络文章和网络课程先进入待处理区；
4. 当代传播材料不能直接作为古籍依据；
5. 当代传播材料不能作为现代学术证据；

9. 当代传播资料可以生成主张卡、争议卡、风险卡和专题报告；

* 《基础知识卡模板总纲 V0.2》；

# 八、最终验收标准

这套资料处理完成后，应至少形成：

* 1张当代传播资料卡；
* 1份视频索引；
* 1份整理稿；
* 1份传统出处待查表；
* 20条以上内容拆解记录；
* 6—8张主张卡；
* 3—5张风险资料卡；
* 2—4张争议卡；
* 若干原文追溯任务；
* 1份专题分析报告；
* 1张项目决策记录。

专题完成的判断标准不是“得出这套方法有用或没用”，而是：

> 能够明确说明其中每一项内容来自哪里、属于什么性质、证据有多强、风险有多大，以及目前可以用于什么、不能用于什么。
